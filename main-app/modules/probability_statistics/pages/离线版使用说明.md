# 概率统计可视化 - 离线版使用说明

## 📦 包含内容

本离线包包含5个全新的概率统计交互式可视化模块：

### 📊 可视化模块列表

1. **常见离散分布可视化** (19KB)
   - 几何分布、超几何分布、负二项分布
   - 交互式参数调整
   - 实时概率质量函数和统计量计算

2. **随机变量函数的分布** (22KB)
   - 线性变换：Y = aX + b
   - 平方变换：Y = X²
   - 指数变换：Y = e^X
   - 对数变换：Y = ln(X)
   - 原始分布与变换后分布对比

3. **Bootstrap方法** (31KB)
   - 自助法重采样技术
   - 支持均值、中位数、方差、相关系数估计
   - 动画演示重采样过程
   - 自动计算置信区间

4. **二维随机变量联合分布** (22KB)
   - 二维正态分布
   - 二维均匀分布
   - 3D曲面图和等高线图
   - 边缘分布可视化

5. **边缘分布与条件分布** (25KB)
   - 离散型：掷骰子示例
   - 连续型：二维正态分布
   - 联合分布、边缘分布、条件分布对比
   - 独立性检验演示

## 🚀 使用方法

### 方法1：直接打开（推荐）

1. 双击任意 `.html` 文件即可在浏览器中打开
2. 所有功能完全离线可用
3. 无需安装任何软件

### 方法2：通过本地服务器（可选）

如果遇到跨域问题：

```bash
# 使用Python启动本地服务器
cd 文件所在目录
python -m http.server 8000

# 然后访问: http://localhost:8000
```
