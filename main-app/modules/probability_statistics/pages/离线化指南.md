# 概率统计可视化 - 离线化指南

## 🎯 目标
将新增的5个可视化页面转换为真正的离线版本

## 📝 步骤

### 方法1：手动下载（推荐用于个人使用）

1. **下载必要的库文件**到 `pages/lib/` 目录：

```bash
cd main-app/modules/probability_statistics/pages/lib

# 下载 Plotly (约 3.5MB)
curl -o plotly.min.js https://cdn.plot.ly/plotly-2.26.0.min.js

# 或者使用 wget
wget https://cdn.plot.ly/plotly-2.26.0.min.js -O plotly.min.js
```

2. **修改每个HTML文件的script标签**：

将：
```html
<script src="https://cdn.plot.ly/plotly-latest.min.js"></script>
```

改为：
```html
<script src="lib/plotly.min.js"></script>
```

将：
```html
<script src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js"></script>
```

改为：
```html
<script src="lib/tex-mml-chtml.js"></script>
```

### 方法2：使用脚本自动转换（推荐）

创建自动化脚本批量转换所有页面。

## ✅ 完成后

- 无需互联网连接即可使用所有可视化功能
- 可以将整个 `pages` 文件夹打包发送给他人
- 适合课堂展示、考试复习等场景

## 📦 需要下载的文件

1. **Plotly** (必需): https://cdn.plot.ly/plotly-2.26.0.min.js (~3.5MB)
2. **MathJax** (可选): https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js (~70KB)

## 📝 注意事项

- MathJax 如果不需要数学公式渲染，可以省略
- Plotly 是必需的，所有图表都依赖它
- 下载后总大小约 3.6MB
