# 概率论与数理统计可视化模块

## 📦 模块简介

本模块是"万物可视化"平台的概率统计子模块，提供了完整的概率论与数理统计交互式可视化工具。

## 🎯 功能特色

### 1. 知识导航系统
- **知识树** (`knowledge-tree.html`): 树状结构展示完整知识体系
- **概念导航器** (`concept-navigator-fast.html`): 快速搜索和定位概念

### 2. 可视化页面（50+个）
包含以下内容：
- 经典分布可视化（二项、泊松、正态、指数等）
- 多维随机变量可视化
- 统计推断方法（假设检验、参数估计等）
- 现代统计方法（Bootstrap等）
- 期末速通系列（30+个快速学习页面）

### 3. 完整的离线支持
- 本地Plotly.js库（3.4MB）
- 本地MathJax库（1.1MB）
- 所有页面可离线使用

## 🚀 使用方法

### 方式1：从主页开始
打开 `index.html`，浏览所有可用的可视化模块

### 方式2：使用知识树
打开 `knowledge-tree.html`，通过树状结构了解知识体系并快速跳转

### 方式3：使用概念导航
打开 `concept-navigator-fast.html`，搜索特定概念并直接访问
