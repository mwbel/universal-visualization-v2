# 快速启动指南

## 🚀 一键启动（推荐）

### macOS / Linux
```bash
cd /Users/Min369/Documents/同步空间/Manju/Projects/AlVisualization/main-app/modules/differential_geometry/pages/act-1/
./start-server.sh
```

### Windows
双击运行 `start-server.bat`

## 📱 然后在浏览器访问

```
http://localhost:8080/chapter2.5-fundamental-forms.html
```

## ❗ 重要提示

1. **不要直接双击HTML文件** - 会导致CORS错误
2. **确保网络连接正常** - 需要加载Plotly和MathJax
3. **使用现代浏览器** - Chrome, Firefox, Safari, Edge

## 🛠️ 如果遇到问题

### 端口被占用
如果8080端口被占用，可以修改启动脚本使用其他端口（如8081, 3000等）

### CDN资源加载失败
- 检查网络连接
- 尝试使用VPN
- 查看 `README-chapter2.5.md` 了解本地部署方案

### 页面显示异常
- 打开浏览器开发者工具（F12）查看控制台错误
- 确保使用HTTP协议访问（不是file://）
- 刷新页面重试
