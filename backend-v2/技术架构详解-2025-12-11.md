## 📋 概述

万物可视化系统采用现代化的多层级架构设计，支持离线优先的可视化生成服务。整个系统就像一个"智能可视化工厂"，能够根据用户需求智能选择最佳的处理方式。

## 🗄️ 数据库: SQLite + SQLAlchemy 2.0

### 什么是数据库？
把数据库想象成一个超级智能的文件柜，专门用来存储和管理数据。

### SQLite是什么？
- **SQLite** 就是一个轻量级的数据库，像一个小巧的文件柜
- 整个数据库就是一个文件（`visualization_cache.db`），不需要安装复杂的数据库软件
- 就像你的手机通讯录一样，所有联系人信息都存在一个文件里

```bash
# 数据库文件位置
backend-v2/data/visualization_cache.db
```

### SQLAlchemy 2.0是什么？
- **SQLAlchemy** 是一个Python工具，让你不用写复杂的SQL语句
- 就像你有了一个翻译器，你说中文，它自动翻译成数据库能听懂的"数据库语言"
- **2.0** 是最新版本，功能更强大，更好用

### 两者如何配合工作？
```python
# 以前要这样写（复杂）：
SELECT * FROM visualization_records WHERE subject = '数学' AND created_at > '2025-01-01'

# 现在可以这样写（简单）：
from models.visualization_models import VisualizationRecord
from database import SessionLocal

db = SessionLocal()
records = db.query(VisualizationRecord).filter(
    VisualizationRecord.subject == '数学',
    VisualizationRecord.created_at > '2025-01-01'
).all()
```

## 🔄 迁移: Alembic版本控制

### 什么是数据库迁移？
想象你装修房子，需要记录每次改动了什么：
- 墙面从白色改成蓝色
- 增加了一个书架
- 拆除了旧家具

**数据库迁移** 就是记录这些"结构变化"的过程。

### Alembic是什么？
- **Alembic** 是一个"装修记录本"，专门用来管理数据库结构的变化
- 它会帮你：
  - 记录每次数据库结构的修改
  - 能够自动升级或降级数据库版本
  - 多人协作时保持数据库结构一致

### Alembic工作流程
```bash
# 1. 创建迁移文件
alembic revision --autogenerate -m "添加新字段"

# 2. 执行迁移
alembic upgrade head

# 3. 查看当前版本
alembic current

# 4. 回退到上一版本
alembic downgrade -1
```

### 版本控制的好处
就像Git管理代码一样，Alembic管理数据库结构：
```python
# 迁移历史：
```

## 🗂️ 缓存系统: 多层级 (memory → SQLite → database)

### 什么是缓存？
把缓存想象成你的"大脑记忆系统"：

### 三层缓存架构

#### 1. Memory (内存缓存) - "瞬时记忆"
```python
# 特点：
# ✅ 最快 - 纳秒级响应
# ✅ 临时 - 应用重启就消失
# ✅ 容量小 - 通常几十MB
# ❌ 持久性差

import time
from functools import lru_cache

@lru_cache(maxsize=100)
def get_cached_result(key):
    return expensive_computation(key)
```

#### 2. SQLite (硬盘缓存) - "长期记忆"
```python
# 特点：
# ✅ 中等速度 - 毫秒级响应
# ✅ 持久存储 - 重启后还在
# ✅ 容量适中 - 几百MB到几GB
# ✅ 支持复杂查询

from database import SessionLocal
from models.visualization_models import VisualizationRecord

def get_cached_visualization(prompt_hash):
    db = SessionLocal()
    return db.query(VisualizationRecord).filter_by(id=prompt_hash).first()
```

#### 3. Database (数据库) - "永久档案"
```python
# 特点：
# ✅ 最完整 - 存储所有数据
# ✅ 最可靠 - ACID事务保护
# ✅ 容量最大 - 几TB
# ❌ 速度最慢 - 磁盘I/O限制

def store_permanent_record(data):
    record = VisualizationRecord(**data)
    db = SessionLocal()
    db.add(record)
    db.commit()
```

### 缓存查询流程
```python
class CacheService:
    def get_visualization(self, prompt: str):
        prompt_hash = hash(prompt)

        # 1. 先查内存缓存 (最快)
        cached_result = memory_cache.get(prompt_hash)
        if cached_result:
            return cached_result

        # 2. 再查SQLite缓存 (较快)
        db_result = self._query_sqlite_cache(prompt_hash)
        if db_result:
            # 存入内存缓存，下次更快
            memory_cache[prompt_hash] = db_result
            return db_result

        # 3. 最后查数据库 (最慢)
        db_result = self._query_database(prompt_hash)
        if db_result:
            # 同时存入两层缓存
            memory_cache[prompt_hash] = db_result
            self._store_sqlite_cache(prompt_hash, db_result)
            return db_result

        # 4. 都没有，需要新生成
        return None
```

```python
class MockTemplate:
    def generate_function_graph(self, function_str):
```

### 智能路由决策
```python
class IntelligentRouter:
    def route_request(self, prompt: str):
        """智能选择最佳生成方式"""

        # 1. 尝试匹配Mock模板
        mock_result = self._try_mock_template(prompt)
        if mock_result:
            return mock_result, "mock"

        # 2. 检查用户是否有相关模板
        user_template = self._find_user_template(prompt)
        if user_template:
            return user_template, "template"

        # 3. 最后调用LLM生成
        if self._should_call_llm(prompt):
            return self._call_llm_api(prompt), "llm"

        # 4. 都不行，返回错误
        raise Exception("无法生成可视化")

    def _should_call_llm(self, prompt: str) -> bool:
        """判断是否值得调用LLM"""
        # 简单的成本控制逻辑
        if len(prompt) < 10:
            return False  # 太短，不值得调用

        if self._is_likely_machable(prompt):
            return False  # 可能有本地模板

        return True
```

```python
class KeywordExtractor:
    def extract_keywords(self, text: str):
        """从文本中智能提取关键词"""
        # 1. 中文分词
        words = jieba.cut(text)

        # 2. 词性标注
        tagged_words = pseg.cut(text)

        # 3. 计算权重
        keywords = []
        for word, pos in tagged_words:
            weight = self._calculate_word_weight(word, pos)
            if weight > threshold:
                keywords.append((word, weight))

        # 4. 排序和去重
        return sorted(keywords, key=lambda x: x[1], reverse=True)[:10]
```

### 学科分类系统
```python
class SubjectClassifier:
    SUBJECT_KEYWORDS = {
        "数学": ["函数", "图像", "坐标", "方程", "几何", "三角函数", "微积分"],
        "物理": ["波动", "频率", "波长", "振幅", "电磁波", "光学", "力学"],
        "化学": ["分子", "原子", "化学键", "反应", "化合物", "pH值"],
        "天文": ["太阳系", "行星", "轨道", "恒星", "星系", "宇宙", "黑洞"],
        "生物": ["细胞", "基因", "DNA", "进化", "生态", "新陈代谢"]
    }

    def classify(self, text: str):
        """分类文本所属学科"""
        scores = {}
        for subject, keywords in self.SUBJECT_KEYWORDS.items():
            score = sum(1 for kw in keywords if kw in text)
            scores[subject] = score

        return max(scores.items(), key=lambda x: x[1]) if scores else (None, 0)
```

```python
class KeywordTracker:

        """记录关键词使用情况"""
        db = SessionLocal()
```

### 智能推荐系统
```python
class RecommendationEngine:
    def get_related_templates(self, keywords: List[str], subject: str):
        """基于关键词推荐相关模板"""

        # 1. 查找同关键词的历史记录
        related_records = db.query(VisualizationRecord).filter(
            VisualizationRecord.keywords.contains(keywords[0])
        ).all()

        # 2. 计算相似度
        similarities = []
        for record in related_records:
            similarity = self._calculate_similarity(keywords, record.keywords.split(','))
            if similarity > 0.5:  # 相似度阈值
                similarities.append((record, similarity))

        # 3. 按相似度排序
        similarities.sort(key=lambda x: x[1], reverse=True)

        return [record for record, _ in similarities[:5]]
```

## 🔗 整个系统配合工作流程

### 用户请求处理流程
```python
class VisualizationService:
    def generate_visualization(self, prompt: str):
        """可视化生成主流程"""

        # 1. 关键词提取和分析
        extractor = KeywordExtractor()
        result = extractor.extract_with_subject(prompt)

        keywords = result['keywords']
        subject = result['subject']

        # 2. 智能路由决策
        router = IntelligentRouter()

        # 3. 缓存查询
        cache_service = CacheService()
        cached_result = cache_service.get_visualization(prompt)

        if cached_result:
            # 缓存命中
            return cached_result, "cache_hit"

        # 4. 智能生成
        visualization, source = router.route_request(prompt)

        # 5. 存储和统计
        self._store_result(prompt, visualization, keywords, subject, source)

        # 6. 更新缓存
        cache_service.store_visualization(prompt, visualization)

        # 7. 更新关键词统计
        for keyword in keywords:
            self._track_keyword(keyword, subject)

        return visualization, source
```

### 数据流向图
```
用户输入
    ↓
[关键词提取] → 提取关键词和学科分类
    ↓
[缓存查询] → 检查是否有现成结果
    ↓
[智能路由] → 选择最佳生成方式:
    ├─ Mock模板 → 快速生成
    ├─ 用户模板 → 个性化生成
    └─ LLM API → 智能生成
    ↓
[结果存储] → 存入数据库
    ↓
[缓存更新] → 更新多层缓存
    ↓

```
