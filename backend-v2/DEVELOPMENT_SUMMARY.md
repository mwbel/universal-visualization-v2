## 📋 API端点总览

### 聊天接口 (`/api/v3/chat`)
```
POST /conversations          # 创建对话
GET  /conversations          # 获取对话列表
PUT  /conversations/{id}     # 更新对话
DELETE /conversations/{id}   # 删除对话
POST /message               # 发送消息
GET  /message/stream        # 流式消息
POST /search                # 搜索对话
GET  /quick-actions         # 快速操作
POST /quick-actions/{id}    # 执行快速操作
```

### 文件接口 (`/api/v3/files`)
```
POST /upload                # 上传文件
GET  /list                  # 文件列表
GET  /files/{id}           # 获取文件信息
GET  /download/{id}        # 下载文件
DELETE /files/{id}         # 删除文件
POST /process              # 处理文件内容
GET  /stats                # 文件统计
```

### 用户接口 (`/api/v3/user`)
```
GET  /me                   # 获取用户信息
PUT  /profile              # 更新个人资料
PUT  /preferences          # 更新偏好设置
PUT  /visualization        # 更新可视化设置
PUT  /model                # 更新模型设置
PUT  /notifications        # 更新通知设置
GET  /api-keys             # 获取API密钥
POST /api-keys             # 创建API密钥
DELETE /api-keys/{id}      # 删除API密钥
GET  /stats                # 使用统计
POST /export               # 导出用户数据
POST /reset                # 重置设置
```
