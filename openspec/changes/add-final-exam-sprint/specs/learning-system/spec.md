# learning-system Specification

## Purpose
提供专门的期末复习学习系统"期末速通"，整合可视化资源，支持进度追踪和AI辅助学习。

## ADDED Requirements

### Requirement: LS-001 - 课程选择界面

系统MUST提供清晰的课程选择界面，允许学生快速进入他们要复习的课程。界面应该显示三门课程（概率论与数理统计、大学物理、C++程序设计），每门课程以卡片形式展示，包含课程名称、图标、描述和当前学习进度。

#### 场景: 选择概率统计课程
**Given** 用户打开期末速通主页
**When** 用户点击"概率论与数理统计"课程卡片
**Then** 应该进入概率统计学习界面
**And** 应该显示该课程的学习进度
**And** 应该显示考点清单

#### 场景: 查看课程进度
**Given** 用户在课程选择界面
**When** 用户查看任意课程卡片
**Then** 应该显示进度条（已掌握/总考点）
**And** 应该显示百分比

### Requirement: LS-002 - 考点清单系统

系统MUST提供交互式考点清单系统，允许学生查看、追踪和管理他们的复习进度。清单应该包含每门课程的核心考点，支持勾选已掌握的考点，按优先级排序，并能够筛选未掌握的考点。

#### 场景: 查看考点清单
**Given** 用户进入某门课程的学习界面
**When** 用户查看考点清单
**Then** 应该列出所有核心考点
**And** 应该标记每个考点的掌握状态
**And** 应该按优先级排序（critical > high > medium）

#### 场景: 标记考点为已掌握
**Given** 用户查看考点清单
**When** 用户勾选某个考点
**Then** 该考点应该标记为已掌握
**And** 进度条应该更新
**And** 进度应该保存到localStorage

#### 场景: 筛选未掌握考点
**Given** 用户查看考点清单
**When** 用户点击"显示未掌握"按钮
**Then** 应该只显示未掌握的考点
**And** 应该优先显示critical优先级的考点

### Requirement: LS-003 - 可视化资源集成

系统MUST集成现有的可视化资源，为每个考点提供相关的交互式可视化链接。应该区分经典可视化和新增可视化，提供清晰的导航，允许学生快速打开相关可视化页面进行学习。

#### 场景: 查看考点相关可视化
**Given** 用户在概率统计课程中
**When** 用户点击某个考点
**Then** 应该显示相关的可视化列表
**And** 应该区分经典可视化和新增可视化
**And** 新增可视化应该标记为"新增"

#### 场景: 打开可视化页面
**Given** 用户看到可视化列表
**When** 用户点击某个可视化链接
**Then** 应该在新标签页打开该可视化
**And** 可视化应该可以正常交互

#### 场景: 返回课程界面
**Given** 用户在可视化页面
**When** 用户点击"返回"按钮
**Then** 应该返回到课程学习界面
**And** 应该保持之前的学习进度

### Requirement: LS-004 - 学习进度持久化

系统MUST实现学习进度持久化机制，使用localStorage保存学生的复习进度，包括已掌握的考点、学习时间戳等信息。确保学生在刷新页面或重新打开浏览器后能够恢复之前的学习进度。

#### 场景: 保存学习进度
**Given** 用户标记某个考点为已掌握
**When** 用户刷新页面或重新打开
**Then** 应该恢复之前的学习进度
**And** 进度条应该显示正确的状态

#### 场景: 跨设备同步（可选）
**Given** 用户在不同设备上学习
**When** 用户在设备A上标记考点
**Then** 在设备B上应该能看到更新（如果实现云同步）

### Requirement: LS-005 - 响应式设计

系统MUST采用响应式设计，支持在不同设备（桌面、平板、手机）上良好运行。在桌面端显示完整导航和侧边栏，在平板端支持侧边栏折叠，在手机端优化为单列布局并添加菜单切换功能。

#### 场景: 在桌面浏览器访问
**Given** 用户使用桌面浏览器（宽度>1024px）
**When** 用户打开期末速通页面
**Then** 应该显示完整的导航和侧边栏
**And** 课程卡片应该网格排列

#### 场景: 在平板设备访问
**Given** 用户使用平板设备（768px<宽度<1024px）
**When** 用户打开期末速通页面
**Then** 侧边栏应该可以折叠
**And** 课程卡片应该调整为2列布局

#### 场景: 在手机设备访问
**Given** 用户使用手机设备（宽度<768px）
**When** 用户打开期末速通页面
**Then** 侧边栏应该默认隐藏
**And** 课程卡片应该单列显示
**And** 应该有菜单按钮切换侧边栏
