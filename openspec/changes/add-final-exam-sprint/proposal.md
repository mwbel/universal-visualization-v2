# Proposal: 添加"期末速通"学习系统

## Change ID
`add-final-exam-sprint`

## Summary
创建一个专门的期末复习学习系统"期末速通"，整合现有的可视化资源，为三门课程（概率论与数理统计、大学物理下册、C++程序设计）提供交互式学习体验和AI辅助功能。

## Motivation
当前项目拥有丰富的可视化资源，但缺乏一个专门的期末复习界面。学生需要一个集中的、按考试重点组织的学习系统，能够：
1. 追踪学习进度
2. 集中查看考点相关可视化
3. 获得AI辅助答疑
4. 高效备考

## Proposed Scope
本变更将创建一个独立的"期末速通"学习系统，包括：

### Phase 1: 基础框架（已完成 ✅）
- [x] 创建期末速通主界面 (`期末速通/index.html`)
- [x] 实现课程选择功能（三门课程）
- [x] 设计学习进度追踪系统
- [x] 创建考点清单系统

### Phase 2: 概率统计可视化增强（已完成 ✅）
- [x] 二维随机变量及其联合分布可视化
- [x] 边缘分布与条件分布可视化
- [x] 常见离散分布（几何、超几何、负二项）
- [x] 随机变量函数的分布
- [x] Bootstrap方法（自助法）可视化

### Phase 3: 系统集成（部分完成）
- [x] 更新概率统计模块首页，链接新增可视化
- [x] 创建可视化索引页面
- [ ] 集成AI学习助手功能
- [ ] 实现跨页面导航

### Phase 4: 其他课程内容（待规划）
- [ ] 大学物理（下册）可视化
- [ ] C++程序设计可视化
- [ ] 综合复习功能

## Impact
- **新增文件**: 5个概率统计可视化HTML文件 + 1个索引页
- **修改文件**: 概率统计模块首页
- **用户价值**: 提供集中的期末复习平台，提升学习效率
- **技术债务**: 需要维护额外的HTML页面

## Alternatives Considered
1. **在现有模块中直接添加内容**
   - 优点: 不需要新界面
   - 缺点: 缺乏期末复习的紧迫感和针对性

2. **使用独立的Web应用**
   - 优点: 完全独立，易于管理
   - 缺点: 与现有资源整合困难

**决定方案**: 创建独立的"期末速通"页面，但深度复用现有可视化资源

## Dependencies
- 现有的概率统计可视化模块
- Plotly.js（可视化库）
- MathJax（公式渲染）

## Success Criteria
- ✅ 用户可以在期末速通主页选择课程
- ✅ 概率统计课程链接到所有相关可视化（包括新增的5个）
- ✅ 学习进度可以追踪和保存
- ✅ 界面友好，响应式设计

## Timeline
- **Phase 1-2**: 已完成（2025-01-17）
- **Phase 3**: 进行中
- **Phase 4**: 待规划（根据用户需求）
