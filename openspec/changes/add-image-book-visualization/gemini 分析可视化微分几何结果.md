###第一章：欧氏几何与非欧几何 (Page 3-5)####1.1 内蕴几何 vs. 外在几何* 
**内蕴几何 (Intrinsic Geometry)**：关注曲面“内部”的几何结构，仅依赖于第一基本形式（度量张量）。例如，生活在曲面上的“智慧蚂蚁”测量测地线或高斯曲率 K，无需知道曲面在三维空间中如何弯曲 。


* 
**外在几何 (Extrinsic Geometry)**：研究曲面在环境空间（如 \mathbb{R}^3）中的弯曲方式，涉及法向量、主曲率等概念 。


* 
**等距变形**：将一张平纸卷成圆柱面，其**外在几何**改变了，但**内蕴几何**（如三角形内角和、距离）保持不变。对于曲面上的生物来说，这种弯曲是无法察觉的 。



####1.2 对径点 vs. 非对径点* 
**定义**：在 n-1 维单位球面 S^{n-1} 上，若 q=-p，则 p, q 为对径点；否则为非对径点 。



####1.3 测地线 (Geodesic)* 
**定义**：曲面上局部最短的“直”线。其方程涉及 Christoffel 符号 \Gamma_{ij}^k 。


* 
**物理直观**：相当于在曲面上拉紧一根绳子形成的路径。切向加速度为零，运动“无偏转” 。

###测地线性质与欧氏/非欧几何 (Page 6-9)####1.4 欧氏几何与非欧几何* **球面测地线**：是大圆（Great Circle）。
* 
**非对径点**：测地线唯一 。


* 
**对径点**：存在无穷多条等长的测地线（例如地球经线连接南北极） 。




* **几何分类**：
* **欧氏**：过直线外一点仅有一条平行线。
* **罗氏/双曲**：过直线外一点有多条平行线。
* 
**黎曼/球面**：不存在平行线 。





####1.5 三角形的角盈 (Angle Excess)* 
**定义**：角盈 \mathcal{E} = (\text{内角和}) - \pi 。


* 
**哈里奥特定理 (1603)**：在球面上，\mathcal{E} = \frac{1}{R^2} A，其中 A 是面积，R 是半径 。



####1.6 构造测地线* 
**直性 (Straightness)**：测地线不仅是最短路径，也是“最直”的路径 。


* 
**胶带构造法**：将一条直的胶带平铺粘在曲面上，其中心线即为测地线 。反之，从曲面上剥下的测地线窄带在平面上是一条直线 。

###空间的本质与绝对单位 (Page 10-12)####1.7 空间的本质* **角盈与曲率**：兰伯特发现 \mathcal{E}(\triangle) = \mathcal{K} A(\triangle)。
* 球面几何：\mathcal{K} > 0（内角和 > \pi）。
* 双曲几何：\mathcal{K} < 0（内角和 < \pi）。
* 平面几何：\mathcal{K} = 0 。




* **双曲几何特性**：
* 双曲三角形角盈最小值为 -\pi（理想三角形）。
* 不存在相似三角形（大小不同则角度必不同） 。




* **自然长度单位**：
* 在非欧几何中，存在由空间曲率决定的“绝对长度”。自然单位长度定义为 R := |\mathcal{K}|^{-1/2} 。


* 角度是无量纲的，而曲率 \mathcal{K} 的量纲是 1/\text{长度}^2 。




* 
**双曲余弦定理**：\cosh c = \cosh a \cosh b - \sinh a \sinh b \cos \gamma 。

###绝妙定理与常曲率曲面 (Page 17-19)* 
**绝妙定理 (Theorema Egregium)**：高斯曲率是**内蕴**的。它只依赖于第一基本形式，与曲面如何嵌入空间无关。例如，捏扁一个乒乓球（不拉伸），其高斯曲率不变 。


* 
**常正曲率曲面**：除了球面，还有两端尖锐的纺锤形曲面（Spindle）等。明金（Minding, 1839）证明，所有具有相同常曲率 \mathcal{K} 的曲面在局部上是等距同构的 。


* 
**常负曲率曲面**：伪球面（Pseudosphere，由曳物线旋转而成）具有常负曲率 \mathcal{K} = -1/R^2 。希尔伯特证明，不可能在三维欧氏空间中嵌入完整的、无边缘的常负曲率曲面 。
