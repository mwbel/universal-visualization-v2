## 第5章 三角比 (Chapter 5: Trigonometric Ratios)

| 中文术语 | 英文术语 | 数学符号 |
|---------|----------|----------|
| 角 | Angle | $\angle$ (几何角), $\alpha$, $\beta$, $\theta$ (角的大小) |
| 锐角 | Acute Angle | $0° < \alpha < 90°$ 或 $0 < \alpha < \frac{\pi}{2}$ |
| 直角 | Right Angle | $90°$ 或 $\frac{\pi}{2}$ |
| 钝角 | Obtuse Angle | $90° < \alpha < 180°$ 或 $\frac{\pi}{2} < \alpha < \pi$ |
| 平角 | Straight Angle | $180°$ 或 $\pi$ |
| 周角 | Revolution / Full Angle | $360°$ 或 $2\pi$ |
| 正角 | Positive Angle | $\alpha > 0$ |
| 负角 | Negative Angle | $\alpha < 0$ |
| 弧度 | Radian | $\text{rad}$ |
| 角度 | Degree | $°$ |
| 象限角 | Quadrantal Angle | - |
| 三角比 | Trigonometric Ratio | - |
| 正弦 | Sine | $\sin \alpha = \frac{y}{r}$ |
| 余弦 | Cosine | $\cos \alpha = \frac{x}{r}$ |
| 正切 | Tangent | $\tan \alpha = \frac{y}{x} = \frac{\sin \alpha}{\cos \alpha}$ |
| 余切 | Cotangent | $\cot \alpha = \frac{x}{y} = \frac{\cos \alpha}{\sin \alpha}$ |
| 正割 | Secant | $\sec \alpha = \frac{r}{x} = \frac{1}{\cos \alpha}$ |
| 余割 | Cosecant | $\csc \alpha = \frac{r}{y} = \frac{1}{\sin \alpha}$ |
| 同角三角比关系 | Trigonometric Identities of Same Angle | - |
| 平方关系 | Pythagorean Identities | $\sin^2 \alpha + \cos^2 \alpha = 1$ |
| 商数关系 | Quotient Identities | $\tan \alpha = \frac{\sin \alpha}{\cos \alpha}$ |
| 倒数关系 | Reciprocal Identities | $\tan \alpha \cdot \cot \alpha = 1$ |
| 诱导公式 | Reduction Formulas | $\sin(\pi - \alpha) = \sin \alpha$ 等 |
| 两角和与差的三角比 | Trigonometric Ratios of Sum and Difference of Angles | - |
| 两角和的正弦 | Sine of Sum of Angles | $\sin(\alpha + \beta) = \sin \alpha \cos \beta + \cos \alpha \sin \beta$ |
| 两角和的余弦 | Cosine of Sum of Angles | $\cos(\alpha + \beta) = \cos \alpha \cos \beta - \sin \alpha \sin \beta$ |
| 两角和的正切 | Tangent of Sum of Angles | $\tan(\alpha + \beta) = \frac{\tan \alpha + \tan \beta}{1 - \tan \alpha \tan \beta}$ |
| 两角差的正弦 | Sine of Difference of Angles | $\sin(\alpha - \beta) = \sin \alpha \cos \beta - \cos \alpha \sin \beta$ |
| 两角差的余弦 | Cosine of Difference of Angles | $\cos(\alpha - \beta) = \cos \alpha \cos \beta + \sin \alpha \sin \beta$ |
| 两角差的正切 | Tangent of Difference of Angles | $\tan(\alpha - \beta) = \frac{\tan \alpha - \tan \beta}{1 + \tan \alpha \tan \beta}$ |
| 倍角公式 | Double Angle Formulas | - |
| 二倍角正弦 | Sine of Double Angle | $\sin 2\alpha = 2\sin \alpha \cos \alpha$ |
| 二倍角余弦 | Cosine of Double Angle | $\cos 2\alpha = \cos^2 \alpha - \sin^2 \alpha = 2\cos^2 \alpha - 1 = 1 - 2\sin^2 \alpha$ |
| 二倍角正切 | Tangent of Double Angle | $\tan 2\alpha = \frac{2\tan \alpha}{1 - \tan^2 \alpha}$ |
| 半角公式 | Half Angle Formulas | $\sin \frac{\alpha}{2} = \pm \sqrt{\frac{1 - \cos \alpha}{2}}$ 等 |
| 万能公式 | Universal Formulas | $\sin \alpha = \frac{2\tan \frac{\alpha}{2}}{1 + \tan^2 \frac{\alpha}{2}}$ 等 |
| 积化和差 | Product-to-Sum Formulas | $\sin \alpha \cos \beta = \frac{1}{2}[\sin(\alpha + \beta) + \sin(\alpha - \beta)]$ 等 |
| 和差化积 | Sum-to-Product Formulas | $\sin \alpha + \sin \beta = 2\sin \frac{\alpha + \beta}{2}\cos \frac{\alpha - \beta}{2}$ 等 |
| 三角恒等式 | Trigonometric Identity | - |
| 三角方程 | Trigonometric Equation | $\sin x = a$ 等 |
| 正弦定理 | Law of Sines | $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$ |
| 余弦定理 | Law of Cosines | $a^2 = b^2 + c^2 - 2bc\cos A$ |
| 解三角形 | Solving Triangles | - |
| 斜三角形 | Oblique Triangle | - |
| 面积公式 | Area Formula | $S = \frac{1}{2}bc\sin A$ |
| 海伦公式 | Heron's Formula | $S = \sqrt{p(p-a)(p-b)(p-c)}$ |
