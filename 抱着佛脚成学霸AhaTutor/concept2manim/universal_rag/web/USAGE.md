## 🚀 快速开始

### 1. 启动服务

```bash
# 方法 1: 使用启动脚本
cd universal_rag/web
./start.sh

# 方法 2: 直接运行
python3 app.py
```

### 2. 访问界面

打开浏览器访问: http://localhost:5001

### 3. 配置数据源

1. 在侧边栏选择数据源类型（JSON/CSV/SQLite）
2. 输入数据源路径（例如：`examples/sample_data.json`）

### 4. 选择策略

点击侧边栏中的策略卡片，选择合适的 RAG 策略：
- **纯向量检索** - 快速语义搜索
- **纯图检索** - 探索概念关系
- **混合检索** - 平衡语义和结构
- **问答优化** - 针对问答场景
- **学习路径优化** - 生成学习路径
- 等等...

### 5. 初始化系统

点击"初始化 RAG"按钮，等待系统初始化完成。

### 6. 开始使用

切换到不同的标签页使用各种功能。

## 📋 功能详解

### 1️⃣ 问答功能

**使用步骤：**
1. 切换到"问答"标签页
2. 在文本框中输入问题（例如：什么是深度学习？）
3. 点击"提问"按钮
4. 查看生成的答案

**特点：**
- 基于检索的上下文生成答案
- 显示使用的策略
- 支持中英文问答

### 2️⃣ 搜索功能

**使用步骤：**
1. 切换到"搜索"标签页
2. 输入搜索关键词（例如：神经网络）
3. 设置返回结果数（Top-K）
4. 点击"搜索"按钮
5. 查看搜索结果

**特点：**
- 显示相似度分数
- 可调整返回结果数
- 卡片式结果展示

### 3️⃣ 学习路径功能

**使用步骤：**
1. 切换到"学习路径"标签页
2. 输入目标概念 ID（例如：5）
3. 点击"生成学习路径"按钮
4. 查看结构化的学习路径

**特点：**
- 显示每步的距离
- 按顺序展示学习步骤
- 适合教育场景

### 4️⃣ 策略对比功能

**使用步骤：**
1. 切换到"策略对比"标签页
2. 输入查询内容
3. 勾选要对比的策略（可多选）
4. 点击"开始对比"按钮
5. 查看不同策略的结果对比

**特点：**
- 并排显示多个策略的结果
- 直观比较效果差异
- 帮助选择最佳策略

## 🔧 API 接口

Web 服务提供完整的 REST API：

### 获取策略列表
```bash
curl http://localhost:5001/api/strategies
```

### 初始化 RAG
```bash
curl -X POST http://localhost:5001/api/init \
  -H "Content-Type: application/json" \
  -d '{
    "data_source_type": "json",
    "data_source_path": "examples/sample_data.json",
    "strategy": "hybrid"
  }'
```

### 问答
```bash
curl -X POST http://localhost:5001/api/ask \
  -H "Content-Type: application/json" \
  -d '{"query": "什么是深度学习？"}'
```

### 搜索
```bash
curl -X POST http://localhost:5001/api/search \
  -H "Content-Type: application/json" \
  -d '{"query": "神经网络", "top_k": 5}'
```

## 💡 使用技巧

1. **首次使用**
   - 使用示例数据：`examples/sample_data.json`
   - 选择"混合检索"策略
   - 先尝试问答功能

2. **策略选择**
   - 快速问答 → 问答优化
   - 文档搜索 → 文档检索优化
   - 学习路径 → 学习路径优化
   - 概念解释 → 概念解释优化

3. **性能优化**
   - 调整 Top-K 值
   - 选择合适的策略
   - 使用向量检索更快

4. **对比策略**
   - 选择 2-3 个策略对比
   - 观察结果数量和质量
   - 找到最适合的策略

## ⚠️ 注意事项

1. **数据源路径**
   - 使用相对于 web 目录的路径
   - 或使用绝对路径

2. **初始化**
   - 切换策略后需要重新初始化
   - 更改数据源后需要重新初始化

3. **图检索功能**
   - 需要数据源包含关系数据
   - JSON 格式需要 `relations` 字段
   - CSV 需要单独的关系文件

4. **浏览器兼容性**
   - 推荐使用 Chrome/Firefox/Safari
   - 需要启用 JavaScript
