# 第2章总练习题

1. 证明：如果  $\lim_{n\to \infty}x_n = a$ ，则  $\lim_{n\to \infty}|x_n| = |a|$ 。反之不一定成立，请举例说明。

2. 设数列  $\{x_{n}\}$  的两个分别由偶数项和奇数项组成的子数列  $\{x_{2k}\}, \{x_{2k-1}\}$  都收敛于  $a$ , 即  $\lim_{k \to \infty} x_{2k} = \lim_{k \to \infty} x_{2k-1} = a$ , 证明  $\lim_{n \to \infty} x_{n} = a$ .

3. 求下列数列的极限：

(1)  $\lim_{n\to \infty}\sqrt[n]{a^n + b^n} (a > 0,b > 0);$

(2)  $\lim_{n\to \infty}\left(\frac{1}{n^2 + n + 1} +\frac{2}{n^2 + n + 2} +\dots +\frac{n}{n^2 + n + n}\right);$

(3)  $\lim_{n\to \infty}\left(\frac{1}{1 + 2} +\frac{1}{1 + 2 + 3} +\dots +\frac{1}{1 + 2 + \cdots + n}\right).$

4. 设  $x_{1} = 1$  ，  $x_{n + 1} = 1 + \frac{x_n}{x_n + 1}$ $(n = 1,2,\dots)$  ，证明  $\lim_{n\to \infty}x_n$  存在，并求极限

5. 求下列函数的极限：

(1)  $\lim_{x\to 0}\frac{\sqrt[3]{1 + x} - 1}{x};$

(2)  $\lim_{x\to 0}\frac{\sqrt{1 + x} - \sqrt{1 - x}}{\sqrt[3]{1 + x} - \sqrt[3]{1 - x}};$

(3)  $\lim_{x\to 0}(\cos x)^{\frac{1}{x^2}}$

(4)  $\lim_{n\to \infty}\left[(1 + x)(1 + x^2)\dots (1 + x^{2^n})\right](|x| < 1)$ ;

(5)  $\lim_{x\to 0}\left(\frac{a^x + b^x + c^x + d^x}{4}\right)^{\frac{1}{x}}$ $(a,b,c,d$  是不等于1的正数).

6. 设函数  $f(x) = \lim_{n\to \infty}\frac{x^{2n - 1} + ax^2 + bx}{x^{2n} + 1}$  在  $(- \infty, + \infty)$  上连续，试求  $a, b$  的值

7. 证明连续函数的局部保号性：若函数  $f(x)$  在点  $x_0$  处连续，且  $f(x_0) > 0$  (或  $f(x_0) < 0$ )，则存在  $\delta > 0$ ，使得当  $x \in U(x_0, \delta)$  时，有

$$
f (x) > 0 (\text {或} f (x) <   0).
$$

8. 设函数  $f(x)$  在闭区间  $[a, b]$  上连续， $x_1, x_2, \dots, x_n$  是  $[a, b]$  中  $n$  个点，则至少在  $(a, b)$  内存在一点  $\xi$ ，使得

$$
f (\xi) = \frac {f (x _ {1}) + f (x _ {2}) + \cdots + f (x _ {n})}{n}.
$$

9. 设函数  $f(x)$  在  $(- \infty, + \infty)$  内连续, 而且  $\lim_{x \to \infty} f(x) = a$  存在, 则  $f(x)$  在  $(- \infty, + \infty)$  内有界.
