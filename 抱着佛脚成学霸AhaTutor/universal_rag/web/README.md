# Universal RAG Web 界面

## 启动 Web 服务

### 1. 安装依赖

```bash
pip install flask
```

### 2. 启动服务

```bash
cd universal_rag/web
python3 app.py
```

### 3. 访问界面

打开浏览器访问: http://localhost:5000

## 功能特性

### 🎨 界面功能

1. **策略选择**
   - 11 种预定义 RAG 策略
   - 可视化策略参数
   - 一键切换策略

2. **问答功能**
   - 输入问题获取答案
   - 显示使用的策略
   - 实时响应

3. **文档搜索**
   - 关键词搜索
   - 可调整 Top-K
   - 显示相似度分数

4. **学习路径**
   - 输入目标概念 ID
   - 生成结构化学习路径
   - 显示每步距离

5. **策略对比**
   - 同时对比多个策略
   - 并排显示结果
   - 直观比较效果

## API 接口

### 获取策略列表
```
GET /api/strategies
```

### 初始化 RAG
```
POST /api/init
Body: {
  "data_source_type": "json",
  "data_source_path": "data.json",
  "strategy": "hybrid"
}
```

### 问答
```
POST /api/ask
Body: {
  "query": "什么是深度学习？"
}
```

### 搜索
```
POST /api/search
Body: {
  "query": "神经网络",
  "top_k": 5
}
```

### 学习路径
```
POST /api/path
Body: {
  "target_id": 5
}
```

### 策略对比
```
POST /api/compare
Body: {
  "query": "深度学习",
  "strategies": ["vector_only", "graph_only", "hybrid"],
  "config": {...}
}
```

## 使用流程

1. **配置数据源**
   - 选择数据源类型（JSON/CSV/SQLite）
   - 输入数据源路径

2. **选择策略**
   - 浏览 11 种策略
   - 点击选择合适的策略

3. **初始化系统**
   - 点击"初始化 RAG"按钮
   - 等待初始化完成

4. **使用功能**
   - 切换到相应标签页
   - 输入查询内容
   - 查看结果

## 技术栈

- **后端**: Flask
- **前端**: HTML5 + CSS3 + JavaScript
- **样式**: 渐变设计 + 卡片布局
- **交互**: 原生 JavaScript (无需框架)

## 特色功能

✅ **响应式设计** - 适配不同屏幕尺寸
✅ **实时反馈** - Loading 状态和错误提示
✅ **美观界面** - 现代化渐变设计
✅ **易用性** - 直观的操作流程
✅ **完整功能** - 覆盖所有 RAG 操作

## 注意事项

1. 确保数据源文件路径正确
2. 首次使用需要先初始化
3. 切换策略后需要重新初始化
4. 学习路径功能需要图关系数据
