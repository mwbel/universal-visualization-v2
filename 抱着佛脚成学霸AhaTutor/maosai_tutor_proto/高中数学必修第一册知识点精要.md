**集合运算**： \* **交集**：$A \\cap B \= \\{x \\mid x \\in A \\text{ 且 } x \\in B\\}$ 1。 \* **并集**：$A \\cup B \= \\{x \\mid x \\in A \\text{ 或 } x \\in B\\}$ 1。 \* **补集**：$\\complement\_U A \= \\{x \\mid x \\in U \\text{ 且 } x \\notin A\\}$ 1。 \* **常用逻辑用语**： \* **充分/必要条件**：若 $\\alpha \\Rightarrow \\beta$，则 $\\alpha$ 是 $\\beta$ 的充分条件，$\\beta$ 是 $\\alpha$ 的必要条件 1。 \* **充要条件**：若 $\\alpha \\Leftrightarrow \\beta$，则 $\\alpha$ 与 $\\beta$ 互为充要条件 1。 \#\#\# 第2章：等式与不等式 \* **一元二次方程根与系数的关系（韦达定理）**： 设 $ax^2+bx+c=0 (a \\neq 0)$ 的两根为 $x\_1, x\_2$，则 $x\_1+x\_2 \= \-\\frac{b}{a}$，$x\_1x\_2 \= \\frac{c}{a}$ 2。 \* **一元二次不等式解法**：取决于判别式 $\\Delta \= b^2 \- 4ac$。当 $a\>0, \\Delta\>0$ 时，其解集位于两根之外；当 $\\Delta\<0$ 时，$ax^2+bx+c\>0$ 的解集为 $\\mathbb{R}$ 2。 \* **基本不等式**： \* **平均值不等式**：$\\frac{a+b}{2} \\geq \\sqrt{ab} \\quad (a, b \> 0)$，当且仅当 $a=b$ 时等号成立 2。 \* **常用变形**：$a^2+b^2 \\geq 2ab$ 3。 \* **三角不等式**：$|a+b| \\leq |a| \+ |b|$，当且仅当 $ab \\geq 0$ 时等号成立 3。 \#\#\# 第3章：幂、指数与对数 \* **幂的运算性质**： $a^s a^t \= a^{s+t}$；$(a^s)^t \= a^{st}$；$(ab)^t \= a^t b^t$ 4。 \* **对数运算性质**： 若 $a^x \= N$，则 $\\log\_a N \= x$ 4。 \* $\\log\_a 1 \= 0$；$\\log\_a a \= 1$ 4。 \* $\\log\_a (MN) \= \\log\_a M \+ \\log\_a N$ 4。 \* $\\log\_a \\frac{M}{N} \= \\log\_a M \- \\log\_a N$ 4。 \* $\\log\_a N^c \= c \\log\_a N$ 4。 \* **换底公式**：$\\log\_b N \= \\frac{\\log\_a N}{\\log\_a b}$ 4。 \#\#\# 第4章：幂函数、指数函数与对数函数 \* **函数形式**：幂函数 $y=x^a$、指数函数 $y=a^x (a\>0, a \\neq 1)$、对数函数 $y=\\log\_a x (a\>0, a \\neq 1)$ 5, 6。 \* **单调性**： \* 对于 $y=a^x$ 和 $y=\\log\_a x$，当 $a\>1$ 时在定义域上严格递增；当 $0\<1$ 时严格递减 5, 6。 \* 对于幂函数 $y=x^a$，当 $a\>0$ 时在 $(0, \+\\infty)$ 上严格递增；当 $a\<0$ 时严格递减 5。 \#\#\# 第5章：函数的概念、性质及应用 \* **函数奇偶性**： \* **偶函数**：$f(-x) \= f(x)$，图像关于 $y$ 轴对称 7。 \* **奇函数**：$f(-x) \= \-f(x)$，图像关于原点对称 8。 \* **函数零点**：使得 $f(c)=0$ 的实数 $c$ 称为函数的零点，即图像与 $x$ 轴交点的横坐标 9。
