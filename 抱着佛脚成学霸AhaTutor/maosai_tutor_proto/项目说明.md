# 产品技术文档 (Technical Documentation)
## 1. 系统架构 (System Architecture)
Maosai Tutor Prototype 采用轻量级的前后端分离架构，强调快速响应与高度交互的数学可视化体验。

### 1.1 技术栈 (Tech Stack)
- 后端 (Backend) : Python FastAPI
  - 提供静态资源服务 ( StaticFiles )。
  - 处理页面模板渲染 ( Jinja2Templates )。
  - 提供知识库与 RAG (检索增强生成) API 接口。
  - 运行环境: Uvicorn (ASGI Server).
- 前端 (Frontend) : Vanilla JavaScript (ES6+)
  - 无重型框架依赖，直接操作 DOM。
  - Plotly.js : 核心可视化库，用于绘制函数图像、向量、几何图形与统计图表。
  - MathJax : 用于渲染 LaTeX 数学公式。
  - Lucide Icons : 提供 UI 图标支持。
- 数据存储 (Data Layer) : JSONC (JSON with Comments)
  - 使用文件系统作为数据库，便于版本控制与配置热更新。
  - aha_knowledge_catalog.jsonc : 定义知识树结构、节点元数据及 UI 绑定关系。
  - aha_view_registry.jsonc : 注册可视化视图及其适用场景。
### 1.2 核心模块 (Core Modules)

#### 1.2.1 知识加载器 (Knowledge Loader)
- **位置** : `app/services/knowledge_loader.py`
- **功能** : 启动时解析 `aha_knowledge_catalog.jsonc`，构建层级化的知识树 (Subject -> Chapter -> Section -> Node)。
- **特性** : 支持 JSONC 格式（带注释的 JSON），包含去注释解析器 (`strip_jsonc_comments`)，确保配置文件的可读性与灵活性。

#### 1.2.2 视图渲染引擎 (View Rendering Engine)
- **位置** : `app/static/app.js` -> `renderView(viewSpec)`
- **机制** : 前端根据 backend 返回的 `view_id` 和 `viz_args`，动态分发到对应的渲染函数 (如 `initVectorLab`, `initSequenceLab`)。
- **动态实验室 (Lab Overlay)** : 支持全屏覆盖层模式，提供沉沉浸式交互式学习环境，能够实时响应控制器参数变化。

#### 1.2.3 AI 智能服务 (AI Service & RAG)
- **位置** : `app/services/ai_service.py` & `app/routers/chat.py`
- **功能** : 
  - **RAG 检索** : 结合 Markdown 知识库与 ZhipuAI (GLM-4) 实现基于上下文的精准问答。
  - **代码生成** : AI 可动态生成 Plotly 可视化代码并在前端实时渲染。
  - **规则引擎** : 预设数学关键词触发特定实验室视图 (如输入“二次函数”自动展示抛物线)。
# 目前实现的功能文档 (Implemented Features Documentation)
## 1. 交互式学习实验室 (Interactive Learning Labs)
系统实现了多个高度集成的数学可视化实验室：

- **平面向量实验室 (Vector Lab)** : 涵盖基本概念、线性运算（三角形/平行四边形法则）、共线判定、数量积（点积）几何意义、基底分解、三角形四心及物理力学应用等 8 大模块。
- **数列全景实验室 (Sequence Lab)** : 包含等差/等比数列定义、中项关系、线性递推、求和方法（Sn 动态推导）、最值分析、数学归纳法演示及极限逼近过程。
- **函数全景实验室 (Function Lab)** : 
    - **基础性质** : 动态演示单调性定义（x1, x2 比较）、奇偶性轴/点对称、最值变化过程。
    - **基本初等函数** : 覆盖指对幂函数图像变换、二次函数参数联动。
    - **复合函数** : 可视化“流水线”模型，动态解析 $y = f(g(x))$。
- **三角函数与物理实验室** : 提供 $A\sin(\omega x + \phi)$ 图像变换演示，并集成简谐振动 (SHM) 物理模拟动画。
- **复数实验室 (Complex Lab)** : 实现复平面拖拽交互、复数加减法的几何意义、模与共轭的直观展示。
- **概率统计工具 (Statistics)** : 实现二项分布 (Binomial Distribution) 动态模型，支持参数 $n, p$ 实时调整及正态分布逼近展示。
- **集合与逻辑** : 交互式 Venn 图、集合运算（交/并/补）及命题逻辑判定。

### 1.2 专项学习模块 (Learning Modules)

#### 1.2.1 考前速通 (Exam Speed-run)
针对短时记忆强化设计：
- **基础练** : 从题库中按专题随机抽取题目，覆盖集合、函数、三角、向量等高频考点。
- **换一批** : 支持实时刷新练习内容。
- **AI 生题** : 调用 AI 服务针对特定专题动态生成新题，实现无限量练习。
- **进度追踪** : 动态展示专题速通进度，营造闯关式学习体验。

#### 1.2.2 深度研究 (Deep Research)
针对长时记忆与思维深度设计：
- **专题透析** : 集成函数解析式深度特辑、解析几何综合研究等高级模块。
- **实验室联动** : 点击深度研究模块可直接激活全屏实验室进行沉浸式探索。

## 2. 智能辅助系统 (Intelligent Assistant)
- **RAG 知识对话** : 用户提问后，系统检索本地 Markdown 知识库，结合 AI 生成带 LaTeX 公式的高质量回答。
- **可视化联动** : 对话过程中 AI 会根据内容自动切换右侧视图，或生成特定的 Plotly 代码块进行图形化解释。
- **公式实时渲染** : 全局集成 MathJax，确保所有数学表达式呈现印刷级质量。

## 3. 技术路线与架构亮点
- **零框架前端** Vanilla JS 实现极速加载，利用 ES6 模块化组织代码。
- **静态配置驱动** : 通过修改 `aha_knowledge_catalog.jsonc` 即可完成知识点的增删改及 UI 视图的绑定，无需改动后端代码。
- **Liquid Glass 设计语言** : 采用毛玻璃特效、平滑过渡动画及自适应布局，提供高端教育工具的视觉质感。

# 发展方向 (Development Direction)

## 1. 智能化升级 (Intelligence Upgrade)
- **分步式引导提示** : 当学生做错题时，AI 不直接给出答案，而是根据错误点提供层层递进的思维启发（Scaffolding）。
- **多模态输入** : 集成 OCR 识别，支持学生拍照上传手写数学题进行自动解析与实验室联动。
- **个性化推题系统** : 基于学生在“考前速通”中的练习数据，利用贝叶斯网络或知识追踪模型模型自动计算薄弱知识点，推送针对性增强练习。

## 2. 内容生态扩展 (Content Expansion)
- **多学科覆盖** : 将“实验室”模式扩展至物理（物理电磁场、光学几何）、化学（分子结构可视化）等领域。
- **高等数学衔接** : 引入微积分初步、线性代数可视化（矩阵变换投影），为学生进入大学教育做平滑过渡。

## 3. 跨终端与持久化 (Eco-system & Persistence)
- **个人中心与错题本** : 建立基于 SQLite 或云端数据库的用户系统，实现错题自动归档、学习进度多端同步。
- **PWA 支持** : 离线缓存核心实验室资源，实现在无网络环境下也能流畅进行数学探究。

## 4. 极致交互体验 (Interaction Excellence)
- **WebGL 3D 实验室** : 引入 Three.js，将解析几何、立体几何的学习从 2D 提升至 3D 沉浸式维度。
- **多人协作白板** : 支持多名学生在同一个可视化实验台上实时操作，实现协作探究学习模式。
