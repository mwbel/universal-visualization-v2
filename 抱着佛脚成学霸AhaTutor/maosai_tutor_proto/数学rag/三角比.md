# **三角比可视化教学系统详细设计文档**

## **一、系统概述**

### 1.1 设计目标
本系统旨在通过交互式可视化技术，将三角比从基础概念到复杂公式的完整知识体系转化为直观、可操作的动态学习环境。系统以"单位圆"和"三角形"两大核心几何模型为骨架，构建8个循序渐进的教学模块，帮助学生深入理解三角比的本质，掌握公式推导与应用。

### 1.2 设计原则
1. **数形结合原则**：每个代数公式必须对应直观的几何解释
2. **交互探究原则**：学生通过操作发现规律，而非被动接受
3. **渐进式学习原则**：模块间逻辑递进，知识螺旋上升
4. **即时反馈原则**：操作后立即获得视觉和数值反馈

### 1.3 系统架构
系统采用三栏式响应布局：
- **左侧导航栏**：8个模块的导航菜单，显示学习进度
- **中部主操作区**：当前模块的交互控制和可视化展示
- **右侧信息面板**：显示公式推导、性质说明、学习提示

### [**模块三：同角三角比关系**](数学rag/三角比.md#L583-590)

#### 2.3.1 核心知识点
1. **平方关系**：
   - sin²α + cos²α = 1
   - 1 + tan²α = sec²α
   - 1 + cot²α = csc²α

2. **商数关系**：
   - tanα = sinα/cosα (cosα≠0)
   - cotα = cosα/sinα (sinα≠0)

3. **倒数关系**：
   - sinα·cscα = 1 (sinα≠0)
   - cosα·secα = 1 (cosα≠0)
   - tanα·cotα = 1 (tanα≠0)

#### 2.3.3 交互设计
1. **动态验证**：拖拽α，观察各关系式左右两边始终相等
2. **几何证明**：
   - 平方关系：展示点P在单位圆上，满足x²+y²=1
   - 商数关系：展示tanα线段与sinα/cosα计算值的一致性
   - 倒数关系：展示互为倒数的线段乘积为1
3. **关系网络图**：点击某个关系式，高亮相关的三角比线段

#### 2.3.4 公式推导展示
**平方关系推导**：
```
由定义：sinα = y/r, cosα = x/r
则 sin²α + cos²α = (y/r)² + (x/r)² = (x²+y²)/r²
∵ 点P在单位圆上：x²+y² = 1, r=1
∴ sin²α + cos²α = 1
```

### [**模块四：和、差、倍、半角公式**](数学rag/三角比.md#L583-590)

#### 2.4.1 核心知识点
1. **两角和差公式**：
   - sin(α±β) = sinαcosβ ± cosαsinβ
   - cos(α±β) = cosαcosβ ∓ sinαsinβ
   - tan(α±β) = (tanα ± tanβ)/(1 ∓ tanαtanβ)

2. **二倍角公式**：
   - sin2α = 2sinαcosα
   - cos2α = cos²α - sin²α = 2cos²α - 1 = 1 - 2sin²α
   - tan2α = 2tanα/(1 - tan²α)

3. **半角公式**：
   - sin(α/2) = ±√[(1-cosα)/2]
   - cos(α/2) = ±√[(1+cosα)/2]
   - tan(α/2) = ±√[(1-cosα)/(1+cosα)] = sinα/(1+cosα) = (1-cosα)/sinα

4. **万能置换公式**：
   - sinα = 2tan(α/2)/[1+tan²(α/2)]
   - cosα = [1-tan²(α/2)]/[1+tan²(α/2)]
   - tanα = 2tan(α/2)/[1-tan²(α/2)]

#### 2.4.2 可视化界面描述
**向量合成界面**：
```
┌─────────────────────────────────────────────┐
│  左侧：两个向量及其合成                     │
│                                             │
│       向量OA(长度1，角度α)                 │
│         ↗                                  │
│        / \                                 │
│       /   \ 向量OB(长度1，角度β)          │
│      /     ↘                              │
│     /       合成向量OC                     │
│    /α      β/                             │
│   O─────────┼─────────────→               │
│             │投影到x轴：cos(α+β)          │
│             │投影到y轴：sin(α+β)          │
│                                             │
│  右侧：公式验证面板                         │
└─────────────────────────────────────────────┘
```

**控制面板**：
- 角度α、β调节滑块
- 公式类型选择：和角/差角/倍角/半角
- 显示选项：向量、投影、坐标

#### 2.4.3 交互设计
1. **向量旋转**：分别拖拽向量OA和OB，观察合成向量OC的变化
2. **投影演示**：展示向量OC在x轴和y轴的投影，验证cos(α+β)和sin(α+β)
3. **公式变形**：选择不同形式的二倍角公式，观察几何解释的变化
4. **特殊值验证**：预设α=β，验证二倍角公式；预设β=-α，验证差角公式

#### 2.4.4 公式推导动画
**两角和公式几何推导**：
```
步骤1：在单位圆上作角α和β
步骤2：标出点A(cosα, sinα)和点B(cosβ, sinβ)
步骤3：计算向量OA与OB的点积：
   OA·OB = |OA||OB|cos(α-β) = cos(α-β)
   又 OA·OB = cosαcosβ + sinαsinβ
   ∴ cos(α-β) = cosαcosβ + sinαsinβ
步骤4：令β为-β，得cos(α+β)公式
步骤5：利用诱导公式推导sin(α±β)
```

### [**模块五：诱导公式**](数学rag/三角比.md#L583-590)

#### 2.5.1 核心知识点
1. **周期公式**（第一组）：
   - sin(2kπ+α) = sinα, cos(2kπ+α) = cosα
   - tan(2kπ+α) = tanα, cot(2kπ+α) = cotα

2. **负角公式**（第二组）：
   - sin(-α) = -sinα, cos(-α) = cosα
   - tan(-α) = -tanα, cot(-α) = -cotα

3. **π±α公式**（第三、四组）：
   - sin(π±α) = ∓sinα, cos(π±α) = -cosα
   - tan(π±α) = ±tanα, cot(π±α) = ±cotα

4. **π/2±α公式**（第五、六组）：
   - sin(π/2-α) = cosα, cos(π/2-α) = sinα
   - sin(π/2+α) = cosα, cos(π/2+α) = -sinα

5. **口诀**："奇变偶不变，符号看象限"

#### 2.5.2 可视化界面描述
**对称变换界面**：
```
┌─────────────────────────────────────────────┐
│  四个象限的单位圆                          │

│                 ·P'(-x,y)                  │
│                  │                        │
│                  │      ·P(x,y)           │
│     关于y轴对称  │      原角α            │
│────────────┼───────────────→             │
│                 │                        │
│        III象限   │    IV象限              │
│                 ·P''(-x,-y)               │

│                                             │

└─────────────────────────────────────────────┘
```

**控制面板**：
- 原始角α输入
- 对称操作选择：关于x轴、y轴、原点、旋转π/2等
- 口诀练习模式：给出变换，让用户预测结果

#### 2.5.3 交互设计
1. **对称点生成**：输入α，自动生成关于各对称轴的点
2. **坐标比较**：显示原始点P和对称点P'的坐标，推导函数值关系
3. **象限判断**：高亮变换后的角所在象限，确定符号
4. **口诀验证**：通过大量例子验证"奇变偶不变，符号看象限"

#### 2.5.4 口诀解释界面
```
"奇变偶不变"：k·(π/2)±α中，k为奇数时函数名改变，偶数时不变
"符号看象限"：把α看作锐角，看原函数在变换后象限的符号

示例：sin(π/2+α)
1. π/2的系数k=1（奇数）→ 函数名改变：sin→cos
2. 假设α为锐角，则π/2+α在第二象限
3. 第二象限sin为正，但变换后是cos，第二象限cos为负
4. 结果：sin(π/2+α) = -cosα（实际应为cosα，符号由变换决定）
注：实际公式为sin(π/2+α)=cosα，这里演示判断过程
```

### [**模块六：三角形中的三角比（正余弦定理与面积）**](数学rag/三角比.md#L583-590)

#### 2.6.1 核心知识点
1. **正弦定理**：
   - a/sinA = b/sinB = c/sinC = 2R
   - 变形：a=2RsinA, sinA=a/(2R)等

2. **余弦定理**：
   - a² = b² + c² - 2bc·cosA
   - b² = a² + c² - 2ac·cosB
   - c² = a² + b² - 2ab·cosC

3. **三角形面积公式**：
   - S = ½ab·sinC = ½ac·sinB = ½bc·sinA
   - S = ½a·hₐ（底乘高）
   - S = abc/(4R)（外接圆半径）
   - S = ½(a+b+c)·r（内切圆半径）
   - 海伦公式：S = √[p(p-a)(p-b)(p-c)], p=(a+b+c)/2

#### 2.6.2 可视化界面描述
**可变形三角形界面**：

│        / | \                               │
│       /  |h \                              │
│      /   |   \                             │
│     /    |    \                            │
│    B─────┼─────C                           │
│        a/2   a/2                           │
│                                             │

**控制面板**：

- 定理验证：正弦定理、余弦定理、面积公式

#### 2.6.3 交互设计
1. **三角形变形**：拖拽任意顶点，所有参数实时更新
2. **外接圆联动**：显示外接圆，验证a/sinA = 2R
3. **向量分解**：用向量法演示余弦定理推导
4. **面积比较**：同时显示多种面积公式计算结果，验证一致性

#### 2.6.4 定理推导展示
**余弦定理向量推导**：
```
设向量：AB = \(\vec{c}\), BC = \(\vec{a}\), CA = \(\vec{b}\)
且 \(\vec{a} + \vec{b} + \vec{c} = \vec{0}\)

考虑 \(\vec{a} = \vec{b} + \vec{c}\) 的模平方：
|\(\vec{a}\)|² = |\(\vec{b} + \vec{c}\)|²
           = |\(\vec{b}\)|² + |\(\vec{c}\)|² + 2\(\vec{b}\)·\(\vec{c}\)
           = b² + c² + 2bc·cos(π-A)
           = b² + c² - 2bc·cosA

∴ a² = b² + c² - 2bc·cosA
同理可得其他两式。
```

### [**模块七：三角形中的三角比性质**](数学rag/三角比.md#L583-590)

#### 2.7.1 核心知识点
1. **边角关系**：
   - 大边对大角：a > b ⇔ A > B ⇔ sinA > sinB
   - 正弦定理推论：a:b:c = sinA:sinB:sinC

2. **角度关系**：
   - sin2A = sin2B ⇔ A = B 或 A+B = π/2
   - cos2A = cos2B ⇔ A = B 或 A+B = π
   - A,B,C成等差数列 ⇔ B = π/3

3. **三角恒等式**：
   - 在△ABC中：A+B+C = π
   - sin(A+B) = sinC, cos(A+B) = -cosC
   - tanA + tanB + tanC = tanA·tanB·tanC
   - cotA·cotB + cotB·cotC + cotC·cotA = 1

4. **特殊三角形条件**：
   - A,B,C成等差且a,b,c成等比 ⇔ △ABC为等边三角形
   - a²+b²=c² ⇔ C=π/2（勾股定理）

#### 2.7.2 可视化界面描述
**性质探究实验室**：

#### 2.7.4 恒等式证明提示
**tanA+tanB+tanC = tanA·tanB·tanC证明**：
```
∵ A+B+C = π
∴ A+B = π-C
tan(A+B) = tan(π-C) = -tanC

又 tan(A+B) = (tanA+tanB)/(1-tanA·tanB)
∴ (tanA+tanB)/(1-tanA·tanB) = -tanC
tanA+tanB = -tanC + tanA·tanB·tanC
tanA+tanB+tanC = tanA·tanB·tanC
```

1. **辅助角公式**：

   - sinαcosβ = ½[sin(α+β)+sin(α-β)]
   - cosαcosβ = ½[cos(α+β)+cos(α-β)]

   - sinα+sinβ = 2sin[(α+β)/2]cos[(α-β)/2]
   - sinα-sinβ = 2cos[(α+β)/2]sin[(α-β)/2]
   - cosα+cosβ = 2cos[(α+β)/2]cos[(α-β)/2]
   - cosα-cosβ = -2sin[(α+β)/2]sin[(α-β)/2]
