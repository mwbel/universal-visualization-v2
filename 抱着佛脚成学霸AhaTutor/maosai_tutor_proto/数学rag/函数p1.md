2. 一、函数基本概念

2.1 函数定义与三要素

目标理解点

要素	含义
定义域	x 的合法取值区间
值域	y 的所有可能输出值
对应法则	输入 x → 输出 y 的规则


⸻

可视化设计

界面元素

Input： f(x) = ______  
数轴A：定义域  
中间：箭头映射图  
数值显示：对应法则说明  
数轴B：值域


⸻

示例可视化行为
	•	用户输入表达式，如 f(x)=2x+1
	•	定义域数轴默认显示 (-∞, +∞)
	•	拖动 x 点 → 实时在右侧显示对应 y
	•	用箭头从 x→y 演示“对应法则”

4. 三、复合函数

⸻

4.1 定义

y = f(g(x))

术语
	•	g(x)：内函数
	•	f(x)：外函数
	•	x：自变量
	•	定义域由 g → f 决定

⸻

可视化设计思想

将复合函数视为“两个层级映射管道”：

X  → g(x)  → 中间 Y  → f(y) → 最终值


⸻

界面视图

Layer1: g(x)
Layer2: f(y)
Arrow 动画连接
数值标签：每步输出


⸻

示例可视化行为

用户输入：
	•	内函数 g(x)=x^2
	•	外函数 f(x)=sin(x)

执行：
	•	拖动 x → 显示 g(x) → 再把结果传给 f → 得到最终 y
	•	动画用箭头逐步显示映射路径

5. 四、函数定义域求法

⸻

5.1 内容要点

求定义域需遵循：

条件	示例
分母不为 0	1/x → x≠0
被开方数 ≥ 0	√(x+5) → x ≥ -5
零次幂底数≠0	x^0 → 无意义
对数真数 > 0	log(x+2) → x>-2
实际意义约束	时间/距离限制


⸻

可视化设计方式

表达式输入→ 条件显示→ 数轴遮罩

控件：
  表达式文本框
演示：
  数轴
  灰色遮罩（不可取区间）


⸻

交互行为
	•	输入 f(x)=√(3x-6) → 数轴自动展示诶开区间 x≥2
	•	移动可视化滑块 → 展示对应有效点

6. 五、函数值域求法

⸻

6.1 直接法示例

函数	定义域	值域

y = k/x (k≠0)	x≠0	y≠0

⸻

可视化设计组件

Graph: 曲线图

区间填充: 值域阴影


⸻

示例交互流程

	•	显示：
	•	抛物线
	•	顶点
	•	单色阴影填充（y≥ min 值）
