第二章 不等式

⸻

一、不等式的基本性质

（1）对称性

a > b \iff b < a

不等式两边的数交换位置，不等号方向随之改变。

⸻

（2）传递性

a > b,\ b > c \Rightarrow a > c

如果一个数大于第二个数，第二个数又大于第三个数，那么第一个数一定大于第三个数。

⸻

（3）可加性

a > b \Rightarrow a + c > b + c \quad (c \in \mathbb{R})

在不等式两边同时加上同一个实数，不等号方向不变。

⸻

（4）同向可加性

\begin{cases}
a > b \\
c > d
\end{cases}
\Rightarrow a + c > b + d

两个同向不等式对应边相加，结果仍保持不等关系。

⸻

（5）可乘性

a > b \Rightarrow
\begin{cases}
c \in \mathbb{R}^+ \Rightarrow ac > bc \\
c \in \mathbb{R}^- \Rightarrow ac < bc
\end{cases}

在不等式两边同乘一个正数，不等号方向不变；
同乘一个负数，不等号方向改变。

⸻

（6）同向可乘性

\begin{cases}
a > b > 0 \\
c > d > 0
\end{cases}
\Rightarrow ac > bd
\quad
\left(\frac{a}{d} > \frac{b}{c}\right)

当两个不等式的各项均为正数时，可对应相乘，仍保持不等关系。

⸻

（7）可倒性

\begin{cases}
a > b \\
ab > 0
\end{cases}
\Rightarrow
\frac{1}{a} < \frac{1}{b}

当两个数同号且不为零时，取倒数后不等号方向改变。

⸻

（8）乘方 / 开方不等式

a > b > 0 \Rightarrow
\begin{cases}
a^n > b^n & (n \in \mathbb{N}^*) \\
\sqrt[n]{a} > \sqrt[n]{b} & (n \ge 2)
\end{cases}

正数之间的大小关系在同次乘方或开方下保持。

⸻

（9）糖水不等式

a > b > 0,\ c > 0
\Rightarrow
\frac{b}{a} < \frac{b+c}{a+c}

在保持“分母比分子大”的情况下，同时加上同一个正数，所得比值变大。

⸻

二、解不等式

⸻

1. 一元一次不等式的解法

步骤：
	1.	将不等式右边化为 0；
	2.	化为形如
ax + b > 0 \ (a>0) \quad \text{或} \quad ax + b < 0
	3.	解对应的一元一次方程；
	4.	利用一次函数图像与 x 轴交点确定解集。

⸻

2. 一元二次方程根的分布（知识补充）

设
ax^2 + bx + c = 0 \quad (a,b,c \in \mathbb{R},\ a>0)
两实根为 x_1, x_2，则：

⸻

（1）x_1>0,\ x_2>0
\begin{cases}
\Delta \ge 0 \\
x_1 + x_2 > 0 \\
x_1 x_2 > 0
\end{cases}
\iff
\begin{cases}
\Delta \ge 0 \\
-\dfrac{b}{2a} > 0 \\
f(0) > 0
\end{cases}

⸻

（2）x_1<0,\ x_2<0
\begin{cases}
\Delta \ge 0 \\
x_1 + x_2 < 0 \\
x_1 x_2 > 0
\end{cases}
\iff
\begin{cases}
\Delta \ge 0 \\
-\dfrac{b}{2a} < 0 \\
f(0) > 0
\end{cases}

⸻

（3）x_1>0,\ x_2<0
\begin{cases}
\Delta > 0 \\
x_1 x_2 < 0
\end{cases}
\iff
f(0) < 0

⸻

（4）x_1>m,\ x_2>m
\begin{cases}
\Delta \ge 0 \\
(x_1-m)+(x_2-m)>0 \\
(x_1-m)(x_2-m)>0
\end{cases}
\iff
\begin{cases}
\Delta \ge 0 \\
f(m)>0 \\
-\dfrac{b}{2a} > m
\end{cases}

⸻

（5）x_1<m<x_2
\begin{cases}
\Delta > 0 \\
(x_1-m)(x_2-m)<0
\end{cases}
\iff
f(m)<0

⸻

（6）x_1,x_2 \in (m,n)
\begin{cases}
\Delta \ge 0 \\
m < -\dfrac{b}{2a} < n \\
f(m)>0 \\
f(n)>0
\end{cases}

⸻

3. 分式不等式的求解

\frac{f(x)}{g(x)} > 0
\iff
f(x)\cdot g(x) > 0

\frac{f(x)}{g(x)} \le 0
\iff
\begin{cases}
f(x)\cdot g(x) \le 0 \\
g(x) \ne 0
\end{cases}

⸻

4. 含绝对值不等式的求解

（1）
|f(x)| < a \ (a>0)
\iff
-a < f(x) < a

|f(x)| \ge a \ (a>0)
\iff
\begin{cases}
f(x) \le -a \\
\text{或 } f(x) \ge a
\end{cases}

⸻

（2）
|f(x)| \le g(x)
\iff
\begin{cases}
g(x)\ge0 \\
-g(x) \le f(x) \le g(x)
\end{cases}

|f(x)| > g(x)
\iff
\begin{cases}
g(x)<0
\end{cases}
\text{ 或 }
\begin{cases}
g(x)\ge0 \\
f(x)>g(x) \\
f(x)<-g(x)
\end{cases}

⸻

（3）
|f(x)| \le |g(x)|
\iff
[f(x)]^2 \le [g(x)]^2

⸻

（4）
|f(x)| + |g(x)| < a \ (a>0)

等价于以下三种情况之一：
\begin{cases}
f(x)+g(x)<a \\
f(x)\ge0 \\
g(x)\ge0
\end{cases}

\begin{cases}
f(x)-g(x)<a \\
f(x)\ge0 \\
g(x)\le0
\end{cases}

\begin{cases}
-f(x)+g(x)<a \\
f(x)\le0 \\
g(x)\ge0
\end{cases}

⸻

解含绝对值不等式的思想：去绝对值

5. 无理不等式的解法（补充）

（1）
\sqrt{f(x)} > \sqrt{g(x)}
\iff
\begin{cases}
f(x)\ge0 \\
g(x)\ge0 \\
f(x)>g(x)
\end{cases}

⸻

（2）
\sqrt{f(x)} > g(x)
\iff
\begin{cases}
g(x)\ge0 \\
f(x)>[g(x)]^2
\end{cases}
\quad \text{或} \quad
\begin{cases}
f(x)\ge0 \\
g(x)<0
\end{cases}

⸻

（3）
\sqrt{f(x)} < g(x)
\iff
\begin{cases}
f(x)\ge0 \\
g(x)>0 \\
f(x)<[g(x)]^2
\end{cases}

⸻

6. 高次不等式的解法（补充）

一元高次不等式
f(x)>0 \quad \text{或} \quad f(x)<0

一般采用数轴标根法：

步骤：
	1.	将最高次项系数化为正数；
	2.	分解为若干一次因式的积；
	3.	将每个因式的根标在数轴上；
	4.	从右向左，按“右上方”规律判断符号变化；
	5.	写出不等式的解集。

三、基本不等式

⸻

（1）基本不等式 1

a^2 + b^2 \ge 2ab \quad (a,b\in\mathbb{R})

当且仅当 a=b 时取等号。

⸻

（2）基本不等式 2

\frac{a+b}{2} \ge \sqrt{ab} \quad (a>0,\ b>0)

当且仅当 a=b 时取等号。

⸻

【知识拓展】

当 0<a\le b 时：
a \le \frac{2}{\frac{1}{a}+\frac{1}{b}}
\le \sqrt{ab}
\le \frac{a+b}{2}
\le \sqrt{\frac{a^2+b^2}{2}}
\le b

⸻

【推广】

若 a_1,a_2,\dots,a_n 为 n 个正数，则：
\frac{a_1+a_2+\cdots+a_n}{n}
\ge
\sqrt[n]{a_1a_2\cdots a_n}

当且仅当：
a_1=a_2=\cdots=a_n
时取等号。

⸻

利用基本不等式求最值

注意：“一正、二定、三相等”

⸻

（1）积定和最小
a+b \ge 2\sqrt{ab}
\iff
\text{若 } ab=P \text{ 为定值，则 } a=b \text{ 时 } a+b \text{ 最小}

最小值为：
2\sqrt{P}

⸻

（2）和定积最大
ab \le \left(\frac{a+b}{2}\right)^2
\iff
\text{若 } a+b=S \text{ 为定值，则 } a=b \text{ 时 } ab \text{ 最大}

最大值为：
\frac{1}{4}S^2
