## 🎯 导航栏功能特性

### 按钮功能
1. **返回上一级** - 使用浏览器历史记录返回
2. **期末速通主页** - 直接跳转到`index.html`

### 面包屑导航
- 显示完整的页面层级
- 可点击跳转到上级页面
- 响应式自动换行

### 响应式设计
- **桌面** (>768px): 完整三栏布局
- **移动** (<768px): 垂直堆叠，全宽按钮

## 📝 示例代码

### 最简单的使用方式
```html
<!DOCTYPE html>
<html>
<head>
    <link rel="stylesheet" href="../css/page-navbar.css">
</head>
<body>
    <nav class="page-navbar">
        <div class="nav-buttons">
            <button class="nav-btn nav-btn-back" onclick="history.back()">
                返回上一级
            </button>
            <a href="../index.html" class="nav-btn nav-btn-home">
                期末速通主页
            </a>
        </div>
        <div class="page-title">
            <h1>我的页面标题</h1>
        </div>
    </nav>

    <!-- 页面内容 -->
</body>
</html>
```
