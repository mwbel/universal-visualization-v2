# 概率统计可视化 - 离线版

## 📦 使用说明

这是一个完全离线的概率统计可视化学习包，无需联网，无需安装任何软件！

### 🚀 快速开始

#### 方法1：直接打开（推荐）
1. 双击打开 `index.html` 文件
2. 点击"概率论与数理统计"卡片
3. 浏览所有可视化内容

#### 方法2：从导航页开始
1. 双击打开 `concept-navigator-fast.html`
2. 选择你想学习的章节
3. 点击对应卡片查看可视化

### ✨ 特点

- ⚡ **秒开体验**：所有页面 < 0.1秒加载
- 📴 **完全离线**：无需网络连接
- 💾 **轻量级**：总共约 1-2 MB
- 🔒 **无依赖**：不依赖任何外部库
- 📱 **跨平台**：Windows/Mac/Linux 都可以使用

### 📚 内容覆盖

**快速版页面（21个）⚡**
- 第一章：随机事件与样本空间、频率与概率、全概率公式、贝叶斯公式
- 第二章：随机变量的函数的分布
- 第三章：二维随机变量
- 第四章：数学期望、方差、矩与协方差矩阵、协方差与相关系数
- 第五章：依概率收敛与大数定律、中心极限定理
- 第六章：常用统计量、三大抽样分布对比、直方图与箱线图
- 第七章：参数估计、矩估计法、最大似然估计法、估计量的评选标准、区间估计
- 第八章：假设检验流程、假设检验扩展

**其他页面（25个）**
- 包含非快速版的完整可视化

### 📊 章节结构

1. **概率论的基本概念** - 样本空间、条件概率、独立性
2. **随机变量及其分布** - 离散型、连续型、函数分布
3. **多维随机变量** - 联合分布、边缘分布、条件分布
4. **随机变量的数字特征** - 期望、方差、协方差、相关系数
5. **大数定律及中心极限定理** - 收敛性、极限定理
6. **样本及抽样分布** - 统计量、三大抽样分布
7. **参数估计** - 点估计、区间估计
8. **假设检验** - 检验流程、实际应用

### 🔍 技术细节

- **纯 HTML + CSS + JavaScript**：无任何框架依赖
- **Canvas API**：用于绘制所有图表
- **Unicode 数学符号**：代替 MathJax，大幅减小体积
- **内联样式**：所有 CSS 都在 HTML 内部
- **响应式设计**：支持不同屏幕尺寸
