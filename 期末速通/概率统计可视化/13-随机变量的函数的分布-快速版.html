🎲 随机变量的函数的分布

如果已知随机变量 X 的分布，如何求 Y = g(X) 的分布？

核心问题：已知 X ~ f_X(x)，求 Y = g(X) 的分布 f_Y(y)

📊 离散型随机变量的函数

方法：对于每个 y 值，找到所有满足 g(x_i) = y 的 x_i
P(Y=y) = Σ P(X=x_i)，对所有 x_i 满足 g(x_i)=y

💡 例子1：Y = X²

  • 如果 X 取值 -2, -1, 0, 1, 2
  • 则 Y = X² 取值 0, 1, 4
  • P(Y=0) = P(X=0)
  • P(Y=1) = P(X=-1) + P(X=1)
  • P(Y=4) = P(X=-2) + P(X=2)

原始分布 X

变换后 Y = g(X)

💡 观察：注意概率是如何"合并"的！

📈 连续型随机变量的函数 - CDF法

步骤：
1. 先求 Y 的分布函数：F_Y(y) = P(Y≤y) = P(g(X)≤y)
2. 对 y 求导得到密度函数：f_Y(y) = dF_Y(y)/dy

💡 例子2：Y = 2X (线性变换)

  • 如果 X ~ U(0,1)，即均匀分布在 [0,1]
  • F_Y(y) = P(2X≤y) = P(X≤y/2) = y/2，当 0≤y≤2
  • f_Y(y) = d(y/2)/dy = 1/2，即 Y ~ U(0,2)

🔢 单调函数的变换公式

定理：如果 y = g(x) 单调可导，且 h(y) 是其反函数
则 f_Y(y) = f_X(h(y)) · |h'(y)|

📌 正态分布的线性变换

  • 如果 X ~ N(μ, σ²)
  • 则 Y = aX + b ~ N(aμ + b, a²σ²)
  • 性质：正态分布的线性变换仍是正态分布！

🎯 实际应用示例

1. 球的半径与体积

  • 球的半径 R ~ 某分布
  • 球的体积 V = (4/3)πR³
  • 如何从 R 的分布求 V 的分布？

2. 股票收益率

  • 初始投资 P₀，收益率 R
  • 最终价值 P₁ = P₀(1+R)
  • 从收益率的分布求最终价值的分布

3. 测量误差

  • 真实值 X，测量误差 ε ~ N(0, σ²)
  • 测量值 Y = X + ε
  • Y 仍服从正态分布，均值为 X，方差为 σ²

📝 总结

1. 离散型：列举所有可能的 y 值，合并对应的概率
2. 连续型（CDF法）：F_Y(y) → 求导 → f_Y(y)
3. 连续型（公式法）：单调函数可用 f_Y(y) = f_X(h(y)) · |h'(y)|
4. 特殊情况：正态分布的线性变换仍是正态分布
