🔬 假设检验扩展

正态总体参数检验与p值

📊 正态总体均值的假设检验

1. 方差已知：Z检验

条件：X₁, ..., Xₙ ~ N(μ, σ²)，σ² 已知
假设：H₀: μ = μ₀ vs H₁: μ ≠ μ₀
检验统计量：Z = (X̄ - μ₀) / (σ/√n) ~ N(0,1)
拒绝域：|Z| > z_{α/2}

💡 例子：食品包装重量检验

声称平均重量500g，已知σ=10g，抽16包，平均495g

H₀: μ = 500 vs H₁: μ ≠ 500

Z = (495-500)/(10/4) = -2

|Z| = 2 > 1.96 = z₀.₀₂₅

结论：拒绝H₀，平均重量显著不等于500g

2. 方差未知：t检验

条件：X₁, ..., Xₙ ~ N(μ, σ²)，σ² 未知
假设：H₀: μ = μ₀ vs H₁: μ ≠ μ₀
检验统计量：T = (X̄ - μ₀) / (S/√n) ~ t(n-1)
拒绝域：|T| > t_{α/2}(n-1)

3. 成对数据的t检验

场景：比较同一组对象在两个条件下的差异
方法：计算差值 dᵢ = Xᵢ - Yᵢ，对 dᵢ 做单样本t检验
统计量：T = d̄ / (S_d/√n) ~ t(n-1)

💡 例子：减肥产品效果检验

10人使用减肥产品前后体重对比

差值：前后体重差 = 使用前 - 使用后

H₀: μ_d = 0（无效）vs H₁: μ_d > 0（有效）

📏 正态总体方差的假设检验

条件：X₁, ..., Xₙ ~ N(μ, σ²)
假设：H₀: σ² = σ₀² vs H₁: σ² ≠ σ₀²
检验统计量：χ² = (n-1)S²/σ₀² ~ χ²(n-1)
拒绝域：χ² < χ²_{1-α/2}(n-1) 或 χ² > χ²_{α/2}(n-1)

💡 例子：生产过程稳定性检验

要求产品方差不超过0.01，抽25个产品，S²=0.015

H₀: σ² = 0.01 vs H₁: σ² > 0.01

χ² = 24×0.015/0.01 = 36

临界值：χ²₀.₀₅(24) = 36.415

36 < 36.415，接受H₀，方差符合要求

两个正态总体方差的比较：F检验

条件：X₁, ..., Xₙ ~ N(μ₁, σ₁²)，Y₁, ..., Yₘ ~ N(μ₂, σ₂²)
假设：H₀: σ₁² = σ₂² vs H₁: σ₁² ≠ σ₂²
检验统计量：F = S₁²/S₂² ~ F(n-1, m-1)
拒绝域：F > F_{α/2}(n-1, m-1) 或 F < F_{1-α/2}(n-1, m-1)

🎯 假设检验的p值

p值的定义：在H₀为真的条件下，观察到当前或更极端样本的概率
决策规则：如果 p < α，拒绝 H₀
优势：不需要查表，直接给出显著性水平

不同检验的p值计算

检验类型 统计量 p值（双尾）
Z检验 Z = z₀ p = 2 × P(Z > |z₀|)
t检验 T = t₀ p = 2 × P(T > |t₀|)
χ²检验 χ² = χ₀² p = 2 × min{P(χ² < χ₀²), P(χ² > χ₀²)}

💡 p值的直观理解

p = 0.03：在H₀为真时，只有3%的概率观察到这样的数据

p = 0.23：即使H₀为真，也有23%的概率观察到这样的数据

决策：p = 0.03 < 0.05 → 拒绝H₀

              p = 0.23 > 0.05 → 接受H₀

📐 样本容量的选择

问题：给定显著性水平α和功效1-β，需要多大的样本量？

Z检验的样本量公式：
n = [(z_{α/2} + z_β) × σ / Δ]²

其中：
• Δ = 我们希望检测出的最小差异（效应大小）
• α = 第一类错误概率（显著性水平）
• β = 第二类错误概率
• 1-β = 功效（正确拒绝错误H₀的概率）

💡 例子：药物疗效试验

想检测出至少5mmHg的血压降低效果（Δ=5）

已知σ=15，α=0.05，功效=80%（β=0.2）

z_{α/2} = 1.96，z_β = 0.84

n = [(1.96 + 0.84) × 15 / 5]² ≈ 56

需要至少56人参与试验

影响样本量的因素

因素 影响 原因
效应大小 Δ Δ越小，n越大 检测小差异需要更多数据
显著性 α α越小，n越大 更严格的标准需要更多证据
功效 1-β 功效越大，n越大 降低第二类错误需要更多数据
方差 σ² σ²越大，n越大 数据越分散，需要更多样本

📊 分布拟合检验

χ²拟合优度检验

目的：检验样本是否来自某个理论分布
假设：H₀: 样本来自分布F₀ vs H₁: 样本不来自F₀
步骤：
① 将数据分成k个区间
② 计算每个区间的观测频数 Oᵢ
③ 计算每个区间的理论频数 Eᵢ = n × pᵢ
④ 计算统计量：χ² = Σᵢ₌₁ᵏ (Oᵢ - Eᵢ)²/Eᵢ
拒绝域：χ² > χ²_{α}(k-r-1)
其中r是被估计的参数个数

💡 例子：骰子是否均匀

掷骰子600次，各面出现次数：
1面:85, 2面:105, 3面:95, 4面:100, 5面:110, 6面:105

如果骰子均匀，每个面期望出现100次

χ² = Σ(Oᵢ-100)²/100 = (85-100)²/100 + ... = 5.5

临界值：χ²₀.₀₅(5) = 11.07

5.5 < 11.07，接受H₀，骰子是均匀的

正态性检验

Shapiro-Wilk检验：适用于小样本（n < 50）
Kolmogorov-Smirnov检验：适用于大样本
Q-Q图：图形化检验，数据点应近似落在直线上

📝 总结

1. 均值检验：Z检验（σ已知）、t检验（σ未知）
2. 方差检验：χ²检验（单个方差）、F检验（两个方差）
3. p值：观察到当前或更极端数据的概率，p < α时拒绝H₀
4. 样本量选择：考虑效应大小、显著性、功效、方差
5. 分布拟合检验：χ²检验判断数据是否符合理论分布
6. 实际应用：质量控制、医学试验、市场调研等
