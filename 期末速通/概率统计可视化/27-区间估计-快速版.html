📏 区间估计与单侧置信区间

第七章：从点估计到区间估计

📖 区间估计的基本概念

点估计 vs 区间估计：
• 点估计：θ̂ = 5.2（给出一个数值）
• 区间估计：θ ∈ [4.8, 5.6]（给出一个范围）

置信区间（Confidence Interval, CI）：
随机区间 [θ̂_L, θ̂_U]，满足 P(θ ∈ [θ̂_L, θ̂_U]) = 1 - α
其中 1-α 称为置信水平（Confidence Level）

💡 直观理解

民意调查："支持率在48%-52%之间（95%置信水平）"

含义：如果重复调查100次，大约有95次，真实支持率会落在[48%,52%]内

注意：不是说"真实支持率有95%的概率在这个区间"，而是"这个方法有95%的概率覆盖真值"

常用置信水平

置信水平 1-α α 临界值 z_{α/2} 应用场景
90% 0.10 1.645 初步探索、容忍不确定性
95% 0.05 1.960 最常用、科学研究的标准
99% 0.01 2.576 高风险决策、医学试验

📊 正态总体均值的区间估计

方差 σ² 已知：Z区间

条件：X₁, ..., Xₙ ~ N(μ, σ²)，σ² 已知

枢轴量（Pivot）：Z = (X̄ - μ) / (σ/√n) ~ N(0,1)

置信区间：
μ ∈ [X̄ - z_{α/2} · σ/√n, X̄ + z_{α/2} · σ/√n]

缩写：X̄ ± z_{α/2} · σ/√n

💡 例子：食品包装重量

声称平均重量500g，已知σ=10g，抽n=16，X̄=495g

95%置信区间：

495 ± 1.96 × 10/4

= 495 ± 4.9

= [490.1, 499.9]

结论：500不在区间内，平均重量显著小于500g

方差 σ² 未知：t区间

条件：X₁, ..., Xₙ ~ N(μ, σ²)，σ² 未知

枢轴量：T = (X̄ - μ) / (S/√n) ~ t(n-1)

置信区间：
μ ∈ [X̄ - t_{α/2}(n-1) · S/√n, X̄ + t_{α/2}(n-1) · S/√n]

缩写：X̄ ± t_{α/2}(n-1) · S/√n

💡 例子：学生成绩

抽样n=25个学生，平均分X̄=78，标准差S=10

95%置信区间：

自由度 = n-1 = 24

t_{0.025}(24) = 2.064

78 ± 2.064 × 10/5

= 78 ± 4.13

= [73.87, 82.13]

注意：用t分布比Z分布更宽（更保守）

为什么用t分布？
• σ未知时用S估计，增加了不确定性
• t分布比正态分布更"扁平"，尾部更厚
• 当n→∞时，t分布收敛于正态分布

📏 正态总体方差的区间估计

条件：X₁, ..., Xₙ ~ N(μ, σ²)

枢轴量：χ² = (n-1)S²/σ² ~ χ²(n-1)

置信区间：
σ² ∈ [(n-1)S²/χ²_{α/2}(n-1), (n-1)S²/χ²_{1-α/2}(n-1)]

💡 例子：生产过程稳定性

抽样n=25个产品，S²=0.015

95%置信区间：

自由度 = 24

χ²_{0.975}(24) = 12.401

χ²_{0.025}(24) = 39.364

下限 = 24×0.015/39.364 = 0.0091

上限 = 24×0.015/12.401 = 0.0290

σ² ∈ [0.0091, 0.0290]

σ ∈ [0.095, 0.170]

📊 0-1分布参数p的区间估计

条件：X ~ B(n, p)，X是成功次数

点估计：p̂ = X/n

大样本置信区间（正态近似）：
p ∈ [p̂ - z_{α/2} · √[p̂(1-p̂)/n], p̂ + z_{α/2} · √[p̂(1-p̂)/n]]

💡 例子：选举民意调查

调查n=1000人，X=520人支持候选人A

点估计：p̂ = 520/1000 = 0.52

标准误差：SE = √(0.52×0.48/1000) = 0.0158

95%置信区间：

0.52 ± 1.96 × 0.0158

= 0.52 ± 0.031

= [0.489, 0.551]

结论：我们有95%的信心认为真实支持率在48.9%到55.1%之间

小样本情况（n < 30）：
使用 Clopper-Pearson 精确区间或 Wilson 得分区间

Wilson 得分区间（推荐）：
p ∈ [p̃ - z_{α/2}·√[p̂(1-p̂)/n + z²/(4n²)], p̃ + z_{α/2}·√[p̂(1-p̂)/n + z²/(4n²)]]
其中 p̃ = (p̂ + z²/(2n)) / (1 + z²/n)

⬆️⬇️ 单侧置信区间

为什么需要单侧？
有时我们只关心上限或下限，不需要双侧

上置信界（Upper Confidence Bound）：
P(μ ≤ μ̄) = 1 - α
μ ≤ X̄ + z_α · σ/√n（正态，σ²已知）

下置信界（Lower Confidence Bound）：
P(μ ≥ μ̲) = 1 - α
μ ≥ X̄ - z_α · σ/√n

💡 应用场景：产品质量保证

情景：需要证明产品平均寿命至少为1000小时

方法：使用单侧置信下界

结果：μ̲ = 1050小时（95%置信下界）

结论：我们有95%的信心认为真实平均寿命 ≥ 1050 > 1000 ✓

优势：单侧区间比双侧更窄，更容易通过检验

类型 双侧区间 单侧上界 单侧下界
形式 [L, U] (-∞, U] [L, +∞)
使用 估计参数范围 "不超过多少" "至少有多少"
临界值 z_{α/2} z_α z_α
例子 μ ∈ [490, 510] μ ≤ 508 μ ≥ 492

单侧 vs 双侧的选择

使用单侧区间：
• 质量控制：寿命 ≥ 某值，缺陷率 ≤ 某值
• 环境监测：污染物含量 ≤ 某值
• 金融风险：VaR（在险价值）≤ 某值

使用双侧区间：
• 一般性的参数估计
• 需要同时知道上限和下限
• 不确定方向的情况

⚠️ 置信区间的正确解释

❌ 常见误解

  • "真实参数有95%的概率在这个区间内" → 错误！
  • "这个区间包含真实参数的概率是95%" → 错误！

✅ 正确理解

  • "这个方法有95%的概率产生包含真值的区间"
  • "如果我们重复抽样100次，大约有95次，区间会包含真值"
  • "置信水平是方法的可靠程度，不是特定区间的概率"

贝叶斯学派 vs 频率学派

方面 频率学派（置信区间） 贝叶斯学派（可信区间）
参数 固定的未知常数 随机变量，有分布
区间 随机的 固定的
解释 方法的可靠程度 参数在区间内的概率
例子 "95%的区间会覆盖真值" "参数有95%概率在这个区间"

🔢 样本量的确定

问题：给定精度Δ和置信水平1-α，需要多大的样本量？

均值估计的样本量公式：
n = (2 · z_{α/2} · σ / Δ)²

其中 Δ = 允许的误差范围（区间宽度的一半）

💡 例子：确定调查样本量

希望误差不超过±3%，置信水平95%，已知σ≈0.5

n = (2 × 1.96 × 0.5 / 0.03)²

= (3.267 / 0.03)²

= 108.9² ≈ 1068

结论：需要至少1068个样本

比例估计的样本量公式：
n = z_{α/2}² · p(1-p) / Δ²

最保守估计（p=0.5时方差最大）：
n = z_{α/2}² · 0.25 / Δ² = (z_{α/2} / 2Δ)²

📝 总结

1. 区间估计：给出参数的可能范围，带有置信水平
2. 置信水平：1-α，常用95%，表示方法的可靠程度
3. 均值区间：σ已知用Z，σ未知用t
4. 单侧区间：用于"不超过"或"至少"的情况，区间更窄
5. 正确解释：是"方法的可靠程度"，不是"参数的概率"
6. 样本量：根据精度要求和置信水平计算
