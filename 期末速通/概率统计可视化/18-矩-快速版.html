📐 矩（原点矩与中心矩）

描述随机变量分布特征的数字特征

📖 基本定义

k阶原点矩（origin moment）：
离散型：μ_k = E(X^k) = Σ x_i^k · p_i
连续型：μ_k = E(X^k) = ∫(-∞ to +∞) x^k · f(x) dx
k阶中心矩（central moment）：
ν_k = E[(X-μ)^k] = ∫(-∞ to +∞) (x-μ)^k · f(x) dx
其中 μ = E(X) 是期望
类型 定义 k=1 k=2 k=3 k=4
原点矩 μ_k E(X^k) μ = E(X) E(X²) E(X³) E(X⁴)
中心矩 ν_k E[(X-μ)^k] 0 σ² = Var(X) 偏度相关 峰度相关

💡 中心矩的重要性

  • k=1：ν₁ = E(X-μ) = 0（恒成立）
  • k=2：ν₂ = σ² = 方差，衡量分布的离散程度
  • k=3：ν₃ 与偏度有关，描述分布的对称性
  • k=4：ν₄ 与峰度有关，描述分布的尖锐程度

📈 偏度与峰度（高阶中心矩的应用）

特征 定义 正态分布的值 意义
偏度（Skewness） γ₁ = ν₃ / σ³ 0 >0：右偏（正偏）
=0：对称
<0：左偏（负偏）
峰度（Kurtosis） γ₂ = ν₄ / σ⁴ - 3 0 >0：尖峰（比正态分布陡峭）
=0：与正态分布相同
<0：低峰（比正态分布平坦）

不同分布的形状对比

偏度对比：对称 vs 偏态分布

峰度对比：不同尖锐程度

🔄 原点矩与中心矩的关系

重要公式：
ν_k = E[(X-μ)^k] = Σ[i=0 to k] C(k,i) · (-μ)^(k-i) · μ_i

特例：
ν₁ = 0
ν₂ = μ₂ - μ₁² = E(X²) - [E(X)]² = σ²
ν₃ = μ₃ - 3μ₁μ₂ + 2μ₁³

💡 为什么需要矩？

  • 矩估计法：用样本矩估计总体矩，从而估计参数
  • 描述分布：前几阶矩可以很好地描述分布的特征
  • 唯一性定理：如果所有矩都存在且相等，则分布相同

🎯 实际应用

1. 矩估计法（Method of Moments）

步骤：

  1. 计算总体的前k阶矩：μ₁(θ), μ₂(θ), ..., μ_k(θ)
  2. 计算样本的前k阶矩：m₁, m₂, ..., m_k
  3. 令 μ_i(θ) = m_i，解方程组得到参数估计值

2. 金融中的矩

  • 一阶矩（均值）：预期收益
  • 二阶矩（方差）：风险度量
  • 三阶矩（偏度）：收益分布的不对称性
  • 四阶矩（峰度）：极端风险（尾部风险）

📝 总结

1. 原点矩 μ_k = E(X^k)：关于原点的k阶矩，k=1是期望
2. 中心矩 ν_k = E[(X-μ)^k]：关于均值的k阶矩，k=2是方差
3. 偏度和峰度：三阶和四阶中心矩的应用，描述分布形状
4. 矩估计：用样本矩估计总体参数的常用方法
5. 应用：金融、统计学、机器学习等多个领域
