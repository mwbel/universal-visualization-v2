📊 常用统计量

从样本数据计算出的用于推断总体特征的数值

📖 基本概念

统计量（Statistic）：样本的函数，不包含任何未知参数
样本：X₁, X₂, ..., Xₙ（从总体中随机抽取的n个观测值）
总体：研究对象的全体，通常服从某个分布 F(x)

💡 统计量的作用

  • 估计参数：用样本均值估计总体均值
  • 假设检验：用检验统计量做决策
  • 描述数据：概括样本的特征

📈 常用统计量表

统计量名称 定义公式 用途 对应总体参数
样本均值 X̄ = (1/n) Σ Xᵢ 估计总体均值 μ = E(X)
样本方差 S² = (1/(n-1)) Σ (Xᵢ - X̄)² 估计总体方差 σ² = Var(X)
样本标准差 S = √S² 衡量数据离散程度 σ = √Var(X)
样本k阶矩 Aₖ = (1/n) Σ Xᵢᵏ 矩估计法 μₖ = E(Xᵏ)
样本k阶中心矩 Bₖ = (1/n) Σ (Xᵢ - X̄)ᵏ 估计偏度、峰度 νₖ = E[(X-μ)ᵏ]
样本偏度 G₁ = B₃ / S³ 衡量对称性 γ₁ = ν₃ / σ³
样本峰度 G₂ = B₄ / S⁴ - 3 衡量尖锐程度 γ₂ = ν₄ / σ⁴ - 3
次序统计量 X₍₁₎ ≤ X₍₂₎ ≤ ... ≤ X₍ₙ₎ 分位数、极值 -
样本中位数 ~X = X₍[(n+1)/2]₎ 中心位置（抗异常值） 中位数

🔍 重要的统计量详解

1. 样本均值 X̄

定义：X̄ = (1/n) Σᵢ₌₁ⁿ Xᵢ
性质：
• E(X̄) = μ（无偏性）
• Var(X̄) = σ²/n（样本量越大，方差越小）
• X̄ ~ N(μ, σ²/n)（当总体正态或n大时）

2. 样本方差 S²

定义：S² = (1/(n-1)) Σᵢ₌₁ⁿ (Xᵢ - X̄)²
为什么除以 n-1 而不是 n？
• 为了保证无偏性：E(S²) = σ²
• 如果除以 n，会低估真实的方差
• n-1 称为自由度

💡 自由度的直观理解

有n个数X₁, X₂, ..., Xₙ，当X̄已知时，只有n-1个数可以自由变化

例如：3个数均值为5，已知前两个数是3和7，第三个数必然是5

3. 次序统计量

定义：将样本按从小到大排序：X₍₁₎ ≤ X₍₂₎ ≤ ... ≤ X₍ₙ₎
应用：
• 样本中位数：~X = X₍[(n+1)/2]₎
• 极差：R = X₍ₙ₎ - X₍₁₎（衡量离散程度）
• 四分位数：Q₁ = X₍[n/4]₎，Q₃ = X₍[3n/4]₎

📊 统计量的分布

样本均值的抽样分布

定理：若 X₁, ..., Xₙ ~ N(μ, σ²)
则 X̄ ~ N(μ, σ²/n)

标准化：Z = (X̄ - μ) / (σ/√n) ~ N(0,1)

样本方差的分布

定理：若 X₁, ..., Xₙ ~ N(μ, σ²)
则 (n-1)S²/σ² ~ χ²(n-1)

推论：S² 与 X̄ 相互独立（正态总体）

t 统计量

定义：T = (X̄ - μ) / (S/√n)
分布：T ~ t(n-1)（当总体正态时）
用途：小样本情况下对均值的推断

🎯 统计量的性质

性质 定义 直观含义 例子
无偏性 E(θ̂) = θ 估计量的期望等于真实值 X̄ 是 μ 的无偏估计
有效性 Var(θ̂₁) < Var(θ̂₂) 方差越小越精确 X̄ 比 ~X 更有效
一致性 θ̂ →p θ 样本量增大时收敛于真实值 X̄ 依概率收敛于 μ
充分性 包含所有信息 不丢失样本中的信息 X̄ 对 μ 是充分的

💡 实际应用

1. 质量控制

从生产线上抽取n个产品，计算样本均值X̄和标准差S

如果 X̄ 超出控制限（μ ± 3σ/√n），则报警

2. 民意调查

调查n个选民，支持率 p̂ = k/n（k是支持人数）

估计误差 = 1.96 × √[p̂(1-p̂)/n]

3. 金融风险

用历史收益率计算样本均值和标准差

VaR（在险价值）= X̄ - 1.65 × S（95%置信水平）

📝 总结

1. 统计量：样本的函数，不含未知参数
2. 核心统计量：样本均值 X̄、样本方差 S²、次序统计量
3. 重要性质：无偏性、有效性、一致性、充分性
4. 抽样分布：X̄ ~ N(μ, σ²/n)、(n-1)S²/σ² ~ χ²(n-1)
5. 应用：参数估计、假设检验、质量控制等
