# ⚡ 页面加载速度优化方案

## 🔍 问题分析

### 当前加载速度慢的原因

1. **Plotly.js** (约3MB)
   - 当前使用CDN: `https://cdn.staticfile.org/plotly.js/2.26.0/plotly.min.js`
   - 从国外CDN加载，网络延迟高

2. **MathJax** (约1MB)
   - 当前使用CDN: `https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js`
   - 从国外CDN加载

3. **总下载量**: 约4MB+
4. **预期加载时间**: 5-15秒（取决于网络）

---

## 🚀 解决方案

### 方案一：使用国内CDN镜像（推荐⭐⭐⭐⭐⭐）

**优点**:
- ✅ 无需修改代码
- ✅ 立即见效
- ✅ 速度快

**实施方法**:

修改所有HTML文件中的CDN链接：

```html
<!-- Plotly.js - 使用阿里云CDN -->
<script src="https://cdn.bootcdn.net/ajax/libs/plotly.js/2.26.0/plotly.min.js" defer></script>

<!-- MathJax - 使用阿里云CDN -->
<script id="MathJax-script" defer
        src="https://cdn.bootcdn.net/ajax/libs/mathjax/3.2.2/es5/tex-mml-chtml.js">
</script>
```

### 方案二：下载到本地（推荐⭐⭐⭐⭐）

**优点**:
- ✅ 完全离线可用
- ✅ 最快速度
- ✅ 不依赖网络

**实施步骤**:

```bash
# 1. 创建资源目录
mkdir -p lib

# 2. 下载Plotly.js
curl -o lib/plotly.min.js https://cdn.bootcdn.net/ajax/libs/plotly.js/2.26.0/plotly.min.js

# 3. 下载MathJax
curl -o lib/tex-mml-chtml.js https://cdn.bootcdn.net/ajax/libs/mathjax/3.2.2/es5/tex-mml-chtml.js

# 或者使用wget
wget -O lib/plotly.min.js https://cdn.bootcdn.net/ajax/libs/plotly.js/2.26.0/plotly.min.js
wget -O lib/tex-mml-chtml.js https://cdn.bootcdn.net/ajax/libs/mathjax/3.2.2/es5/tex-mml-chtml.js
```

修改HTML文件：

```html
<!-- 使用本地资源 -->
<script src="lib/plotly.min.js" defer></script>
<script id="MathJax-script" defer src="lib/tex-mml-chtml.js"></script>
```

### 方案三：懒加载（推荐⭐⭐⭐）

**优点**:
- ✅ 页面先显示，后加载图表
- ✅ 改善用户体验

**实施方法**:

```javascript
// 检测用户是否滚动到可视化区域
const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
        if (entry.isIntersecting) {
            loadPlotly(); // 加载Plotly
            observer.disconnect();
        }
    });
});

observer.observe(document.getElementById('plot'));
```

### 方案四：使用更轻量的替代库

**考虑使用**:
- **Chart.js** (200KB) - 替代Plotly
- **KaTeX** (50KB) - 替代MathJax

## 🛠️ 快速修复脚本

创建一个脚本自动替换所有HTML文件的CDN链接：

```bash
#!/bin/bash
# fix-cdn.sh

echo "🔄 替换为国内CDN..."

# 替换Plotly
find . -name "*.html" -type f -exec sed -i '' \
  's|https://cdn.staticfile.org/plotly.js/|https://cdn.bootcdn.net/ajax/libs/plotly.js/|g' \
  {} \;

# 替换MathJax
find . -name "*.html" -type f -exec sed -i '' \
  's|https://cdn.jsdelivr.net/npm/mathjax@3/|https://cdn.bootcdn.net/ajax/libs/mathjax/3.2.2/|g' \
  {} \;

echo "✅ 完成！"
```

运行：

```bash
chmod +x fix-cdn.sh
./fix-cdn.sh
```
