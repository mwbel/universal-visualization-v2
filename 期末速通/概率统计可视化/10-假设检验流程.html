假设检验完整流程可视化

📖 一言以蔽之

假设检验：用样本数据判断对总体的"假设"是否成立。本质是小概率反证法——如果在假设成立的前提下，出现了极小概率事件，则拒绝该假设。

🛠️ 核心思想

  • 反证法：假设H₀成立，看是否出现矛盾
  • 小概率原理：概率<α的事件在一次试验中几乎不可能发生
  • 决策规则：如果p值<α，拒绝H₀；否则不拒绝H₀
  • 两类错误：可能犯错，但可以控制犯错概率

📐 基本概念

原假设 H₀：通常代表"无差异"、"无效"、"随机"等现状（如：μ = μ₀）
备择假设 H₁：研究者想证明的结论（如：μ ≠ μ₀, μ > μ₀, μ < μ₀）
显著性水平 α：第一类错误的概率上限（常用0.05, 0.01）
p值：在H₀成立时，出现当前或更极端样本的概率
拒绝域：导致拒绝H₀的检验统计量取值范围

📋 假设检验五步流程

1 提出假设

原假设 H₀：μ = μ₀（声称的值）

备择假设 H₁：

  • • 双侧：μ ≠ μ₀（"有差异"）
  • • 右侧：μ > μ₀（"大于"）
  • • 左侧：μ < μ₀（"小于"）
2 选择检验统计量

根据已知条件选择：

  • σ已知，大样本 → z统计量：$$z = \frac{\bar{x} - \mu_0}{\sigma/\sqrt{n}}$$
  • σ未知，小样本 → t统计量：$$t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}$$
  • 比例检验：$$z = \frac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}}$$
3 确定拒绝域

根据显著性水平α和检验类型：

  • 双侧检验：拒绝域 = {|z| > zₐ/₂}
  • 右侧检验：拒绝域 = {z > zₐ}
  • 左侧检验：拒绝域 = {z < -zₐ}
4 计算检验统计量和p值

根据样本数据计算统计量，查表或计算p值

p值 = P(在H₀成立时，出现当前或更极端的统计量)
5 做出决策

方法1（p值法）：

  • p值 < α → 拒绝H₀，支持H₁
  • p值 ≥ α → 不拒绝H₀（证据不足）

方法2（临界值法）：

  • 统计量落入拒绝域 → 拒绝H₀
  • 统计量未落入拒绝域 → 不拒绝H₀

⚠️ 两类错误（Type I & Type II Errors）

假设检验可能犯两种错误，理解它们对正确解读结果至关重要。

α = 0.05 μ = 0.60

第一类错误（Type I Error）

定义：H₀为真，但拒绝了H₀

概率：P(拒绝H₀ | H₀为真) = α

别名：假阳性（False Positive）

例子：无罪的人被判有罪

控制：可以通过设置α来控制（通常≤0.05）

α = 0.05

第二类错误（Type II Error）

定义：H₀为假，但不拒绝H₀

概率：P(不拒绝H₀ | H₀为假) = β

别名：假阴性（False Negative）

例子：有罪的人被判无罪

相关概念：功效 = 1 - β（正确拒绝H₀的概率）

💡 权衡关系

  • 此消彼长：在样本量固定时，α减小会导致β增大（反之亦然）
  • 同时减小：只有增大样本量n，才能同时减小α和β
  • 实践建议：将严重的错误设为第一类错误，严格控制α
  • 药物检验：α=0.05（假阳性风险），β=0.20（功效80%）

💡 p值解读要点

  • p值不是H₀为真的概率！P(H₀|数据) ≠ P(数据|H₀)
  • p值越小：数据与H₀的矛盾越大，证据越强
  • 阈值α：p<α表示"在H₀下，当前数据几乎不可能出现"
  • ≠效应大小：大样本下，微小差异也能得到极小的p值
  • 二值思维：不要只看p<0.05是否成立，要关注实际意义

📈 功效函数曲线（Power Function）

功效 = 1 - β，展示检验在不同真实参数值下正确拒绝H₀的能力。

n = 30 σ = 1.0

💡 功效分析要点

  • 功效曲线：真实μ离μ₀越远，功效越高（越容易检测出差异）
  • 样本量影响：n增大，功效曲线变陡，检验更敏感
  • 设计实验：实验前应做功效分析，确定需要的样本量
  • 目标功效：通常要求功效≥0.80（β≤0.20）
  • 实际应用：如果功效太低（<0.50），"不显著"可能只是样本不足

📝 实践建议

  • 不要过度依赖p值：大样本下，微小差异也能"显著"
  • 报告效应大小：除了p值，还要报告置信区间和效应量（Cohen's d等）
  • 先做功效分析：实验前计算需要的样本量，避免资源浪费
  • 解释"不显著"：可能真的没有差异，也可能是样本不足、功效太低

🎯 常见假设检验选择指南

检验名称 应用场景 检验统计量 条件
单样本z检验 已知σ，检验均值 z = (x̄ - μ₀) / (σ/√n) 正态总体或n≥30
单样本t检验 未知σ，检验均值 t = (x̄ - μ₀) / (s/√n) 正态总体
两独立样本t检验 比较两组均值 t = (x̄₁ - x̄₂) / SE 正态、方差齐性
配对t检验 前后对比/配对数据 t = d̄ / (s_d/√n) 差值正态
比例检验 检验总体比例 z = (p̂ - p₀) / √(p₀(1-p₀)/n) np₀≥5, n(1-p₀)≥5
卡方检验 拟合优度/独立性 χ² = Σ(O-E)²/E 期望频数≥5
方差分析（ANOVA） 比较多组均值 F = MS_between / MS_within 正态、方差齐性
