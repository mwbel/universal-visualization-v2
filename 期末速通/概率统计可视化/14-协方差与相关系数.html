理解两个随机变量之间的线性关系强度和方向

核心公式：
协方差：Cov(X,Y) = E[(X - μₓ)(Y - μᵧ)] = E(XY) - E(X)E(Y)
相关系数：ρ = Cov(X,Y) / (σₓ · σᵧ)，范围[-1, 1]
含义：ρ > 0 正相关，ρ < 0 负相关，ρ = 0 无线性相关

💡 协方差与相关系数解读

  • 协方差 Cov(X,Y)：衡量两个变量协同变化的程度
    • > 0：X增大时Y倾向于增大
    • < 0：X增大时Y倾向于减小
    • = 0：无线性关系
  • 相关系数 ρ：标准化的协方差，更易解释
    • ρ ≈ 1：强正相关，点几乎在一条直线上（正相关）
    • ρ ≈ -1：强负相关，点几乎在一条直线上（负相关）
    • ρ ≈ 0：无线性相关，点分散无规律
    • |ρ| > 0.7：强相关；|ρ| < 0.3：弱相关
  • 注意：相关系数只衡量线性关系，不反映非线性关系
