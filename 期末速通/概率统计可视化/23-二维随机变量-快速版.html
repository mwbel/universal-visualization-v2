📊 二维随机变量

第三章：多维随机变量的基础

📖 基本概念

定义：设 X, Y 是两个随机变量，(X, Y) 称为二维随机向量
联合分布函数：F(x,y) = P(X ≤ x, Y ≤ y)
性质：
1. F(x,y) 对每个变量单调不减
2. 0 ≤ F(x,y) ≤ 1
3. F(+∞,+∞) = 1, F(-∞,y) = 0, F(x,-∞) = 0

离散型 vs 连续型

类型 联合分布 概率/密度
离散型 联合分布律 p_{ij} = P(X=x_i, Y=y_j) Σ_i Σ_j p_{ij} = 1
连续型 联合概率密度 f(x,y) ∫∫ f(x,y)dxdy = 1

🎲 离散型二维随机变量

联合分布律：p_{ij} = P(X=x_i, Y=y_j)

表格表示：
     Y=y₁ Y=y₂ ...
X=x₁ [ p₁₁ p₁₂ ... ]
X=x₂ [ p₂₁ p₂₂ ... ]
...  [ ... ... ... ]

💡 例子：抛两次硬币

X = 第一次是否正面（1=正，0=反）

Y = 第二次是否正面（1=正，0=反）

X\Y 0 1 P(X=x_i)
0 1/4 1/4 1/2
1 1/4 1/4 1/2
P(Y=y_j) 1/2 1/2 1

📈 连续型二维随机变量

联合概率密度：f(x,y)
性质：
1. f(x,y) ≥ 0
2. ∫_{-∞}^{+∞}∫_{-∞}^{+∞} f(x,y)dxdy = 1
3. P((X,Y) ∈ D) = ∫∫_D f(x,y)dxdy

二维均匀分布

定义：在区域 D 上均匀分布
f(x,y) = { 1/A, (x,y) ∈ D; 0, 其他 }
其中 A 是区域 D 的面积

二维正态分布

符号：(X,Y) ~ N(μ₁, μ₂, σ₁², σ₂², ρ)

密度函数：
f(x,y) = [1/(2πσ₁σ₂√(1-ρ²))] × exp{-1/[2(1-ρ²)] ×
    [((x-μ₁)²/σ₁²) - 2ρ(x-μ₁)(y-μ₂)/(σ₁σ₂) + ((y-μ₂)²/σ₂²)]}

💡 二维正态分布的性质

  • 边缘分布：X ~ N(μ₁, σ₁²)，Y ~ N(μ₂, σ₂²)
  • 独立性：ρ = 0 时 X, Y 独立
  • 形状："钟形"曲面，峰点在 (μ₁, μ₂)

📊 边缘分布

离散型边缘分布：
P(X=x_i) = Σ_j p_{ij}（按行求和）
P(Y=y_j) = Σ_i p_{ij}（按列求和）

连续型边缘分布：
f_X(x) = ∫_{-∞}^{+∞} f(x,y)dy
f_Y(y) = ∫_{-∞}^{+∞} f(x,y)dx

💡 直观理解

边缘分布是"忽略"另一个变量后的分布

例如：调查人群的(身高，体重)联合分布

  • 身高的边缘分布 = 无论体重如何，身高的分布
  • 体重的边缘分布 = 无论身高如何，体重的分布

🔍 条件分布

离散型条件分布：
P(X=x_i | Y=y_j) = p_{ij} / P(Y=y_j) = p_{ij} / Σ_i p_{ij}

连续型条件分布：
f(x|y) = f(x,y) / f_Y(y)
f(y|x) = f(x,y) / f_X(x)

💡 例子：考试分数

X = 数学成绩，Y = 物理成绩

  • f(x|y=85) = 在物理85分的条件下，数学成绩的分布
  • 这反映了数学和物理成绩的相关性

🔗 相互独立的随机变量

定义：X, Y 独立 ⇔ F(x,y) = F_X(x) · F_Y(y)

等价条件：
离散型：p_{ij} = P(X=x_i) · P(Y=y_j)，对所有i,j
连续型：f(x,y) = f_X(x) · f_Y(y)

独立性的判断

条件 结论
联合分布 = 边缘分布的乘积 ✅ 独立
联合分布 ≠ 边缘分布的乘积 ❌ 不独立
协方差 Cov(X,Y) = 0 ⚠️ 不相关（独立⇒不相关，但不相关⇒独立）

💡 重要例子

独立：抛硬币两次的结果

不独立：人的身高和体重

不相关但不独立：X ~ U(-1,1)，Y = X²

    （Cov(X,Y)=0，但Y完全由X决定）

🔄 两个随机变量的函数的分布

1. 和的分布 Z = X + Y

离散型（卷积公式）：
P(Z=z) = Σ_x P(X=x, Y=z-x)

连续型：
f_Z(z) = ∫_{-∞}^{+∞} f(x, z-x)dx

💡 重要结论

  • 正态分布：若 X~N(μ₁,σ₁²)，Y~N(μ₂,σ₂²) 独立
  •               则 X+Y ~ N(μ₁+μ₂, σ₁²+σ₂²)
  • 泊松分布：若 X~Poisson(λ₁)，Y~Poisson(λ₂) 独立
  •               则 X+Y ~ Poisson(λ₁+λ₂)

2. 最大值的分布 M = max(X,Y)

分布函数：F_M(m) = P(M ≤ m) = P(X ≤ m, Y ≤ m) = F(m,m)
独立时：F_M(m) = F_X(m) · F_Y(m)

3. 最小值的分布 N = min(X,Y)

分布函数：F_N(n) = P(N ≤ n) = 1 - P(N > n) = 1 - P(X > n, Y > n)
独立时：F_N(n) = 1 - [1-F_X(n)][1-F_Y(n)]

可视化：和、最大值、最小值的分布

Z = X + Y 的分布

M = max(X,Y) 的分布

📝 总结

1. 二维随机变量：(X,Y)的联合分布函数F(x,y)=P(X≤x,Y≤y)
2. 边缘分布：通过积分/求和，从联合分布得到单个变量的分布
3. 条件分布：在已知一个变量的条件下，另一个变量的分布
4. 独立性：f(x,y)=f_X(x)·f_Y(y)，独立的变量不提供彼此的信息
5. 函数的分布：卷积公式求和，独立时max/min有简化公式
6. 重要应用：金融（多资产组合）、工程（系统可靠性）、统计（回归分析）
