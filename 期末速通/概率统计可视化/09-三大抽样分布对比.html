📊 三大抽样分布

期末速通 / 概率统计 / 三大抽样分布

三大抽样分布对比可视化

📖 一言以蔽之

三大抽样分布：从正态总体抽样时产生的三种重要分布——χ²分布、t分布、F分布。它们是统计推断的基石！

🛠️ 应用场景

  • χ²分布：方差估计、拟合优度检验、列联表分析
  • t分布：小样本均值检验、回归系数显著性检验
  • F分布：方差分析（ANOVA）、方差齐性检验

📐 与正态分布的关系

设 $X_1, X_2, \ldots, X_n$ 独立同分布于 $N(0, 1)$，则： χ²分布：$$\chi^2 = \sum_{i=1}^{n} X_i^2 \sim \chi^2(n)$$ t分布：$$T = \frac{Z}{\sqrt{\chi^2/n}} \sim t(n)$$ F分布：$$F = \frac{\chi^2_1/n_1}{\chi^2_2/n_2} \sim F(n_1, n_2)$$
χ² 卡方分布 (Chi-square)

定义：标准正态变量的平方和

参数：自由度 ν (nu)

特点：非负、右偏，ν→∞时趋近正态

应用：方差检验、拟合优度

$$E(\chi^2) = \nu, \quad Var(\chi^2) = 2\nu$$
t t分布 (Student's t)

定义：正态变量除以√(卡方/自由度)

参数：自由度 ν

特点：对称、肥尾，ν→∞时→N(0,1)

应用：小样本均值检验

$$E(t) = 0, \quad Var(t) = \frac{\nu}{\nu-2} \quad (\nu>2)$$
F F分布 (Fisher's F)

定义：两个卡方分布之比

参数：自由度 (ν₁, ν₂)

特点：非负、右偏，专门比较方差

应用：ANOVA、方差齐性检验

$$E(F) = \frac{\nu_2}{\nu_2-2} \quad (\nu_2>2)$$

📊 χ²分布（卡方分布）

用于单样本方差检验、拟合优度检验、列联表独立性检验。

ν = 5

💡 观察要点

  • 形状变化：ν=1时严重右偏，ν增大时逐渐对称，ν>30时可近似为正态分布
  • 临界值：红色阴影区域是拒绝域（面积为α），临界值χ²ₐ(ν)随ν增大而增大
  • 期望与方差：E=ν，Var=2ν，所以变异系数CV=√(2/ν)
  • 可加性：独立的χ²变量之和仍服从χ²分布（自由度相加）

📈 t分布（学生t分布）

用于小样本均值检验、回归系数显著性检验。当σ未知时用t检验替代z检验。

ν = 5

💡 观察要点

  • 肥尾现象：相比正态分布，t分布尾部更厚（小样本时极端值更常见）
  • 收敛速度：ν→∞时t分布→标准正态分布N(0,1)，ν>30时几乎无区别
  • 临界值：tₐ/₂(ν) > zₐ/₂，小样本时需要更大的"证据"才能拒绝原假设
  • 实用性：真实世界σ几乎总是未知，所以t检验比z检验更常用

📉 F分布（方差比分布）

用于方差分析（ANOVA）、方差齐性检验（Levene检验）、回归模型整体显著性检验。

ν₁ = 5 ν₂ = 10

💡 观察要点

  • 非负性：F≥0，因为它是方差之比（平方项）
  • 不对称：严重右偏，峰值接近0（大概率是小值）
  • 临界值：Fₐ(ν₁,ν₂)通常>1，只有当组间方差显著大于组内方差时才拒绝H₀
  • 互惠关系：F₁₋ₐ(ν₁,ν₂) = 1 / Fₐ(ν₂,ν₁)
  • ANOVA原理：F = MS_between / MS_within，值越大说明组间差异越显著

🔄 三分布关系总结

理解三大抽样分布之间的联系：

📝 关键结论

  1. 正态分布是基础：三大抽样分布都源于正态总体
  2. 极限行为：自由度→∞时，χ²、t、F都趋近于正态分布
  3. 小样本用t：σ未知时用t检验，σ已知时用z检验（几乎不适用）
  4. 比较方差用F：ANOVA、方差齐性检验的基石
  5. 检验列联表用χ²：分类数据关联性检验的首选

🎯 选择合适的检验：决策指南

单样本均值检验

σ已知 → z检验（正态分布）

σ未知，n≥30 → z检验（近似）

σ未知，n<30 → t检验

两样本均值比较

独立样本 → 两样本t检验

配对样本 → 配对t检验

多组均值 → 单因素ANOVA（F检验）

方差检验

单样本方差 → χ²检验

两样本方差 → F检验

多样本方差 → Levene检验/Bartlett检验

分类数据

拟合优度 → χ²拟合优度检验

独立性 → χ²列联表检验

相关性 → 相关系数检验（t或F）
