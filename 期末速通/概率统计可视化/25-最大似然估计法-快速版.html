🎯 最大似然估计法（Maximum Likelihood Estimation, MLE）

第七章：最常用的参数估计方法

💡 基本思想

核心思想：找到使"观察到当前样本"概率最大的参数值

直观理解：
如果我们观察到了某组数据，那么这组数据出现的概率应该比较大
我们选择那个使这组数据"最可能"出现的参数作为估计值

🎯 类比：破案推理

情景：案发现场发现一枚指纹（样本）

可能嫌疑人：A, B, C（不同参数）

MLE思路：谁的指纹最像现场指纹？→ 选择最匹配的那个

数学化：哪个参数下，观察到该样本的概率最大？

似然函数（Likelihood Function）

定义：L(θ) = f(x₁, x₂, ..., xₙ; θ)

独立同分布样本：
L(θ) = Πᵢ₌₁ⁿ f(xᵢ; θ)

对数似然（Log-Likelihood）：
ln L(θ) = Σᵢ₌₁ⁿ ln f(xᵢ; θ)

📋 基本步骤

步骤1：写出似然函数 L(θ) = Πᵢ f(xᵢ; θ)
步骤2：取对数：ln L(θ) = Σᵢ ln f(xᵢ; θ)
步骤3：求导：d(ln L)/dθ = 0
步骤4：解方程得到估计值 θ̂

💡 为什么要取对数？

  1. 简化计算：乘积变成求和， easier to differentiate
  2. 数值稳定：避免多个小概率相乘导致下溢
  3. 单调变换：ln是单调增函数，最大化L等价于最大化lnL

📚 典型例子

例1：正态分布 N(μ, σ²)

问题

样本 x₁, x₂, ..., xₙ ~ N(μ, σ²)，求 μ, σ² 的MLE

解

① 似然函数：

L(μ, σ²) = Πᵢ [1/√(2πσ²) · exp(-(xᵢ-μ)²/(2σ²))]

② 对数似然：

ln L = Σᵢ [ln(1/√(2πσ²)) - (xᵢ-μ)²/(2σ²)]

       = -n/2 · ln(2πσ²) - Σᵢ (xᵢ-μ)²/(2σ²)

③ 对μ求偏导：

∂(ln L)/∂μ = Σᵢ (xᵢ-μ)/σ² = 0

→ Σᵢ xᵢ - nμ = 0

→ μ̂ = (1/n) Σᵢ xᵢ = X̄

④ 对σ²求偏导：

∂(ln L)/∂σ² = -n/(2σ²) + Σᵢ (xᵢ-μ)²/(2σ⁴) = 0

→ -nσ² + Σᵢ (xᵢ-μ)² = 0

→ σ̂² = (1/n) Σᵢ (xᵢ - X̄)²

注意：MLE的σ̂²分母是n，不是n-1（有偏但渐近无偏）

例2：指数分布 Exp(λ)

问题

样本 x₁, x₂, ..., xₙ ~ Exp(λ)，求 λ 的MLE

解

① 似然函数：

L(λ) = Πᵢ [λ · exp(-λxᵢ)] = λⁿ · exp(-λ Σᵢ xᵢ)

② 对数似然：

ln L = n ln λ - λ Σᵢ xᵢ

③ 求导：

d(ln L)/dλ = n/λ - Σᵢ xᵢ = 0

④ 求解：

λ̂ = n / Σᵢ xᵢ = 1/X̄

结论：与矩估计结果相同！

例3：泊松分布 Poisson(λ)

问题

样本 x₁, x₂, ..., xₙ ~ Poisson(λ)，求 λ 的MLE

解

① 似然函数：

L(λ) = Πᵢ [e^(-λ) · λ^(xᵢ) / xᵢ!]

      = e^(-nλ) · λ^(Σᵢ xᵢ) / Πᵢ xᵢ!

② 对数似然：

ln L = -nλ + (Σᵢ xᵢ) · ln λ - Σᵢ ln(xᵢ!)

③ 求导：

d(ln L)/dλ = -n + (Σᵢ xᵢ) / λ = 0

④ 求解：

λ̂ = (1/n) Σᵢ xᵢ = X̄

例4：均匀分布 U(0, θ)

问题

样本 x₁, x₂, ..., xₙ ~ U(0, θ)，求 θ 的MLE

解

① 似然函数：

L(θ) = Πᵢ [1/θ · I(0 ≤ xᵢ ≤ θ)] = (1/θⁿ) · I(max(xᵢ) ≤ θ)

② 分析：

L(θ) = θ^(-n)，当 θ ≥ max(xᵢ)

L(θ) = 0，当 θ < max(xᵢ)

③ 最大化：

L(θ)随θ增大而减小（负指数）

因此取最小的可能值：θ = max(xᵢ)

④ 结论：

θ̂ = max(x₁, x₂, ..., xₙ) = X₍ₙ₎

注意：此例不能用求导法！需要用不等式约束分析。

🏆 MLE 的优良性质

性质 数学表述 直观含义
相合性 θ̂_n →p θ₀ 样本量增大时，估计值收敛于真实值
渐近正态性 √n(θ̂ - θ₀) →d N(0, I⁻¹(θ₀)) 大样本下，估计服从正态分布
渐近有效性 方差达到Cramer-Rao下界 在所有相合估计中，方差最小
不变性 如果 θ̂ 是θ的MLE，则 g(θ̂) 是g(θ)的MLE 参数变换后仍可直接代入

💡 实际意义

  • 相合性：数据越多，估计越准确
  • 渐近正态：可以构造置信区间、进行假设检验
  • 有效性：MLE是"最好"的估计之一（大样本）
  • 不变性：估计方差时，直接用 θ̂² 即可，无需重新推导

🔄 MLE vs 矩估计

特性 矩估计 MLE
思想 匹配矩 最大化似然
计算 简单，解方程 复杂，可能需迭代
效率 较低 渐近最优
唯一性 可能不唯一 通常唯一（凸似然）
适用性 矩存在即可 需知道分布类型
小样本 可能更好 可能不稳定

何时选择哪种方法？

选择矩估计：
• 分布未知，只知道矩
• 需要快速得到粗略估计
• 小样本情况

选择MLE：
• 分布类型已知
• 需要精确估计
• 大样本情况
• 需要构造置信区间/假设检验

🔢 数值优化方法

当无法解析求解时，使用数值方法：

梯度上升：θ₍ₖ₊₁₎ = θ₍ₖ₎ + α · ∇(ln L(θ₍ₖ₎))

牛顿法：θ₍ₖ₊₁₎ = θ₍ₖ₎ - [H(θ₍ₖ₎)]⁻¹ · ∇(ln L(θ₍ₖ₎))
其中 H 是 Hessian 矩阵（二阶导数矩阵）

常用软件：
• R: optim(), mle()
• Python: scipy.optimize.minimize()
• MATLAB: fminsearch()

📝 总结

1. 核心思想：使观察样本概率最大的参数值
2. 基本步骤：①似然函数 ②取对数 ③求导 ④求解
3. 优良性质：相合、渐近正态、渐近有效、不变性
4. 优势：效率高、性质好、适用推断
5. 劣势：计算复杂、需知分布、小样本可能不稳定
6. 应用：现代统计学中最常用的参数估计方法
