## 🧪 测试流程

### 快速测试（5分钟）

1. **打开快速测试页面**
   ```bash

   ```

2. **逐个打开新建页面**（标记为"NEW"）
   - 07-贝叶斯公式.html

   - 09-三大抽样分布对比.html
   - 10-假设检验流程.html

3. **检查清单**
   - ✅ 页面加载正常
   - ✅ 导航栏可用

   - ✅ 控件响应灵敏

   - 打开页面，检查具体问题

4. **导出测试报告**
   - 点击"导出测试报告"
   - 保存测试结果

## 🐛 常见问题排查

### 问题1: 页面加载失败
**可能原因**:
- 文件路径错误
- 文件权限问题
- HTTP服务器未启动

**解决方法**:
```bash
# 检查文件是否存在
ls -la *.html

# 启动HTTP服务器
python3 -m http.server 8000
# 或
npx http-server

# 然后访问
open http://localhost:8000/quick-test.html
```

### 问题2: 数学公式不显示
**可能原因**:
- MathJax CDN访问失败
- 网络连接问题

**解决方法**:
- 检查网络连接
- 使用离线版MathJax
- 清除浏览器缓存

### 问题3: 图表不显示
**可能原因**:
- Plotly CDN访问失败
- JavaScript错误

**解决方法**:
- 打开浏览器开发者工具（F12）
- 查看Console错误信息
- 检查网络请求是否成功

### 问题4: 控件无响应
**可能原因**:
- JavaScript事件未绑定
- 脚本加载顺序错误

**解决方法**:
- 检查HTML中脚本位置
- 确保使用`defer`或`async`
- 查看Console是否有错误

## 🔧 开发者工具使用

### Chrome DevTools

1. **打开开发者工具**
   - macOS: `Cmd + Option + I`
   - Windows/Linux: `Ctrl + Shift + I`

2. **检查Console错误**
   - 查看JavaScript错误
   - 检查网络请求失败
   - 查看性能警告

3. **检查Network**
   - 查看资源加载时间
   - 检查CDN请求状态
   - 分析加载瓶颈

4. **检查Elements**
   - 查看DOM结构
   - 检查CSS样式
   - 调试布局问题

### 性能测试

```javascript
// 在Console中运行
```
