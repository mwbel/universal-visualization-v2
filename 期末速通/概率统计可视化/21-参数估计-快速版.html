🎯 参数估计

第七章：从样本推断总体参数

📖 基本概念

参数估计：根据样本统计量推断总体参数的方法
点估计：用单个数值估计参数（如：μ̂ = X̄）
区间估计：用区间估计参数，并给出置信水平（如：μ ∈ [X̄-1.96σ/√n, X̄+1.96σ/√n]）

💡 两种估计的对比

  • 点估计：估计明天温度是 25°C（精确但不可靠）
  • 区间估计：估计明天温度在 23-27°C 之间（给出了不确定性范围）

📊 点估计方法

1. 矩估计法（Method of Moments, MOM）

基本思想：用样本矩估计总体矩
步骤：
① 计算总体前k阶矩：μᵢ = E(Xⁱ)，i = 1, 2, ..., k
② 计算样本前k阶矩：mᵢ = (1/n) Σⱼ₌₁ⁿ Xⱼⁱ
③ 令 μᵢ(θ) = mᵢ，解方程组得到参数估计值

💡 例子：指数分布 Exp(λ)

总体：E(X) = 1/λ

样本：m₁ = X̄

令：1/λ̂ = X̄

得：λ̂ = 1/X̄

2. 最大似然估计法（Maximum Likelihood Estimation, MLE）

基本思想：找到使"观察到当前样本"概率最大的参数值
似然函数：L(θ) = Πᵢ₌₁ⁿ f(xᵢ; θ)
对数似然：ln L(θ) = Σᵢ₌₁ⁿ ln f(xᵢ; θ)
求解：令 d(ln L)/dθ = 0，解出 θ̂

💡 例子：正态分布 N(μ, σ²)

似然函数：L(μ, σ²) = Πᵢ₌₁ⁿ [1/√(2πσ²) · e^(-(xᵢ-μ)²/(2σ²))]

对数似然：ln L = -n/2 · ln(2πσ²) - Σᵢ₌₁ⁿ (xᵢ-μ)²/(2σ²)

求导得：μ̂ = X̄，σ̂² = (1/n) Σᵢ₌₁ⁿ (xᵢ - X̄)²

3. 两种方法的比较

特性 矩估计法 最大似然估计
思想 匹配矩 最大化似然
优点 计算简单，直观 性质优良，效率高
缺点 可能不唯一 计算复杂，需迭代
适用性 广泛 需知道分布类型

🏆 估计量的评选标准

标准 数学定义 直观含义 比较方法
无偏性 E(θ̂) = θ 估计量的期望等于真实值 计算 E(θ̂) - θ
有效性 Var(θ̂) 最小 在无偏估计中，方差最小 比较方差，越小越好
一致性 θ̂ →p θ 样本量增大时收敛于真实值 证明依概率收敛
均方误差 MSE = E[(θ̂-θ)²] 综合偏差和方差 MSE = Var + Bias²

💡 例子：样本均值的性质

  • 无偏性：E(X̄) = μ ✓
  • 有效性：在所有线性无偏估计中，X̄ 方差最小（Gauss-Markov定理）
  • 一致性：X̄ →p μ（大数定律）

📏 区间估计（置信区间）

置信区间：包含真实参数的概率区间
置信水平：1 - α（常用：95%, 99%）
表示：P(θ ∈ [θ̂_L, θ̂_U]) = 1 - α

1. 正态总体均值的区间估计

条件：X₁, ..., Xₙ ~ N(μ, σ²)，σ² 已知
枢轴量：Z = (X̄ - μ) / (σ/√n) ~ N(0,1)
置信区间：
μ ∈ [X̄ - z_{α/2} · σ/√n, X̄ + z_{α/2} · σ/√n]

常用值：z₀.₀₂₅ = 1.96（95%置信水平）
条件：X₁, ..., Xₙ ~ N(μ, σ²)，σ² 未知
枢轴量：T = (X̄ - μ) / (S/√n) ~ t(n-1)
置信区间：
μ ∈ [X̄ - t_{α/2}(n-1) · S/√n, X̄ + t_{α/2}(n-1) · S/√n]

注意：用 t 分布，比正态分布更宽（更保守）

2. 正态总体方差的区间估计

条件：X₁, ..., Xₙ ~ N(μ, σ²)
枢轴量：χ² = (n-1)S²/σ² ~ χ²(n-1)
置信区间：
σ² ∈ [(n-1)S²/χ²_{α/2}(n-1), (n-1)S²/χ²_{1-α/2}(n-1)]

3. 0-1分布参数p的区间估计

条件：X ~ B(n, p)，X是成功次数
点估计：p̂ = X/n
置信区间（大样本）：
p ∈ [p̂ - z_{α/2} · √(p̂(1-p̂)/n), p̂ + z_{α/2} · √(p̂(1-p̂)/n)]

💡 例子：选举民意调查

调查1000人，520人支持候选人A

点估计：p̂ = 520/1000 = 0.52

95%置信区间：

[0.52 - 1.96×√(0.52×0.48/1000), 0.52 + 1.96×√(0.52×0.48/1000)]

= [0.489, 0.551]

结论：我们有95%的信心认为支持率在48.9%到55.1%之间

4. 单侧置信区间

上置信界：P(μ ≤ μ̄) = 1 - α
μ ≤ X̄ + z_α · σ/√n（正态，σ²已知）

下置信界：P(μ ≥ μ̲) = 1 - α
μ ≥ X̄ - z_α · σ/√n

💡 应用：产品质量保证

我们需要证明产品平均寿命至少为1000小时

使用单侧置信下界，如果 μ̲ = 1050 小时

则有95%的信心认为真实平均寿命 ≥ 1050 > 1000 ✓

🔄 置信区间与假设检验的关系

定理：显著性水平为α的假设检验，与置信水平为1-α的置信区间对应

关系：
• 如果 H₀: μ = μ₀ 在水平α下被拒绝 ⇔ μ₀ 不在置信区间内
• 如果 H₀: μ = μ₀ 在水平α下被接受 ⇔ μ₀ 在置信区间内

💡 例子：

95%置信区间：μ ∈ [48.9, 55.1]

  • H₀: μ = 50 → 50 ∈ [48.9, 55.1] → 接受 H₀
  • H₀: μ = 60 → 60 ∉ [48.9, 55.1] → 拒绝 H₀

📝 总结

1. 点估计方法：矩估计法（简单）、最大似然估计（优良）
2. 评选标准：无偏性、有效性、一致性、均方误差
3. 区间估计：置信区间给出参数的可能范围
4. 常用区间：均值（Z/t）、方差（χ²）、比例（正态近似）
5. 单侧区间：用于质量保证等需要证明"至少"或"至多"的场景
6. 与假设检验的关系：置信区间等价于一系列假设检验
