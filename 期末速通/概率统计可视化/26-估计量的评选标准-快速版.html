🏆 估计量的评选标准

第七章：如何判断一个估计量的好坏？

📖 基本概念

估计量（Estimator）：用于估计参数的统计量，是样本的函数
估计值（Estimate）：估计量在具体样本中的取值

例子：
• 估计量：θ̂ = X̄（随机变量）
• 估计值：θ̂ = 5.2（具体数值）

💡 为什么需要评选标准？

对于同一个参数，可能有多个估计方法：

  • 正态分布均值 μ：可用 X̄、中位数、切尾均值
  • 均匀分布参数 θ：可用 max(Xᵢ)、2X̄、(n+1)X₍ₙ₎/n

问题：哪个更好？需要客观标准！

📊 四大评选标准

1. 无偏性（Unbiasedness）

定义：E(θ̂) = θ
偏差：Bias(θ̂) = E(θ̂) - θ

直观理解：估计量的期望等于真实值，"平均来说"准确

例子：E(X̄) = μ ✓，E(S²) = σ² ✓

2. 有效性（Efficiency）

定义：在所有无偏估计中，方差最小
Var(θ̂₁) < Var(θ̂₂) ⇒ θ̂₁ 更有效

直观理解：估计的波动越小越好

例子：X̄ 比中位数更有效（方差更小）

3. 一致性（Consistency）

定义：θ̂ →p θ（依概率收敛）
即：lim(n→∞) P(|θ̂ - θ| < ε) = 1

直观理解：样本量增大时，估计值趋近真实值

例子：X̄ →p μ（大数定律）

4. 充分性（Sufficiency）

定义：包含样本中关于参数的全部信息
P(X|θ̂, θ) = P(X|θ̂)（不依赖θ）

直观理解：不丢失样本中的信息

例子：X̄ 对 μ 是充分的

📚 详细解释与例子

1. 无偏性详解

✅ 无偏估计的例子

  • 样本均值：E(X̄) = μ
  • 样本方差：E(S²) = σ²（注意：分母是n-1）
  • 样本比例：E(p̂) = p

❌ 有偏估计的例子

  • MLE的方差：E(σ̂²_MLE) = (n-1)σ²/n（低估）
  • 样本标准差：E(S) ≠ σ（非线性函数）

💡 有偏估计一定不好吗？

不一定！例如：Ridge回归是有偏的，但方差更小，总体MSE可能更小

2. 有效性详解

Cramer-Rao 下界（CRB）：
Var(θ̂) ≥ 1/[nI(θ)]
其中 I(θ) = E[(∂ ln f(X;θ)/∂θ)²] 是 Fisher 信息

达到CRB的估计称为"有效估计"
估计量 方差 有效性
样本均值 X̄ σ²/n ✅ 达到CRB
样本中位数 ~X ≈ 1.57σ²/n（正态总体） ❌ 未达到CRB
切尾均值 介于两者之间 ⚠️ 抗异常值，但效率较低

💡 偏差-方差权衡（Bias-Variance Tradeoff）

均方误差：MSE = E[(θ̂ - θ)²] = Var(θ̂) + [Bias(θ̂)]²

有时接受小的偏差，换取更小的方差，从而降低MSE

应用：正则化方法（Ridge、Lasso）

3. 一致性详解

充分条件：如果满足以下条件，则 θ̂ 是一致估计：
① lim(n→∞) E(θ̂) = θ（渐近无偏）
② lim(n→∞) Var(θ̂) = 0（方差趋于0）

马尔可夫不等式：可直接证明一致性

💡 一致 vs 不一致

一致的：X̄ → μ, S² → σ², p̂ → p

不一致的：用前10个样本的均值（不随n增加）

一致性是最基本的要求：数据越多，估计应该越准确

4. 充分性详解

因子分解定理（Neyman-Fisher）：
f(x₁, ..., xₙ; θ) = g(T(x₁, ..., xₙ), θ) · h(x₁, ..., xₙ)

如果能这样分解，则 T 是充分的统计量

💡 充分统计量的例子

  • 正态 N(μ, σ²)：T = (ΣXᵢ, ΣXᵢ²) 对 (μ, σ²) 充分或
  • 泊松 Poisson(λ)：T = ΣXᵢ 对 λ 充分
  • 均匀 U(0, θ)：T = max(Xᵢ) 对 θ 充分

意义：充分统计量压缩了数据，但不损失信息

⚖️ 综合比较：哪个估计量更好？

例：正态分布均值 μ 的估计

💡 实际建议

  1. 优先考虑无偏性：系统偏差会误导结论
  2. 在无偏估计中，选择方差最小的：更精确
  3. 如果小样本或有异常值：牺牲部分效率，换取稳健性
  4. 大样本时，一致性最重要：数据够多，几乎所有估计都收敛

🥇 最小方差无偏估计（MVUE）

定义：在所有无偏估计中，方差最小的估计

Lehmann-Scheffé 定理：
如果 T 是充分完备统计量，且 E(φ(T)) = θ
则 φ(T) 是 MVUE

💡 MVUE 的例子

  • 正态均值：X̄ 是 μ 的 MVUE
  • 正态方差：S² 是 σ² 的 MVUE（分母n-1）
  • 泊松参数：X̄ 是 λ 的 MVUE

MVUE 是"黄金标准"：既无偏，又最精确

📝 总结

1. 无偏性：E(θ̂) = θ，平均来说准确（最基本要求）
2. 有效性：Var(θ̂) 最小，波动越小越好（精确度）
3. 一致性：θ̂ →p θ，样本增大时收敛（大样本性质）
4. 充分性：包含全部信息，不损失数据（信息利用）
5. 权衡：无偏性 vs 有效性，效率 vs 稳健性
6. MVUE：最小方差无偏估计，理论最优
