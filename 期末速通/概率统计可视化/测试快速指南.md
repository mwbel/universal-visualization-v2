
## 🐛 常见问题

### Q1: 页面打不开？
**A**: 检查是否启动了HTTP服务器
```bash
python3 -m http.server 8000
```

### Q2: 数学公式不显示？
**A**:
- 检查网络连接
- 清除浏览器缓存
- 等待MathJax加载完成

### Q3: 图表不显示？
**A**:
- 打开开发者工具（F12）
- 查看Console错误
- 检查Plotly是否加载

### Q4: 控件无响应？
**A**:
- 查看是否有JavaScript错误
- 检查事件是否正确绑定
- 刷新页面重试
