# 概率论与数理统计可视化实现计划

## 📊 项目概述

基于刚完成的**条件概率可视化**模板和规范，为概率论与数理统计的所有核心概念创建交互式可视化页面。

---

## 🎯 核心原则

1. **遵循新规范** - 使用刚创建的模板和标准
2. **三栏式布局** - 参考 Google DynamicView 设计
3. **LaTeX 渲染** - 所有数学符号使用 MathJax
4. **动态交互** - 参数调整时实时更新可视化
5. **统一体验** - 所有页面风格一致

## 📐 技术实现要点

### 1. 使用新模板
```bash
cp visualization-page-template.html new-page.html
```

### 2. 三栏布局实现
```css
.three-column-layout {
    display: grid;
    grid-template-columns: 280px 1fr 320px;
    gap: 20px;
    height: calc(100vh - 200px);
}
```

### 3. 响应式设计
- 桌面：三栏布局
- 平板：两栏（参数+可视化，说明在下方）
- 手机：单栏（垂直堆叠）

### 4. 性能优化
- 使用 `requestAnimationFrame` 优化动画
- 防抖滑块事件（300ms）
- Plotly.react 代替 newPlot（如果可能）
