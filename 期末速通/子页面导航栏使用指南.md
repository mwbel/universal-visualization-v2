# 期末速通 - 子页面导航栏使用指南

## 📋 概述

为了提供更好的用户体验和导航便利性，所有期末速通的子页面都应该添加统一的导航栏。本指南说明如何在子页面中添加导航按钮。

---

## 🎯 导航栏功能

每个子页面的导航栏包含以下功能：

1. **返回上一级按钮** - 使用浏览器历史记录返回上一页
2. **期末速通主页按钮** - 直接返回期末速通主页面
3. **页面标题** - 显示当前页面标题
4. **面包屑导航** - 显示当前页面在层级结构中的位置

---

## 🔧 快速集成方法

### 方法1：使用完整HTML结构（推荐）

适用于独立页面（如concept-navigator.html）

#### 步骤1：引入CSS样式
```html
<head>
    <link rel="stylesheet" href="css/page-navbar.css">
</head>
```

#### 步骤2：添加导航栏HTML
```html
<body>
    <nav class="page-navbar">
        <div class="nav-buttons">
            <button class="nav-btn nav-btn-back" onclick="history.back()">
                返回上一级
            </button>
            <a href="index.html" class="nav-btn nav-btn-home">
                期末速通主页
            </a>
        </div>

        <div class="page-title">
            <h1>📚 您的页面标题</h1>
        </div>

        <div class="breadcrumb">
            <div class="breadcrumb-item">
                <a href="index.html">期末速通</a>
                <span class="breadcrumb-separator">/</span>
            </div>
            <div class="breadcrumb-item">
                <a href="#">所属课程</a>
                <span class="breadcrumb-separator">/</span>
            </div>
            <div class="breadcrumb-item">
                <a href="#">当前页面</a>
            </div>
        </div>
    </nav>

    <!-- 您的页面内容 -->
</body>
```

### 方法2：使用JavaScript辅助函数

适用于需要动态添加导航栏的页面

#### 步骤1：引入辅助JS
```html
<script src="js/navbar-helper.js"></script>
```

#### 步骤2：调用辅助函数
```javascript
// 页面加载完成后
document.addEventListener('DOMContentLoaded', function() {
    // 插入导航栏
    NavbarHelper.insertNavbar(
        '您的页面标题',  // 页面标题
        NavbarHelper.BreadcrumbTemplates.probability  // 使用预设的面包屑模板
    );
});
```

### 方法3：自动集成（iframe中的可视化页面）

如果您在iframe中嵌入可视化页面，导航栏会自动添加！

**前提条件**：
1. 在index.html中已引入`navbar-helper.js`（已完成✅）
2. iframe内容会自动检测并添加导航按钮

**自动添加的按钮**：
- ← 返回学习界面（关闭iframe）
- 🏠 返回主页（跳转到index.html）

## 📱 响应式行为

导航栏会根据屏幕尺寸自动调整：

### 桌面（>768px）
- 完整的三栏布局（按钮 | 标题 | 面包屑）
- 按钮横向排列

### 移动端（<768px）
- 垂直堆叠布局
- 按钮占据全宽
- 面包屑自动换行
- 字体和间距自动缩小

## 🐛 常见问题

### Q1：返回上一级按钮不工作？
**A**: 确保页面有历史记录可以返回。如果是直接打开的页面，可能没有历史记录。

### Q2：导航栏样式不显示？
**A**: 检查CSS文件路径是否正确：
```html
<link rel="stylesheet" href="css/page-navbar.css">
```
如果是子目录中的页面，需要调整路径：
```html
<link rel="stylesheet" href="../css/page-navbar.css">
```

### Q3：iframe中的按钮不显示？
**A**: 确保：
1. index.html中已引入`navbar-helper.js`
2. iframe的`src`属性已设置
3. iframe内容与主页同源（跨域限制）

### Q4：如何隐藏面包屑？
**A**: 在HTML中删除`.breadcrumb`部分，或在CSS中设置：
```css
.breadcrumb {
    display: none;
}
```
