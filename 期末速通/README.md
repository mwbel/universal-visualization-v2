# 🎯 期末速通 - 三门课程期末攻关系统

**目标**: 在2-3周内，通过可视化学习和AI辅助，高效掌握三门课程的核心考点，确保期末考试顺利通过

---

## 📚 三门课程

1. 📊 **概率论与数理统计** - 分布可视化、统计推断、假设检验
2. ⚛️ **大学物理（下册）** - 电磁学、波动光学、近代物理
3. 💻 **C++程序设计** - 面向对象、继承多态、STL容器

---

## 🚀 快速开始

### 访问系统
```
http://localhost:8000/期末速通/index.html
```

### 使用流程
1. 选择一门课程
2. 查看考点清单（红色=重要）
3. 观看可视化，理解概念
4. 问AI助手，解答疑惑
5. 标记已掌握，继续下一个

---

## ✨ 核心功能

### 1. 可视化学习
- **复用现有资源**: 概率统计已集成5个分布可视化
- **交互式学习**: 动态调整参数，直观理解概念
- **多学科支持**: 数学、物理、编程全覆盖

### 2. AI学习助手
- **即时问答**: 随时提问，AI即时回答
- **学科专属**: 针对不同学科定制回答
- **公式渲染**: 支持LaTeX数学公式

### 3. 进度追踪
- **考点清单**: 每科8-10个核心考点
- **重要性标记**: critical/high/medium
- **自动保存**: 本地存储，刷新不丢失
