## 方案B：服务器部署

### 前置要求
- Ubuntu 20.04+ 服务器
- 域名（可选）
- SSH访问权限

### 步骤1：上传文件到服务器
```bash
# 在本地执行
scp -r probability-stats-online/ user@your-server:/var/www/

# 或使用Git
git clone <your-repo-url>
cd probability-stats-online
```

### 步骤2：安装Nginx
```bash
# 在服务器上执行
sudo apt update
sudo apt install nginx -y
sudo systemctl start nginx
```

### 步骤3：配置Nginx
```bash
# 创建站点配置
sudo nano /etc/nginx/sites-available/probstats
```

**添加以下配置**:
```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        root /var/www/probability-stats-online/modules;
        index index.html;
    }

    # 如果有API后端
    location /api/ {
        proxy_pass http://localhost:8000;
    }
}
```

### 步骤4：启用站点
```bash
sudo ln -s /etc/nginx/sites-available/probstats /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

### 步骤5：访问网站
```
http://your-domain.com/常见离散分布可视化.html
```

### 完成！🎉

## 方案C：Docker部署

### 步骤1：创建docker-compose.yml
```yaml
version: '3.8'

services:
  frontend:
    image: nginx:alpine
    ports:
      - "80:80"
    volumes:
      - ./modules:/usr/share/nginx/html
    restart: unless-stopped
```

### 步骤2：启动容器
```bash
docker-compose up -d
```

### 步骤3：访问网站
```
http://localhost/常见离散分布可视化.html
```

### 完成！🎉

## 🤖 集成AI功能（可选）

### 前置条件
- OpenAI API密钥 或其他LLM服务

### 步骤1：配置API
```bash
cp config/api-config.js config/api-config.local.js
```

### 步骤2：编辑配置文件
```javascript
// config/api-config.local.js
const API_CONFIG = {
    LLM_API: {
        apiKey: 'sk-your-api-key',  // 替换这里
        baseURL: 'https://api.openai.com/v1',
        model: 'gpt-3.5-turbo'
    }
};
```

### 步骤3：在HTML中添加AI按钮
```html
<div class="ai-assistant">
    <button onclick="askAI('条件概率')">🤖 AI解释</button>
</div>

<script src="../api/api-client.js"></script>
<script src="../config/api-config.local.js"></script>
```

### 完成！✨

## 🔧 常见问题

### Q1: 页面打不开？
**A**: 检查端口是否被占用
```bash
# 查看端口占用
lsof -i :8080

# 更换端口
python -m http.server 8888
```

### Q2: 图表不显示？
**A**: 检查CDN连接是否正常
- 确保网络连接正常
- 检查防火墙设置

### Q3: AI功能不能用？
**A**:
- 检查API密钥是否正确
- 查看浏览器控制台错误信息
- 确认API额度充足
