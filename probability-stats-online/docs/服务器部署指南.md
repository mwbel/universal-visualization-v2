# 🚀 服务器部署指南

## 📦 部署方案

### 方案1：传统服务器部署（推荐生产环境）

#### 服务器要求
- **操作系统**: Ubuntu 20.04+ / CentOS 8+
- **CPU**: 2核+
- **内存**: 4GB+
- **磁盘**: 20GB+

#### 1. 安装依赖

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装Python 3.9+
sudo apt install python3.9 python3.9-venv python3-pip -y

# 安装Nginx
sudo apt install nginx -y

# 安装PostgreSQL
sudo apt install postgresql postgresql-contrib -y

# 安装Redis
sudo apt install redis-server -y

# 安装Node.js（可选，如果需要前端构建工具）
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install nodejs -y
```

#### 2. 配置PostgreSQL

```bash
# 切换到postgres用户
sudo -u postgres psql

# 创建数据库和用户
CREATE DATABASE probstats_db;
CREATE USER probstats_user WITH PASSWORD 'your_secure_password';
GRANT ALL PRIVILEGES ON DATABASE probstats_db TO probstats_user;
\q
```

#### 3. 配置Redis

```bash
# 编辑Redis配置
sudo nano /etc/redis/redis.conf

# 设置密码（可选）
requirepass your_redis_password

# 重启Redis
sudo systemctl restart redis
sudo systemctl enable redis
```

#### 4. 部署后端API

```bash
# 创建项目目录
sudo mkdir -p /var/www/probstats-api
cd /var/www/probstats-api

# 创建虚拟环境
python3.9 -m venv venv
source venv/bin/activate

# 安装依赖（需要先创建requirements.txt）
pip install -r requirements.txt

# 创建配置文件
sudo nano .env
```

**.env 文件内容**:
```env
# 应用配置
APP_NAME=概率统计AI助手
APP_VERSION=1.0.0
DEBUG=False
SECRET_KEY=your-secret-key-here

# 数据库配置
DATABASE_URL=postgresql://probstats_user:your_secure_password@localhost/probstats_db

# Redis配置
REDIS_URL=redis://:your_redis_password@localhost:6379/0

# LLM API配置
LLM_API_KEY=sk-your-api-key
LLM_API_URL=https://api.openai.com/v1
LLM_MODEL=gpt-3.5-turbo

# 服务器配置
HOST=0.0.0.0
PORT=8000
WORKERS=4
```

**requirements.txt**:
```txt

pydantic==2.5.0
sqlalchemy==2.0.23
psycopg2-binary==2.9.9
redis==5.0.1
python-multipart==0.0.6

passlib[bcrypt]==1.7.4
openai==1.3.5

httpx==0.25.1

```

#### 5. 创建Systemd服务

```bash
# 创建服务文件
sudo nano /etc/systemd/system/probstats-api.service
```

**服务文件内容**:
```ini
[Unit]
Description=概率统计AI助手API
After=network.target postgresql.service redis.service

[Service]
Type=notify
User=www-data
Group=www-data
WorkingDirectory=/var/www/probstats-api
Environment="PATH=/var/www/probstats-api/venv/bin"
ExecStart=/var/www/probstats-api/venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4
ExecReload=/bin/kill -s HUP $MAINPID
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# 启动服务
sudo systemctl daemon-reload
sudo systemctl start probstats-api
sudo systemctl enable probstats-api

# 检查状态
sudo systemctl status probstats-api
```

#### 6. 部署前端

```bash
# 创建前端目录
sudo mkdir -p /var/www/probstats-frontend
cd /var/www/probstats-frontend

# 复制前端文件
sudo cp -r /path/to/probability-stats-online/* .

# 设置权限
sudo chown -R www-data:www-data /var/www/probstats-frontend
sudo chmod -R 755 /var/www/probstats-frontend
```

#### 7. 配置Nginx

```bash
# 创建站点配置
sudo nano /etc/nginx/sites-available/probstats
```

**Nginx配置文件**:
```nginx
# 上游API服务器
upstream probstats_api {
    server 127.0.0.1:8000;
}

# HTTP服务器
server {
    listen 80;
    server_name your-domain.com www.your-domain.com;

    # 前端静态文件
    location / {
        root /var/www/probstats-frontend/modules;
        index index.html;
        try_files $uri $uri/ /index.html;

        # 缓存静态资源
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
            expires 1y;
            add_header Cache-Control "public, immutable";
        }
    }

    # API代理
    location /api/ {
        proxy_pass http://probstats_api;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # 文件上传大小限制
    client_max_body_size 10M;

    # Gzip压缩
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_types text/plain text/css text/xml text/javascript
               application/x-javascript application/xml+rss
               application/json application/javascript;
}
```

```bash
# 启用站点
sudo ln -s /etc/nginx/sites-available/probstats /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重启Nginx
sudo systemctl restart nginx
sudo systemctl enable nginx
```

#### 8. 配置SSL证书（HTTPS）

```bash
# 安装Certbot
sudo apt install certbot python3-certbot-nginx -y

# 获取并安装证书
sudo certbot --nginx -d your-domain.com -d www.your-domain.com

# 自动续期
sudo certbot renew --dry-run
```

### 方案2：Docker部署（推荐开发/测试）

#### Docker Compose配置

**docker-compose.yml**:
```yaml
version: '3.8'

services:
  # PostgreSQL数据库
  db:
    image: postgres:15-alpine
    container_name: probstats-db
    environment:
      POSTGRES_DB: probstats_db
      POSTGRES_USER: probstats_user
      POSTGRES_PASSWORD: your_secure_password
    volumes:
      - postgres_data:/var/lib/postgresql/data
    ports:
      - "5432:5432"
    restart: unless-stopped

  # Redis缓存
  redis:
    image: redis:7-alpine
    container_name: probstats-redis
    command: redis-server --requirepass your_redis_password
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    restart: unless-stopped

  # 后端API
  api:
    build: ./backend
    container_name: probstats-api
    environment:
      DATABASE_URL: postgresql://probstats_user:your_secure_password@db:5432/probstats_db
      REDIS_URL: redis://:your_redis_password@redis:6379/0
      LLM_API_KEY: ${LLM_API_KEY}
      LLM_API_URL: ${LLM_API_URL}
      LLM_MODEL: ${LLM_MODEL}
    ports:
      - "8000:8000"
    depends_on:
      - db
      - redis
    restart: unless-stopped

  # 前端
  frontend:
    image: nginx:alpine
    container_name: probstats-frontend
    volumes:
      - ./modules:/usr/share/nginx/html
      - ./nginx.conf:/etc/nginx/conf.d/default.conf
    ports:
      - "80:80"
    depends_on:
      - api
    restart: unless-stopped

volumes:
  postgres_data:
  redis_data:
```

**后端Dockerfile** (`backend/Dockerfile`):
```dockerfile
FROM python:3.9-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000", "--workers", "4"]
```

**启动命令**:
```bash
# 构建并启动
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止
docker-compose down

# 重新构建
docker-compose up -d --build
```

### 数据库备份

```bash
# 每日自动备份脚本
#!/bin/bash
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/var/backups/probstats"
mkdir -p $BACKUP_DIR

# 备份数据库
pg_dump -U probstats_user probstats_db | gzip > $BACKUP_DIR/db_$DATE.sql.gz

# 保留最近30天的备份
find $BACKUP_DIR -name "db_*.sql.gz" -mtime +30 -delete

# 添加到crontab
# 0 2 * * * /path/to/backup.sh
```

```bash

sudo ufw allow 80    # HTTP
sudo ufw allow 443   # HTTPS

sudo ufw deny 5432   # 不允许外部访问数据库
```

## 🆘 常见问题

### 问题1: API 502错误
**原因**: 后端服务未启动或端口配置错误
**解决**: 检查 `sudo systemctl status probstats-api`

### 问题2: 数据库连接失败
**原因**: 数据库未启动或密码错误
**解决**: 检查 `sudo systemctl status postgresql`

### 问题3: 静态文件404
**原因**: Nginx路径配置错误
**解决**: 检查 `root` 路径是否正确
