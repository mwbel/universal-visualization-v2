# 大模型集成指南

## 📋 概述

本文档说明如何将大语言模型（LLM）集成到概率统计可视化系统中，实现智能问答、概念解释、测验生成等功能。

---

## 🎯 核心功能

### 1. 智能概念解释
- 用户点击"AI解释"按钮
- 调用LLM API生成详细的概念解释
- 展示通俗易懂的例子和类比

### 2. 互动式问答
- 实时回答用户关于概率统计的问题
- 提供步骤化的解题指导
- 关联具体可视化页面

### 3. 自动测验生成
- 根据当前学习内容生成练习题
- 不同难度级别可选
- 提供详细的答案解析

### 4. 智能学习推荐
- 根据用户学习进度推荐下一步内容
- 识别薄弱环节
- 个性化学习路径

### 5. 错题分析
- 分析用户答题错误
- 提供针对性复习建议
- 生成类似练习题

## 🔌 API设计

### 1. 概念解释API

**端点**: `POST /api/v1/explain`

**请求**:
```json
{
    "concept": "条件概率",
    "context": {
        "userLevel": "beginner",
        "currentPage": "条件概率.html",
        "previousTopics": ["样本空间", "概率定义"]
    },
    "language": "zh-CN"
}
```

**响应**:
```json
{
    "success": true,
    "data": {
        "explanation": "条件概率是指在某个事件已经发生的条件下...",
        "examples": [
            "抛硬币的例子...",
            "医疗检测的例子..."
        ],
        "visualAids": "建议使用Venn图理解...",
        "relatedTopics": ["独立性", "贝叶斯公式"],
        "difficulty": "intermediate"
    }
}
```

### 2. 聊天对话API

**端点**: `POST /api/v1/chat/completions`

**请求**:
```json
{
    "messages": [
        {"role": "system", "content": "你是概率统计学习助手..."},
        {"role": "user", "content": "什么是中心极限定理？"}
    ],
    "model": "gpt-3.5-turbo",
    "temperature": 0.7,
    "max_tokens": 1000
}
```

**响应**:
```json
{
    "success": true,
    "data": {
        "id": "chatcmpl-xxx",
        "choices": [{
            "message": {
                "role": "assistant",
                "content": "中心极限定理是概率论中最重要..."
            },
            "finish_reason": "stop"
        }],
        "usage": {
            "prompt_tokens": 20,
            "completion_tokens": 100,
            "total_tokens": 120
        }
    }
}
```

### 3. 测验生成API

**端点**: `POST /api/v1/quiz/generate`

**请求**:

**响应**:
```json

                "correctAnswer": 0,
                "explanation": "标准正态分布N(0,1)..."
```

### API密钥管理

### 请求限流
```python
# 使用Redis实现限流
from redis import Redis
from functools import wraps

redis = Redis(host='localhost', port=6379, db=0)

def rate_limit(max_requests=10, window=60):
    """限流装饰器：每个用户每分钟最多max_requests个请求"""
    def decorator(f):
        @wraps(f)
        async def wrapped_function(*args, **kwargs):
            user_id = get_user_id()
            key = f"rate_limit:{user_id}"

            current = redis.incr(key)
            if current == 1:
                redis.expire(key, window)

            if current > max_requests:
                return {"error": "请求过于频繁，请稍后再试"}

            return await f(*args, **kwargs)
        return wrapped_function
    return decorator

# 使用示例
@app.post("/api/v1/explain")
@rate_limit(max_requests=10, window=60)
async def explain_concept(request: Request):
    ...
```

## 🚀 快速开始

### 1. 前端集成

```html
<!-- 在可视化页面中添加AI助手按钮 -->
<button onclick="askAI('条件概率')">🤖 AI解释</button>

<!-- 引入API客户端 -->
<script src="../api/api-client.js"></script>
<script>
async function askAI(concept) {
    const response = await llmClient.explainConcept(concept, {
        userLevel: 'beginner',
        currentPage: window.location.pathname
    });

    if (response.success) {
        showAIExplanation(response.data);
    }
}
</script>
```

### 2. 后端部署（FastAPI示例）

```python
# main.py
from fastapi import FastAPI
from api import llm, recommendation, analytics

app = FastAPI(title="概率统计AI助手API")

app.include_router(llm.router, prefix="/api/v1", tags=["LLM"])
app.include_router(recommendation.router, prefix="/api/v1", tags=["推荐"])
app.include_router(analytics.router, prefix="/api/v1", tags=["统计"])

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

### 3. 配置环境变量

```bash
# .env
LLM_API_KEY=sk-...
LLM_API_URL=https://api.openai.com/v1
LLM_MODEL=gpt-3.5-turbo
REDIS_URL=redis://localhost:6379

```

```bash

python main.py
```
