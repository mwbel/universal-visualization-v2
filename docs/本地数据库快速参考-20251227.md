## 📋 常用命令

### 数据库管理

```bash
# 进入项目目录
cd /Users/Min369/Documents/同步空间/Manju/Projects/AlVisualization/backend-v2

# 测试数据库连接
python3 database/init_database.py --test

# 初始化数据库（首次使用）
python3 database/init_database.py --init

# 查看统计信息
python3 database/init_database.py --stats

# 备份数据库
python3 database/init_database.py --backup

# 恢复数据库
python3 database/init_database.py --restore

# 重置数据库（⚠️ 删除所有数据）
python3 database/init_database.py --reset
```

### PostgreSQL 命令

```bash
# 连接到数据库
psql -U universal_viz_user -d universal_viz_db

# 查看所有数据库
psql -U universal_viz_user -l

# 查看数据库大小
psql -U universal_viz_user -d universal_viz_db -c "SELECT pg_size_pretty(pg_database_size('universal_viz_db'));"
```

### 在 psql 中

```sql
-- 查看所有表
\dt

-- 查看表结构
\d subjects

-- 查看索引
\di

-- 查看表内容
SELECT * FROM subjects LIMIT 10;

-- 统计各表行数
SELECT
    'subjects' AS table_name, COUNT(*) FROM subjects
UNION ALL
SELECT 'subject_keywords', COUNT(*) FROM subject_keywords
UNION ALL
SELECT 'core_concepts', COUNT(*) FROM core_concepts
UNION ALL
SELECT 'visualization_templates', COUNT(*) FROM visualization_templates;

-- 退出
\q
```

## 🔍 故障排查

### 问题1：连接被拒绝

```bash
# 检查服务状态
brew services list  # macOS
sudo systemctl status postgresql  # Linux

# 启动服务
brew services start postgresql@16
```

### 问题2：密码错误

```bash
# 重置密码
psql -U postgres -d postgres
ALTER USER universal_viz_user WITH PASSWORD 'new_password';
\q

# 更新 .env 文件
vim backend-v2/.env
```

### 问题3：端口冲突

```bash
# 查看占用
lsof -i :5432

# 更改端口（在 .env 中）
DB_PORT=5433
```

## 🎯 开发工作流

### 首次设置

```bash
# 1. 一键设置
./setup_local_db.sh

# 2. 配置 API Key
vim .env
# 修改 GEMINI_API_KEY

# 3. 启动后端
python3 -m uvicorn main:app --reload

# 4. 访问文档
open http://localhost:8000/docs
```

### 日常开发

```bash
# 启动后端
cd backend-v2
python3 -m uvicorn main:app --reload

# 启动前端（另一个终端）
cd frontend-v4
python3 -m http.server 3000
```

### 添加新数据

```bash
# 连接到数据库
psql -U universal_viz_user -d universal_viz_db

# 插入新学科
INSERT INTO subjects (name, name_en, description, icon, color)
VALUES ('拓扑学', 'Topology', '研究连续变换下不变的性质', '🔄', '#e74c3c');

# 插入关键词
INSERT INTO subject_keywords (subject_id, keyword, weight, is_core)
SELECT id, '同胚', 2.0, TRUE FROM subjects WHERE name = '拓扑学';

# 退出
\q
```
