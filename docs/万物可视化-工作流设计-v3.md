## 项目核心定位

### 核心目标

**文档分析 + AI问答 + 核心概念可视化**

```
用户上传PDF文档
    ↓
系统提取核心概念
    ↓
基于文档AI问答
    ↓
核心概念交互式可视化
```

### 关键特性

- ✅ **文档分析优先** - 提取已有内容，不构建新知识
- ✅ **多模态理解** - Gemini统一处理可编辑/扫描PDF
- ✅ **智能学科分类** - 传统ML + GM4.6
- ✅ **精准概念提取** - TF-IDF + 上下文过滤
- ✅ **交互式可视化** - 模板匹配 + 参数调整
- ✅ **多模型AI问答** - 豆包/Gemini/ChatGPT联动

## 与Math2Manim的本质差异

### 核心差异表

| 维度 | Math2Manim | 万物可视化 |
|------|-----------|-----------|
| **输入** | 用户问题（"解释量子力学"）| 已有PDF文档 |
| **输出** | 动画视频（5分钟）| 交互式可视化 + AI问答 |
| **媒介** | 线性视频 | 非线性交互 |
| **目标用户** | 零基础学习者 | 有基础学习者/研究者 |
| **知识来源** | AI递归推理构建 | 从文档中提取 |
| **核心方法** | **反向知识树**（递归）| **TF-IDF + 模板匹配**（提取）|
| **时间特性** | 固定时长（5分钟）| 无固定时长（用户可控）|
| **是否需要前置知识** | **必须**（否则看不懂）| **不需要**（文档已包含）|

### 为什么不用反向知识树？

**Math2Manim使用反向知识树的原因：**
> 因为要生成**线性的、教学式的动画视频**，必须假设观众是零基础，所以必须从基础概念开始构建完整的知识路径。

**万物可视化不需要反向知识树的原因：**
> 因为是**分析已有文档**，用户有基础，文档本身已包含前置知识，系统只需要提取并可视化文档内容，不需要重新构建知识体系。

### 模块1：文档预处理（Gemini优先）

#### 核心策略

**统一使用 Gemini 1.5 Pro，基于质量评估智能降级**

```python
# 简化架构

用户上传PDF
    ↓
统一调用 Gemini API
    ↓
质量评估（5个维度）
    ↓
质量 ≥ 0.85？
    ↓
  YES → 完成（90%情况）
  NO  → 降级 MinerU（10%情况）
```

#### 质量评估算法

```python
def assess_quality(result):
    """
    综合质量评估（0-1分）

    评估维度：
    1. 解析成功率 (30%)
    2. 内容完整性 (25%)
    3. 文本提取置信度 (20%)
    4. 结构完整性 (15%)
    5. 公式识别率 (10%)
    """
    score = 1.0

    # 1. 解析成功？
    if 'parse_error' in result:
        score -= 0.3

    # 2. 内容足够？
    if len(result['content']) < 500:
        score -= 0.25

    # 3. Gemini自己评估的置信度
    confidence = result['quality_indicators']['text_extraction_confidence']
    score *= confidence

    # 4. 有章节结构？
    if not result['structure']['sections']:
        score -= 0.15

    # 5. 公式数量合理？
    formulas = result['formulas']
    expected = estimate_formula_count(result['content'])
    if len(formulas) < expected * 0.5:
        score -= 0.1

    return max(0, min(1, score))
```

#### Gemini API调用

```python
import google.generativeai as genai

class DocumentPreprocessor:
    def __init__(self):
        genai.configure(api_key=os.getenv("GEMINI_API_KEY"))
        self.model = genai.GenerativeModel('gemini-1.5-pro')

    async def process(self, file_path, user_id):
        # 1. 上传PDF到Gemini
        file = genai.upload_file(path=file_path)

        # 2. 等待处理
        while file.state.name == "PROCESSING":
            await asyncio.sleep(1)
            file = genai.get_file(file.name)

        # 3. 生成内容
        prompt = """
        请分析这份PDF文档，返回JSON格式：
        {
          "content": "Markdown文本",
          "structure": {"sections": [...], "total_pages": N},
          "formulas": [{"latex": "...", "page": N}],
          "quality_indicators": {
            "text_extraction_confidence": 0.95,
            "is_scanned": false
          }
        }
        """

        response = self.model.generate_content([file, prompt])
        result = json.loads(response.text)

        # 4. 质量评估
        quality = self.assess_quality(result)

        # 5. 质量合格，返回
        if quality >= 0.85:
            return self.standardize(result, quality)

        # 6. 质量不合格，降级MinerU
        else:
            return await self.fallback_mineru(file_path)
```

from sklearn.naive_bayes import MultinomialNB
from sklearn.svm import SVC
import joblib

class SubjectRouter:
    def __init__(self):
        # 加载预训练模型
        self.nb_model = joblib.load('models/naive_bayes.pkl')
        self.svm_model = joblib.load('models/svm.pkl')

        # 加载学科关键词库
        self.subject_keywords = self.load_subject_keywords()

    async def classify(self, doc_id, content):
        # 1. GM4.6提取特征
        features = await self.extract_features_with_gm46(content)

        # 2. 构建特征向量（100维）
        vector = self.build_feature_vector(features)

        # 3. 朴素贝叶斯初步分类
        nb_probs = self.nb_model.predict_proba([vector])[0]
        top_2_idx = np.argsort(nb_probs)[-2:][::-1]

        candidates = [
            {'subject': self.nb_model.classes_[i], 'prob': nb_probs[i]}
            for i in top_2_idx
        ]

        # 4. SVM二次确认
        keyword_rules = self.match_keyword_rules(content, candidates)
        final_subject = self.svm_model.predict([keyword_rules])[0]

        return {
            'subject': final_subject,
            'confidence': candidates[0]['prob'],
            'candidates': candidates
        }

    async def extract_features_with_gm46(self, content):
        """GM4.6 API 提取特征"""
        prompt = f"""

### 模块3：核心概念提取

#### 处理流程

```
加载学科概念词库
    ↓
TF-IDF权重计算
    ↓
取TOP20概念
    ↓
GM4.6上下文过滤
  ├─ 过滤：仅在例题出现的概念
  ├─ 补充：隐含概念（未命名）
  └─ 排序：综合重要性
    ↓
返回TOP10核心概念
```

#### TF-IDF计算

```python
from sklearn.feature_extraction.text import TfidfVectorizer

class CoreConceptExtractor:
    def extract(self, doc_id, subject, content):
        # 1. 加载学科核心概念词库
        concept_vocab = self.load_concept_vocabulary(subject)

        # 2. TF-IDF计算
        vectorizer = TfidfVectorizer(
            vocabulary=concept_vocab,
            stop_words=self.load_stopwords(),
            token_pattern=r'(?u)\b\w+\b'  # 排除纯数字
        )

        tfidf_matrix = vectorizer.fit_transform([content])
        feature_names = vectorizer.get_feature_names_out()
        scores = tfidf_matrix.toarray()[0]

        # 3. 取TOP20
        top_20_idx = np.argsort(scores)[-20:][::-1]
        top_20_concepts = [
            {
                'name': feature_names[i],
                'tfidf_score': scores[i],
                'is_synonym': self.check_synonym(feature_names[i])
            }
            for i in top_20_idx
        ]

        # 4. GM4.6过滤与补充
        final_concepts = await self.gm46_filter_and_supplement(
            content, top_20, subject
        )

        # 5. 保存到数据库
        self.save_concepts(doc_id, final_concepts)

        return final_concepts
```

#### GM4.6上下文过滤

```python
async def gm46_filter_and_supplement(self, content, top_20, subject):
    """GM4.6过滤与补充"""

    prompt = f"""
    学科：{subject}
    文档内容：{content[:3000]}

    TOP20概念（含TF-IDF）：
    {json.dumps(top_20, ensure_ascii=False)}

    请执行以下任务：

    1. **过滤次要概念**：
       - 排除仅在"例题/练习题"中出现，未在"定义/定理"中出现的概念
       - 例如："四阶行列式"若仅出现在例题，应过滤

    2. **补充隐含概念**：
       - 若文档多次提及某概念的特征但未明确命名，应补充
       - 例如：多次提到"向量加法满足交换律、数乘满足分配律"，应补充"线性空间"

    3. **重要性排序**：
       - 按"标题出现次数 + 定义出现次数 + TF-IDF得分"综合排序
       - 取前10个

    返回JSON：
    {{
      "final_concepts": [
        {{
          "name": "行列式",
          "synonyms": ["det(A)", "determinant"],
          "definition": "...的定义",
          "importance_score": 0.95,
          "locations": [{{"page": 3, "section": "1.2"}}],
          "is_supplemented": false
        }}
      ]
    }}
    """

    response = await gm46_api.generate(prompt)
    return json.loads(response)
```

class VisualizationGenerator:
    def generate(self, doc_id, subject, concepts):
        visualizations = []

        for concept in concepts:
            # 1. 匹配模板
            template = self.match_template(subject, concept['name'])

            if not template:
                # 无模板
                visualizations.append({
                    'concept': concept['name'],
                    'status': 'no_template'
                })
                continue

            # 2. 生成代码
            viz_code = await self.generate_viz_code(
                template, concept, doc_id
            )

            # 3. 存储到云存储
            code_url = self.upload_to_s3(viz_code)

            visualizations.append({
                'concept': concept['name'],
                'template_id': template['id'],
                'template_name': template['name'],
                'code_url': code_url,
                'parameters': template['parameters'],
                'status': 'ready'
            })

        return visualizations
```

    - 准确展示数学/物理概念
    - 符合学科规范

    返回完整代码（单个HTML文件，包含所有依赖的CDN链接）
    """

    response = await gm46_api.generate(prompt, max_tokens=8000)
    code = self.extract_code_block(response)

    # 压缩代码
    code = self.minify_code(code)

    return code
```

### 模块5：AI问答联动

#### 多模型支持

```python
class AIQAService:
    def __init__(self):
        self.models = {
            '豆包': DoubaoClient(),
            'Gemini': GeminiClient(),
            'ChatGPT': ChatGPTClient()
        }

    async def answer(self, user_id, doc_id, question, selected_models):
        # 1. 获取文档上下文
        context = self.get_context(doc_id)

        # 2. 构建prompt
        prompt = self.build_prompt(question, context)

        # 3. 调用模型
        if 'single' in selected_models:
            model_name = selected_models['single']
            answer = await self.models[model_name].generate(prompt)

            answers = [{
                'model': model_name,
                'answer': answer
            }]

        elif 'comparison' in selected_models:
            # 对比模式：并行调用
            models = selected_models['comparison']
            answers = await asyncio.gather(*[
                self.models[m].generate(prompt)
                for m in models
            ])

        # 4. 注入可视化超链接
        for ans in answers:
            ans['answer'] = self.inject_viz_links(
                ans['answer'],
                doc_id,
                context['core_concepts']
            )

        # 5. 保存对话历史
        self.save_conversation(user_id, doc_id, question, answers)

        return {
            'conversation_id': generate_id(),
            'answers': answers
        }
```

#### Prompt模板

```python
def build_prompt(self, question, context):
    """构建问答prompt"""

    core_concepts_str = ', '.join([
        c['name'] for c in context['core_concepts']
    ])

    prompt = f"""
    基于用户上传的【{context['subject']}】文档，
    内容摘要：{context['content_preview']}

    核心概念：{core_concepts_str}

    回答问题：{question}

    **要求**：
    1. 结合文档内容回答，避免泛化
    2. 若涉及核心概念，简要说明后标注"可查看可视化分析"
    3. 回答清晰易懂，分点说明
    4. 保持上下文连贯（若为追问）
    """

    return prompt
```

#### 可视化链接注入

```python
def inject_viz_links(self, answer, doc_id, core_concepts):
    """注入可视化超链接"""

    for concept in core_concepts:
        concept_name = concept['name']

        if concept_name in answer:
            # 构建超链接
            viz_url = f"/visualization?docId={doc_id}&conceptId={concept['id']}"

            # 替换概念为超链接
            answer = answer.replace(
                concept_name,
                f'{concept_name}（<a href="{viz_url}" target="_blank">查看可视化分析</a>）'
            )

    return answer
```

## 总结

### 核心创新点

1. **Gemini优先策略** - 统一API，智能降级
2. **传统ML + AI** - 朴素贝叶斯+SVM分类，GM4.6补充
3. **TF-IDF提取** - 不是反向知识树，而是内容提取
4. **交互式可视化** - 参数调整，用户可控
5. **多模型问答** - 豆包/Gemini/ChatGPT联动

### 与Math2Manim的彻底区分

| 维度 | Math2Manim | 万物可视化 |
|------|-----------|-----------|
| **输入** | 用户问题 | 已有文档 |
| **输出** | 教学动画 | 可视化+问答 |
| **方法** | 反向知识树（递归）| TF-IDF（提取）|
| **目标用户** | 零基础学习者 | 有基础研究者 |
| **是否需要前置知识** | **必须** | **不需要** |

### 最终建议

1. **MVP阶段** - 仅用Gemini（覆盖90%场景）
2. **生产阶段** - 启用智能降级（覆盖95%+场景）
3. **持续优化** - 根据质量数据调整阈值
