# GLM-4.6 数学动画生成器 - Web 应用使用指南

## 🎉 恭喜！Web 应用已创建完成！

你现在拥有一个完整的 Web 应用，可以通过浏览器轻松生成数学动画。

## ✅ 已创建的文件

### 后端
- `backend-v2/api/web_animation.py` - FastAPI 后端服务
- `backend-v2/agents/glm_animation_agent.py` - GLM 动画生成代理

### 前端
- `web_app/index.html` - 完整的单页 Web 应用

### 启动脚本
- `start_web_app.sh` - 一键启动脚本

## 🚀 快速开始

### 方式 1: 使用启动脚本（推荐）

```bash
./start_web_app.sh
```

### 方式 2: 手动启动

```bash
cd backend-v2/api
python3 web_animation.py
```

启动成功后，你会看到：
```
🚀 启动 GLM-4.6 数学动画生成器 Web 服务
============================================================
📱 访问地址: http://localhost:8000
📚 API 文档: http://localhost:8000/docs
============================================================
```

## 📱 访问 Web 应用

在浏览器中打开：
```
http://localhost:8000
```

你将看到一个漂亮的界面，包含：
- ✨ 术语生成表单
- ✨ 概念生成表单
- 📊 实时统计信息
- 📜 生成历史记录
- 💾 代码下载功能

## 🎯 功能演示

### 1. 从术语生成动画

**步骤**:
1. 在左侧选择"术语生成"标签
2. 填写中文术语（例如：正弦）
3. 填写英文术语（例如：Sine）
4. 填写数学符号（例如：`\sin \alpha = \frac{y}{r}`）
5. 点击"✨ 生成动画"按钮

**预期结果**:
- 2-5 秒后显示生成结果
- 包含完整的 Python 代码
- 显示使用的 tokens 和成本
- 可以下载生成的代码文件

### 2. 从概念生成动画

**步骤**:
1. 在左侧选择"概念生成"标签
2. 填写概念描述（例如：展示勾股定理的几何证明）
3. 可选：填写 LaTeX 表达式（例如：`a^2 + b^2 = c^2`）
4. 设置动画时长
5. 点击"✨ 生成动画"按钮

### 3. 查看统计信息

页面顶部显示：
- 总生成次数
- 成功率
- 总成本

### 4. 查看历史记录

页面底部显示最近 10 条生成记录。

### 5. 下载代码

点击生成结果中的"📥 下载代码"按钮即可下载 Python 文件。

## 🔌 API 接口

### 自动生成的 API 文档

访问：`http://localhost:8000/docs`

你将看到完整的 Swagger API 文档，包括：
- 所有可用的 API 端点
- 请求/响应模型
- 在线测试功能

### 主要 API 端点

#### 1. 健康检查
```bash
GET /api/health
```

#### 2. 从术语生成
```bash
POST /api/generate/terminology
Content-Type: application/json

{
  "chinese": "正弦",
  "english": "Sine",
  "symbol": "\\sin \\alpha = \\frac{y}{r}",
  "save_to_db": true
}
```

#### 3. 从概念生成
```bash
POST /api/generate/concept
Content-Type: application/json

{
  "concept": "展示勾股定理的几何证明",
  "latex": "a^2 + b^2 = c^2",
  "duration": 10
}
```

#### 4. 获取历史
```bash
GET /api/history?limit=20
```

#### 5. 获取统计
```bash
GET /api/stats
```

#### 6. 下载文件
```bash
GET /api/download/{filename}
```

#### 7. 查看代码
```bash
GET /api/code/{scene_name}
```

## 💡 使用技巧

### 1. LaTeX 符号格式

在填写数学符号时，使用双反斜杠：
- ✅ 正确：`\\sin \\alpha = \\frac{y}{r}`
- ❌ 错误：`\sin \alpha = \frac{y}{r}`

### 2. 复制生成的代码

代码预览区域可以：
- 查看生成的代码
- 复制代码到剪贴板
- 下载完整的 Python 文件

### 3. 批量生成

在浏览器中多次点击"生成"按钮即可批量生成。

### 4. 查看成本

每个生成请求都会显示：
- 使用的 tokens 数量
- 预估成本（通常 ¥0.00006-0.00008）

## ❓ 常见问题

**Q: 如何停止服务？**
A: 在终端按 `Ctrl + C`

**Q: 端口被占用怎么办？**
A: 修改 `web_animation.py` 中的端口号（默认 8000）

**Q: 可以远程访问吗？**
A: 可以，在浏览器中使用 `http://你的IP:8000`

**Q: 生成失败怎么办？**
A:
1. 检查 API 密钥是否有效
2. 查看浏览器控制台的错误信息
3. 查看终端的服务器日志

**Q: 如何修改界面？**
A: 编辑 `web_app/index.html` 文件

**Q: 支持哪些浏览器？**
A: 所有现代浏览器（Chrome、Firefox、Safari、Edge）
