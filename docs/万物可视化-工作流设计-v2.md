## 项目核心定位

### 核心目标

**文档分析 + AI问答 + 核心概念可视化**

用户上传PDF → 系统提取核心概念 → 基于文档AI问答 → 可视化核心概念

### 与Math2Manim的本质差异

| 维度 | Math2Manim（之前参考）| 万物可视化（实际需求）|
|------|---------------------|-------------------|
| **输入** | 用户问题（"解释量子力学"）| 已有PDF文档 |
| **输出** | 教学动画（从基础讲起）| 文档分析+AI问答+概念可视化 |
| **目标用户** | 学习者（零基础）| 研究者/学生（有基础）|
| **核心方法** | 反向知识树（递归构建前置知识）| 文档内容提取（TF-IDF+模板匹配）|
| **AI角色** | 生成教学动画 | 基于文档问答+生成可视化代码 |
| **知识来源** | AI推理生成 | 从文档中提取 |

**关键结论：不应该使用反向知识树！**

**输出**: 学科分类（主学科+置信度）

#### 处理流程

```python
class SubjectRouter:
    """学科路由模块"""

    def classify(self, doc_id, content):
        # 1. 特征提取（调用 GM4.6 API）
        features = self._extract_features_with_gm46(content)

        # 2. 朴素贝叶斯初步分类
        nb_results = self._naive_bayes_classify(features)

        # 3. SVM二次确认
        final_subject = self._svm_confirm(nb_results, content)

        # 4. 更新数据库
        self._update_subject(doc_id, final_subject)

        return final_subject

    def _extract_features_with_gm46(self, content):
        """使用 GM4.6 API 提取特征"""
        prompt = f"""
        分析以下文档内容，提取特征：

        {content[:2000]}  # 限制长度

        请返回JSON格式：
        {{
          "keywords": {{"关键词": "出现频次", ...}},
          "formulas": {{"公式": "类型", ...}},
          "section_titles": ["章节1", "章节2", ...]
        }}
        """

        result = gm46_api.generate(prompt)
        return self._parse_features(result)

    def _naive_bayes_classify(self, features):
        """朴素贝叶斯分类"""
        from sklearn.naive_bayes import MultinomialNB

        # 构建特征向量（100维）
        vector = self._build_feature_vector(features)

        # 加载预训练模型
        nb_model = joblib.load('models/naive_bayes_model.pkl')

        # 预测
        probabilities = nb_model.predict_proba([vector])[0]

        # 返回前2个高概率学科
        top_2 = np.argsort(probabilities)[-2:][::-1]

        return {
            'subjects': [nb_model.classes_[i] for i in top_2],
            'probs': [probabilities[i] for i in top_2]
        }

    def _svm_confirm(self, nb_results, content):
        """SVM二次确认"""
        from sklearn.svm import SVC

        # 针对前2个候选学科
        candidates = nb_results['subjects']

        # 提取关键词组合规则
        rule_matches = self._match_keyword_rules(content, candidates)

        # 加载SVM模型
        svm_model = joblib.load('models/svm_model.pkl')

        # 预测
        final_subject = svm_model.predict([rule_matches])[0]

        return {
            'subject': final_subject,
            'confidence': nb_results['probs'][0]  # 使用NB的置信度
        }
```

**关键技术**:
- **GM4.6 API**: 提取学科关键词、公式特征、章节标题
- **scikit-learn**: 朴素贝叶斯(MultinomialNB) + SVM(SVC)
- **特征向量**: 100维，对应学科关键词库

### 模块3：核心概念提取模块

**输入**: 学科 + 预处理文本
**输出**: 核心概念列表（按重要性排序）

#### 处理流程

```python
class CoreConceptExtractor:
    """核心概念提取模块"""

    def extract(self, doc_id, subject, content):
        # 1. 加载学科核心概念词库
        concept_vocab = self._load_concept_vocabulary(subject)

        # 2. TF-IDF权重计算
        tfidf_scores = self._calculate_tfidf(content, concept_vocab)

        # 3. 取前20个概念
        top_20 = tfidf_scores[:20]

        # 4. GM4.6上下文过滤与补充
        final_concepts = self._gm46_filter_and_supplement(
            content,
            top_20,
            subject
        )

        # 5. 存储到数据库
        self._save_concepts(doc_id, final_concepts)

        return final_concepts

    def _calculate_tfidf(self, content, concept_vocab):
        """TF-IDF权重计算"""
        from sklearn.feature_extraction.text import TfidfVectorizer

        # 初始化向量化器
        vectorizer = TfidfVectorizer(
            vocabulary=concept_vocab,
            stop_words=self._load_stopwords(),
            token_pattern=self._build_token_pattern()  # 排除例题中的数字
        )

        # 计算TF-IDF
        tfidf_matrix = vectorizer.fit_transform([content])

        # 获取特征名和分数
        feature_names = vectorizer.get_feature_names_out()
        scores = tfidf_matrix.toarray()[0]

        # 排序
        sorted_indices = np.argsort(scores)[::-1]

        return [
            {
                'concept': feature_names[i],
                'tfidf_score': scores[i],
                'is_synonym': self._check_if_synonym(feature_names[i])
            }
            for i in sorted_indices
        ][:20]  # 取前20

    def _gm46_filter_and_supplement(self, content, top_20, subject):
        """GM4.6上下文过滤与补充"""
        prompt = f"""
        学科：{subject}
        文档内容：{content[:3000]}

        初步提取的TOP20概念（含TF-IDF得分）：
        {json.dumps(top_20, ensure_ascii=False)}

        请执行以下任务：

        1. **过滤次要概念**：
           - 排除仅在"例题/练习题"中出现，未在"定义/定理"中出现概念
           - 例如："四阶行列式"若仅出现在例题，应过滤

        2. **补充隐含概念**：
           - 若文档多次提及某概念的特征但未明确命名，应补充
           - 例如：多次提到"向量加法满足交换律、数乘满足分配律"，应补充"线性空间"

        3. **重要性排序**：
           - 按"概念在标题中出现次数 + 在定义/定理中出现次数 + TF-IDF得分"综合排序
           - 取前10个核心概念

        返回JSON格式：
        {{
          "final_concepts": [
            {{
              "name": "概念名",
              "synonyms": ["同义词1", "同义词2"],
              "definition": "定义",
              "importance_score": 0.95,
              "locations": [{{"page": 3, "section": "1.2"}}],
              "is_supplemented": true,
              "reasoning": "为什么补充/保留这个概念"
            }}
          ]
        }}
        """

        result = gm46_api.generate(prompt)
        return json.loads(result)

    def _load_concept_vocabulary(self, subject):
        """加载学科核心概念词库"""
        # 例如：线性代数核心概念库
        return {
            '行列式': ['行列式', 'det(A)', 'determinant'],
            '向量组': ['向量组', 'vector set', '向量集合'],
            '秩': ['秩', 'rank', 'r(A)'],
            # ... 20+核心概念，每个含同义词/别名
        }
```

**关键技术**:
- **scikit-learn**: TfidfVectorizer计算TF-IDF权重
- **GM4.6 API**: 上下文过滤（去除例题概念）+ 补充隐含概念
- **核心概念词库**: 每个学科20+核心概念，含同义词

class VisualizationGenerator:
    """可视化模板匹配与代码生成模块"""

    def generate(self, doc_id, subject, concepts):
        # 1. 模板匹配
        matched_templates = self._match_templates(subject, concepts)

        # 2. 为每个概念生成可视化代码
        visualizations = []

        for concept in concepts:
            # 获取匹配的模板
            template = matched_templates.get(concept['name'])

            if not template:
                # 无匹配模板
                visualizations.append({
                    'concept': concept['name'],
                    'status': 'no_template',
                    'message': '当前概念暂无可视化模板'
                })
                continue

            # 生成可视化代码
            viz_code = self._generate_viz_code(
                template=template,
                concept=concept,
                doc_id=doc_id
            )

            # 存储到云存储
            code_url = self._upload_to_cloud_storage(viz_code)

            visualizations.append({
                'concept': concept['name'],
                'template_id': template['id'],
                'template_name': template['name'],
                'code_url': code_url,
                'parameters': template['parameters'],
                'status': 'ready'
            })

        # 3. 更新数据库
        self._update_visualizations(doc_id, visualizations)

        return visualizations

    def _match_templates(self, subject, concepts):
        """匹配可视化模板"""
        # 加载模板库
        template_library = self._load_template_library()

        matched = {}

        for concept in concepts:
            concept_name = concept['name']

            # 查找匹配的模板
            templates = [
                tmpl for tmpl in template_library
                if tmpl['subject'] == subject
                and concept_name in tmpl['applicable_concepts']
            ]

            if not templates:
                continue

            # 如果匹配多个模板，按使用率排序
            templates.sort(key=lambda x: x['usage_count'], reverse=True)

            # 返回使用率最高的模板
            matched[concept_name] = templates[0]

        return matched

    def _generate_viz_code(self, template, concept, doc_id):
        """生成可视化代码（调用 GM4.6 API）"""
        prompt = f"""
        模板ID：{template['id']}
        模板名称：{template['name']}

        核心概念信息：
        - 名称：{concept['name']}
        - 定义：{concept['definition']}
        - 公式（LaTeX）：{concept.get('formulas', [])}
        - 例题数据：{concept.get('examples', [])}

        前端交互要求：
        {json.dumps(template['interaction_requirements'], ensure_ascii=False)}

        请生成符合以下要求的 HTML/CSS/JS 代码：

        1. **浏览器兼容性**：兼容 Chrome 90+、Firefox 88+、Edge 90+
        2. **参数联动**：集成参数调整逻辑（如接收 "阶数=3" 参数后，动态渲染三阶行列式图形）
        3. **学科规范**：可视化效果符合学科规范（如行列式几何意义准确展示面积/体积）
        4. **代码注释**：包含详细注释（说明参数含义、交互逻辑）
        5. **技术栈**：
           - JS兼容ES6
           - CSS使用Tailwind CSS v3
           - 可使用D3.js进行数据可视化
           - 可使用MathJax渲染LaTeX公式

        返回完整的 HTML/CSS/JS 代码（单个文件，包含所有依赖的CDN链接）。
        """

        result = gm46_api.generate(prompt, max_tokens=8000)

        # 提取代码块
        code = self._extract_code_block(result)

        # 压缩代码
        code = self._minify_code(code)

        return code

    def _load_template_library(self):
        """加载可视化模板库"""
        return [
            {
                'id': 'LINEAR_ALGEBRA_DETERMINANT_GEOMETRY',
                'subject': '线性代数',
                'name': '行列式几何意义',
                'applicable_concepts': ['行列式', 'determinant'],
                'usage_count': 1523,
                'interaction_requirements': {
                    'parameters': [
                        {
                            'name': 'order',
                            'type': 'select',
                            'options': [2, 3, 4],
                            'default': 2,
                            'label': '阶数'
                        },
                        {
                            'name': 'elements',
                            'type': 'array',
                            'constraints': {'min': -10, 'max': 10},
                            'label': '元素值'
                        }
                    ],
                    'visualization_type': 'dynamic',
                    'support_interactions': ['zoom', 'fullscreen', 'export']
                }
            },
            # ... 更多模板（至少20个）
        ]

### 模块5：AI问答联动模块

**输入**: 用户提问 + 文档ID + 选定模型
**输出**: AI回答（含可视化超链接）

#### 处理流程

```python
class AIQAService:
    """AI问答联动模块"""

    def answer(self, user_id, doc_id, question, selected_models, conversation_id=None):
        # 1. 获取文档上下文
        context = self._get_document_context(doc_id)

        # 2. 构建prompt
        prompt = self._build_prompt(question, context)

        # 3. 调用AI模型
        answers = []

        if 'single' in selected_models:
            model_name = selected_models['single']
            answer = self._call_model(model_name, prompt)
            answers.append({
                'model': model_name,
                'answer': answer,
                'time': datetime.now()
            })

        elif 'comparison' in selected_models:
            # 对比模式：同时调用2个模型
            models = selected_models['comparison']
            results = self._call_models_parallel(models, prompt)

            for model_name, answer in results.items():
                answers.append({
                    'model': model_name,
                    'answer': answer,
                    'time': datetime.now()
                })

        # 4. 处理回答（注入可视化超链接）
        for answer in answers:
            answer['answer'] = self._inject_viz_links(
                answer['answer'],
                doc_id,
                context['core_concepts']
            )

        # 5. 保存对话历史
        conv_id = self._save_conversation(user_id, doc_id, question, answers, conversation_id)

        return {
            'conversation_id': conv_id,
            'answers': answers
        }

    def _get_document_context(self, doc_id):
        """获取文档上下文"""
        # 从数据库获取
        doc = db.get_document(doc_id)

        return {
            'subject': doc['subject'],
            'content_preview': doc['content'][:500],  # 前500字
            'core_concepts': doc['core_concepts'],  # 核心概念列表
            'structure': doc['structure']
        }

    def _build_prompt(self, question, context):
        """构建prompt"""
        core_concepts_str = ', '.join([c['name'] for c in context['core_concepts']])

        prompt = f"""
        基于用户上传的【{context['subject']}】文档（内容摘要：{context['content_preview']}}），
        回答问题：{question}

        **要求**：
        1. 结合文档内容回答，避免泛化
        2. 若涉及核心概念（{core_concepts_str}），简要说明后标注"可查看可视化分析"
        3. 回答清晰易懂，分点说明（若适用）
        4. 保持上下文连贯（若为追问）
        """

        return prompt

    def _call_model(self, model_name, prompt):
        """调用单个AI模型"""
        if model_name == '豆包':
            return self._call_doubao(prompt)
        elif model_name == 'Gemini':
            return self._call_gemini(prompt)
        elif model_name == 'ChatGPT':
            return self._call_chatgpt(prompt)

    def _inject_viz_links(self, answer, doc_id, core_concepts):
        """注入可视化超链接"""
        for concept in core_concepts:
            concept_name = concept['name']

            # 检查回答中是否提到该概念
            if concept_name in answer:
                # 构建超链接
                viz_url = f"/visualization?docId={doc_id}&conceptId={concept['id']}"

                # 替换概念为超链接
                answer = answer.replace(
                    concept_name,
                    f"{concept_name}（<a href="{viz_url}" target="_blank">查看可视化分析</a>）"
                )

        return answer
```

**关键技术**:
- **多模型支持**: 豆包、Gemini、ChatGPT
- **上下文管理**: 保持单文档对话上下文
- **可视化联动**: 回答中自动注入可视化超链接

<template>

## 关键实施要点

### 1. 数据库设计

```sql
-- 文档表
CREATE TABLE documents (
    doc_id VARCHAR(50) PRIMARY KEY,
    user_id VARCHAR(50) NOT NULL,
    filename VARCHAR(255) NOT NULL,
    file_size BIGINT,
    upload_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    status ENUM('preprocessing', 'subject_identified', 'concept_extracted', 'visualization_ready', 'failed'),
    subject VARCHAR(50),
    cloud_path TEXT,
    is_scanned BOOLEAN,
    FOREIGN KEY (user_id) REFERENCES users(user_id)
);

-- 核心概念表
CREATE TABLE core_concepts (
    concept_id VARCHAR(50) PRIMARY KEY,
    doc_id VARCHAR(50) NOT NULL,
    name VARCHAR(100) NOT NULL,
    synonyms JSON,
    definition TEXT,
    importance_score FLOAT,
    is_supplemented BOOLEAN,
    locations JSON,
    FOREIGN KEY (doc_id) REFERENCES documents(doc_id)
);

-- 可视化代码表
CREATE TABLE visualizations (
    viz_id VARCHAR(50) PRIMARY KEY,
    doc_id VARCHAR(50) NOT NULL,
    concept_id VARCHAR(50) NOT NULL,
    template_id VARCHAR(50),
    code_url TEXT,
    parameters JSON,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (doc_id) REFERENCES documents(doc_id),
    FOREIGN KEY (concept_id) REFERENCES core_concepts(concept_id)
);

-- 对话历史表
CREATE TABLE conversations (
    conv_id VARCHAR(50) PRIMARY KEY,
    user_id VARCHAR(50) NOT NULL,
    doc_id VARCHAR(50) NOT NULL,
    question TEXT NOT NULL,
    answer TEXT NOT NULL,
    model VARCHAR(20) NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    feedback ENUM('useful', 'inaccurate', 'no_feedback'),
    FOREIGN KEY (user_id) REFERENCES users(user_id),
    FOREIGN KEY (doc_id) REFERENCES documents(doc_id)
);
```

## 总结

### 核心工作流

```
PDF上传 → 预处理（OCR/文本提取）
→ 学科分类（朴素贝叶斯+SVM）
→ 核心概念提取（TF-IDF+GM4.6）
→ 模板匹配 → 可视化生成（GM4.6）
→ AI问答（多模型）
```

### 关键技术

- **GM4.6 API**: 特征提取、概念补充、代码生成
- **MinerU API**: 扫描件OCR
- **scikit-learn**: 学科分类、概念提取
- **多模型AI**: 豆包、Gemini、ChatGPT

### 与Math2Manim的差异

**不是教学系统，而是文档分析系统！**
**不是知识构建，而是内容提取！**
**不是反向递归，而是正向分析！**
