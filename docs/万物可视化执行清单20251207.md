# 🎯 万物可视化执行清单 20251207

**目标转变**: 从"扩充预设模板库"转向"构建通用AI可视化生成引擎"。不再手动编写每一个模板，而是赋予系统根据用户自然语言实时生成交互式可视化的能力。

## 📊 核心架构升级路线图

### 1. 现代 AI 界面 (Modern AI Interface)
**目标**: 打造媲美 Claude Artifacts / ChatGPT Canvas 的交互体验，支持流式输出与可视化界面的无缝融合。

- [ ] **流式对话 UI 重构**
  - [ ] 实现打字机效果的流式文本渲染 (Markdown + LaTeX)。
  - [ ] 状态指示器升级 (思考中、生成代码中、渲染中)。
- [ ] **可视化工件 (Artifacts) 容器**
  - [ ] 独立的可视化面板 (右侧分栏或弹窗)，与对话流分离。
  - [ ] 支持代码查看/编辑模式 (允许用户微调生成的代码)。
  - [ ] 全屏/沉浸式预览模式。
- [ ] **交互式参数面板**
  - [ ] AI 自动识别变量，动态生成滑块/输入框 (不再硬编码 HTML)。
- [ ] **基础交互体验优化**
  - [ ] **对话布局调整**: 符合主流习惯，用户消息靠右 (Right-aligned)，AI 消息靠左 (Left-aligned)。
  - [ ] **文本操作增强**: 确保全局文字允许选择与复制 (user-select)，输入框完全支持系统级复制粘贴操作。

### 2. 学科路由器 (Subject Router)
**目标**: 构建智能分发中枢，准确识别用户意图，将请求路由至最适合的垂直领域模型或 Prompt 策略。

- [ ] **意图识别层**
  - [ ] 开发 LLM 分类器 (区分：闲聊 / 绘图 / 数学推导 / 物理模拟 / 天文演示)。
  - [ ] 提取关键实体 (如：公式、初始条件、天体名称)。
- [ ] **路由策略**
  - [ ] **数学路由**: 指向 Python/SymPy (符号计算) + Plotly。
  - [ ] **物理路由**: 指向 Matter.js (2D物理) / Three.js (3D场景)。
  - [ ] **通用/统计路由**: 指向 ECharts / Plotly (数据图表)。
- [ ] **上下文管理**
  - [ ] 维护多轮对话状态，支持"把这个球变红"或"增加重力"等修改指令。

### 3. 通用可视化引擎 (General Visualization Engine)
**目标**: 核心生成模块，实现 "Text-to-Interactive-Code" 的动态生成能力。

- [ ] **动态代码生成器**
  - [ ] 设计通用的 System Prompt，规范输出格式 (HTML + JS + Dependencies)。
  - [ ] 注入标准库支持 (自动引入 Plotly, Three.js, MathJax 等 CDN)。
- [ ] **安全沙箱环境 (Sandbox)**
  - [ ] 升级 `<iframe>` 机制，确保生成的 AI 代码在隔离环境中运行。
  - [ ] 实现父子页面通信 (postMessage)，用于参数动态调整。
- [ ] **自我修正机制 (Self-Correction)**
  - [ ] 捕获 iframe 运行时的 JS 错误。
  - [ ] 将错误堆栈回传给 LLM，触发自动修复重绘。

### 4. 后端与模型集成 (Infrastructure)
**目标**: 提供强大的计算支持与模型接入。

- [ ] **模型接入层**
  - [ ] 接入主流大模型 API (DeepSeek / Claude / GPT-4o)。
  - [ ] 建立 Prompt 模板库管理系统。
- [ ] **数据与存储**
  - [ ] 存储用户生成的优质可视化代码 (构建私有知识库)。
  - [ ] 用户偏好设置同步。
